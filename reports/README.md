# 审计报告

本目录保存可公开的批次、质量、素材权利和构建报告。原始接口响应、失败页面和可能含敏感信息的日志只保存在相邻的 `private-archive`。

- [`completeness-reconciliation.md`](completeness-reconciliation.md)：主页、合集与编号口径对账；
- [`qa-summary.md`](qa-summary.md)：当前自动化质量检查摘要；
- [`public-release-v0.1.1.md`](public-release-v0.1.1.md)：v0.1.1 发布候选范围与门禁；
- [`release-notes-v0.1.1.md`](release-notes-v0.1.1.md)：拟发布版本说明；
- `content-rights.csv` / `asset-rights.csv`：正文与素材权利待审清单。
