# 审计报告

本目录保存可公开的批次、质量、权利、脱敏和发布报告。原始接口响应、失败页面、图片及可能
含敏感信息的日志只保存在相邻的 `private-archive`。

- [`completeness-reconciliation.md`](completeness-reconciliation.md)：主页、合集与编号口径对账；
- [`qa-summary.md`](qa-summary.md)：当前自动化质量检查摘要；
- [`text-authorization-v0.2.0.md`](text-authorization-v0.2.0.md)：正文许可人、范围与授权口径；
- [`fulltext-redactions.csv`](fulltext-redactions.csv)：不暴露原值的正文脱敏记录；
- [`readme-svg-v0.2.0.md`](readme-svg-v0.2.0.md)：原创 README 信息图的设计、来源与视觉验收；
- [`public-release-v0.2.0.md`](public-release-v0.2.0.md)：v0.2.0 发布范围与门禁结果；
- [`release-notes-v0.2.0.md`](release-notes-v0.2.0.md)：v0.2.0 GitHub Release 说明；
- `content-rights.csv`：475 篇正文的许可字段审计；
- `asset-rights.csv`：逐篇图片数量、占位符与素材状态。

v0.1.0 与 v0.1.1 的历史发布报告继续保留，用于追踪从元数据版本升级到全文版本的范围变化。
