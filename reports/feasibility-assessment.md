# 公众号知识库与 Git 开源评估

## 判断

这个公众号可以整理成 Git 原生知识库。当前最合适的形态是“Markdown 事实库 + 机器索引 + 中文全文检索 + 静态站点”，原始档案与公开仓库分层保存。它便于版本追踪、人工校订、AI 检索和后续迁移，也不把项目锁死在某个向量数据库中。

## 当前证据

- 公开合集接口当前可连续取得 475 篇文章清单，位置 1–475。
- 合集最大文章编号为 483，编号 3、94、435 未决，356–364 高度疑似一次跳号。
- 公众号主页截图显示 486 篇原创内容；截图同期合集为 474 篇，历史差额 12 篇仍需后台导出或人工清单补齐。
- 跨早期、中期和近期文章的公开直链正文、标题、账号与图片清单已验证。
- `chksm` 是公开合集文章链接的必要校验参数，必须保留。

## 推荐发布边界

代码、目录结构、处理脚本和空白模板可使用 MIT。文章正文需要权利人另行确认许可，可选 CC BY-NC 4.0、CC BY 4.0 或保留所有权利；选择应基于作者构成和传播目标。论文封面、期刊图表、照片、引用截图和客座作者材料逐项审查，不能随正文许可证自动开源。

当前公开仓库只发布代码与元数据，正文和图片继续保存在私有归档。未来启用全文站点或 GitHub
Pages 前，仍须逐项完成权利核对并另行确认发布范围。
