# 首次 Git 提交候选范围

## 目标

首个提交用于建立可复现的“代码＋元数据”知识库骨架。它可以在全新 clone 中运行单元测试并严格构建元数据站点，同时不复制公众号文章正文、正文摘要片段或图片。

## 纳入范围

- 项目说明、协作规则、MIT 代码许可证和内容权利声明；
- 公开合集发现、正文导入、图片私有归档、索引、检索和质量审计脚本；
- 单元测试、依赖锁文件和 MkDocs 配置；
- `data/article-metadata.jsonl` 的 474 条公开安全元数据；
- `docs/catalog-public.md` 的标题、日期、栏目和微信原文链接；
- 导入状态、质量报告、权利待审清单和项目专用 skill。

## 明确排除

- `docs/articles/`：474 篇文章正文；
- `data/articles.jsonl`：含正文 `preview` 的本地全文索引；
- `docs/llms.txt`：含正文摘要片段的代理检索索引；
- `docs/catalog.md`：指向本地全文页面的本地目录；
- 原始 HTML、原图、接口快照、搜索日志、浏览器配置及整个 `private-archive`；
- `.venv/`、`site/`、缓存、环境变量和凭据文件。

以上正文与正文衍生文件已由 `.gitignore` 设置发布闸门。即使执行普通 `git add .`，这些路径也不会进入候选提交。

- Ruff：通过。
- Pytest：10/10 通过。
- `mkdocs build --strict`：通过；构建只依赖公开目录与安全元数据。
