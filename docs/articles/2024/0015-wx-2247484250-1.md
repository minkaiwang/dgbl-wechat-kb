# 元语言纠正反馈对新英语学生基于数字游戏的语法学习表现、感知和行为模式的影响

**2**

**摘要**

**①背景**

通过数字游戏进行学习已经相当受欢迎。虽然基于数字游戏的学习有潜力提高学习者的语言学习成绩、参与度和动机，但在这些游戏中向学习者提供有效反馈方面仍然存在差距。

**②问题**

传统的数字游戏通常为学习者提供即时纠错功能，这对于学习者学习复杂的语言内容（例如语法）时帮助不大。

**③方法**

在这项研究中，提出了一种基于元语言纠正反馈的数字游戏方法。此外，还进行了一项实验，探讨数字游戏与元语言纠正反馈相结合如何影响英语新手的语法学习成绩，以及他们在学习过程中对学习动机、自我效能和心流体验的感知。滞后序贯分析也用于识别两组行为模式的差异。共有 76 名大学生参与了这项研究。实验组通过数字游戏结合元语言纠正反馈来学习目标语法，而对照组则通过数字游戏结合定期反馈来学习，这是即时纠错。

**④结果**

结果表明，元语言纠正反馈对学生的语法学习有积极影响，对初始内在动机和自我效能感较低的学生有利。不同的反馈类型也会导致不同的学习行为。从业者笔记 关于此主题的已知信息 反馈在基于数字游戏的学习领域具有巨大的潜力。在设计数字游戏来引导语言学习者进行有意义的学习时，应考虑适当的教学理论和策略。本文所添加的通过强调语法规则和语言结构来指导学习者纠正错误的反馈被称为元语言纠正反馈。本研究提出了一种基于元语言纠正反馈的数字游戏方法，以探索此类反馈在数字游戏中的功效。除了学习成果之外，本研究还记录和分析了学习者的学习行为模式。对实践和/或政策的影响 将元语言纠正反馈整合到数字游戏中以促进语言学习者的学习表现和感知可能是值得的。元语言纠正反馈有潜力支持自我效能感和学习复杂语言内容动机较低的学习者。未来的研究可以将不同的反馈模型集成到数字游戏中并研究其有效性。

**3**

**问题**

1. 通过基于数字游戏的学习（整合了元语言纠正反馈方法（DGBL-MF））的英语新手学习者的语法**学习表现**与那些接受定期反馈（DGBL-RF）的人相比是否有统计学上的显着差异？
2. 接受 DGBL-MF 的英语新手**学习动机**与接受 DGBL-RF 的英语学习者的学习动机是否存在显着差异？
3. 接受 DGBL-MF 的英语新手与接受 DGBL-RF 的英语学习者的**自我效能感**有统计学差异吗？
4. 接受 DGBL-MF 的英语新手与接受 DGBL-RF 的英语学习者在**心流体验**方面是否存在显着差异？
5. 接受 DGBL-MF 和 DGBL-RF 的英语新手的**学习行为**有何差异？

**4**

**特点**

**目标结构：**

选择关系代词作为目标结构。原因在于，它是一种学生已经有了显性知识的结构，但在使用时仍然会犯错误。该课程的目的不是检查这两种类型的反馈是否有助于学生学习全新的结构，而是检查它们是否有助于学生控制他们过去未完全掌握的结构。

**系统设计：**

学习者扮演一个想成为侦探的男孩的角色。有一天，他得知，在一个遥远的村庄里，有一所侦探培训学院。迫切地想要成为一名侦探后，他前往村庄追寻自己的梦想。到达村庄后，男孩（学习者）会经历三个阶段的任务，包括（A）学习阶段、（B）实践阶段和（C）高级实践阶段。

在A阶段“成为侦探”中，学习者被要求观看两段有关“关系代词”语法结构的教学视频（图3），并回答选择题练习题。在练习过程中，老师要求学生独立回答多项选择题。如果学生提供了正确的答案，他们会收到积极的反馈并继续下一个问题，直到完成所有问题；另一方面，如果学生回答错误，他们会收到纠正反馈，并被要求重新回答问题。

在B阶段，学习者必须完成寻找目标人物亚历山大的任务。为了找到他，学习者必须运用第一阶段所学的知识；也就是说，他们需要通过回答关系代词选择题与村民交流，收集线索，最终找到目标。此阶段的所有选择题都与故事情节精心配合，引导玩家实现最终目标。

在C阶段，学习者必须完成一项定时任务。城堡的主人在城堡里藏了许多宝箱，每个宝箱里都装有一枚硬币，并由一名仆人看守。学习者的任务是在 5 分钟内击败仆人并收集尽可能多的硬币。

为了打败仆人，他们需要完成仆人给出的关系代词的多项选择题。虽然这个阶段的问题可能不是相互依赖的，但学生们仍然被赋予了一个统一的背景，即收集硬币的目标和侦探的头衔。最终，如果学习者成功收集超过15枚硬币，则被授予“高级侦探”称号；如果学习者收集到7到15枚硬币，他们将被授予“实习侦探”称号；如果收集到的金币少于七枚，就只能获得“侦探助理”的称号，并被转移到地下山洞接受进一步的指导。想要走出山洞，他们还需要再观看两段教学视频，只不过这一次视频的速度慢了很多，让学习者有更多的时间来处理视频中的教学内容。

对于显式反馈组，如果学生给出了错误的答案，他们将获得正确的答案，并附有语法解释。反馈显示正确答案是“谁”。它所指的先行词是“人”，后面的词是动词，即关系代词代替主语。因此，答案应该是“谁”，一个主观关系代词，指的是一个人。另一方面，对于元语言纠正反馈组（右侧）来说，如果他们回答错误，他们会得到语法解释，但不会得到正确答案。

**实验**

**参与人员：**

中科大两个班共76名英语新手作为便利参与者。在这个准实验设计中，一类（n = 37）被分配到常规反馈组，另一类（n = 39）是元语言纠正反馈组。两个班级由同一位老师授课，学生们过去都没有经历过基于数字游戏的学习。值得注意的是，本研究中的英语新手是根据英语水平测试结果来定义的。大多数参与者都是英语基础使用者，英语语言水平在 A1 到 A2 之间。

**实验流程：**
两组首先进行预测试，测量他们的课程知识，并完成自我效能和学习动机的预问卷。这个过程持续了大约20分钟。本阶段要求学生在10分钟内完成预测。预问卷方面，老师带领全班同学一起阅读并回答每个问题。

第二阶段，两组均接受了游戏的指导和指导，并开始了学习过程。对照组采用基于数字游戏的学习方法并结合定期反馈进行学习，而实验组则采用接受元语言纠正反馈的相同方法学习相同的内容。学生允许按照自己的节奏玩游戏。整个学习过程持续约70分钟。两组之间没有观察到显着的时间差异。学习活动结束后，要求两组学生在15分钟内完成语法后测。老师还带领学生共同完成学习动机、自我效能感、心流体验等后测问卷。这是第三阶段，持续约30分钟。

**学习效果：**

前测和后测由两位具有10年以上EFL课程教学经验的英语讲师设计，测试学生对关系代词语法结构的了解。两项测试均包含 10 个多项选择题和 5 个填空题，满分 100 分。

我们尝试采用单向方差分析（ANOVA）来比较两组的预测试分数。然而，由于违反了正态性和方差齐性的假设（p = 0.046 < 0.05），因此进行了 Brown-Forsythe 检验。结果表明，两组之间没有差异，F(1,66.38) = 0.02，p = 0.89 > 0.05，表明他们在玩游戏之前处于相似的语法水平。

接下来，采用单向协方差分析（ANCOVA）比较治疗后两组的语法学习成绩，以预测分数作为协变量，以消除预先存在的组间差异的影响。在进行ANCOVA之前，对两组预测分数检验回归系数的同质性。 F(1,72) = 0.29, p > 0.05 证实了这一点，表明可以使用 ANCOVA 来分析两组的后测分数。

从ANCOVA结果来看，实验组学生的调整平均值和标准误差分别为75.58和14.56，而对照组学生的调整平均值和标准误差分别为68.72和19.57。根据结果（F(1,73) = 4.09，p < 0.05，η2 = 0.05），两组之间存在显着差异。

此外，使用重复测量方差分析来研究不同组和测试时间对学习成绩的影响。

**学习动机：**

改编自 Wang 和 Chen（2010）的研究，根据采用 Pintrich 等（1991）人提出的措施。 。问卷包括两个维度：内在动机和外在动机。内在动机包括三个问题（例如，“在这样的课程中，我更喜欢真正挑战我的课程材料，这样我就可以学习新事物”）。外在动机还包括三个问题（例如，“我想在这门课上取得好成绩，因为向我的家人、朋友或其他人展示我的能力很重要”。）

本研究采用的学习动机问卷由内在动机和外在动机两个维度组成。关于内在动机，进行回归斜率的同质性以确保ANCOVA的执行是否充分。结果表明，回归同质性假设被违反（F = 4.59，p = 0.04 < 0.05）。因此，采用Johnson-Neyman技术进行后续分析；提出了约翰逊-内曼图。另一方面，还进行了回归斜率的同质性以确定ANCOVA是否可以用于分析外在动机。结果表明，自变量和协变量之间不存在显着的交互作用。

**自我效能感：**

改编自 Pintrich 等（1991）人。 在使用 ANCOVA 之前，需要对回归斜率进行同质性检查，以确保 ANCOVA 的执行是否充分。由于自变量和协变量之间存在显着交互作用，F = 9.55，p < 0.05，因此不满足单向 ANCOVA 的标准；因此，采用Johnson-Neyman方法进行进一步分析。

以反馈类型为自变量、问卷后评分为因变量对两组自我效能感得分进行回归分析。结果表明，当问卷前分数低于4.09时，实验组的问卷后分数显着高于另一组，占75%（76人中的57人） ) 参与者；当问卷前评分高于4.09时，两组治疗后评分无差异（25%）。也就是说，当学生初始自我效能感较低时，接受元语言纠正反馈可以更好地提高其自我效能感；当学习者初始自我效能感较高时，反馈类型不会影响他们治疗后的自我效能感。

**心流体验：**

心流体验问卷采用 Pearce 等（2005）人的方法 。总共有八个问题（例如，“在学习活动中我感觉自己能控制自己所做的事情”）。采用独立样本t检验来检验两组的心流体验（表6）。结果表明，两组之间的心流体验存在统计学上的显着差异（t（74）= 5.34，p < 0.001）。具体来说，实验组的心流体验（M = 4.76，SD = 0.24）显着高于对照组（M = 4.29，SD = 0.49）。

**行为分析：**
总共包括7个编码项，是根据Yang（2017）和Lin等人制定的（2020）。

观看视频（WV），代表观看关系代词的教学视频；正确回答（AC）和错误回答（AW），代表对游戏中的问题提供正确和错误的答案；纠正反馈（CF），这是学习者提供错误答案时收到的反馈，复习学习材料（RL），代表复习所学内容，以及开始任务（SM）和完成任务（SM），代表学习的开始和完成被赋予的使命。
