**摘要**

[图像 05：待版权审查，原图保存在私有归档]

自适应教学支持对于满足学习者的个体差异、促进有意义的认知过程至关重要 。尽管商业模拟游戏（BSG）被广泛用于体验式的创业学习，但它们通常缺乏形成性反馈和结构化反思，这很容易让新手学习者感到不知所措，并加剧现有的教育不平等 。虽然AI支持的对话代理（CAs）为大规模自适应支持提供了潜力，但在数字游戏化学习（DGBL）领域，尤其是在伦理和“设计公平（equity-by-design）”方面，依然缺乏理论驱动的指导 。

本研究采用行动设计研究（ADR）方法，经过两轮迭代，开发并评估了AI增强的对话代理“Lara” 。研究团队基于教育心理学和信息系统研究，提出了一套名为 CAIS-GBL 的框架（包含4项设计原则和15项设计特征） 。通过对师范生和参与BSG的真实学生进行实地测试，结果表明：学生对 Lara 的认知和社交临场感、自主学习支持、易用性和行为意图均给予了积极评价 。随着五周游戏的推进，感知的社交临场感和自主学习支持显著增加 。此外，学生的性别、年龄和先验知识并未显著预测对CA的感知差异，而“对AI的态度”和“社交型玩家特质”则是关键预测因素 。这表明，Lara 能够公平地适应不同背景学习者的需求 。

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

- 如何设计对话代理，以便在商业模拟游戏中提供基于AI增强的自适应教学支持？
- 具有不同背景和倾向的学生对AI增强型对话代理的感知如何随时间演变？这些见解如何为面向教育公平的CA设计提供参考？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

数字游戏化学习（DGBL）通过将教育内容与电脑游戏结合，极大地提升了学习者的参与度 。在经济与商业教育中，商业模拟游戏（BSG）是极其重要的工具 。然而，如果缺乏量身定制的教学支持、及时的指导和形成性反馈，复杂的动态内容会导致严重的认知超载（Cognitive Overload） 。为了提供公平的学习机会，教学设计必须遵循通用学习设计（UDL）原则，主动消除学习障碍，防止数字环境固化现有的教育鸿沟 。在高等教育的大规模课堂中，教师无法做到一对一辅导 ，而引入AI驱动的对话代理（CAs）正是实现可扩展、个性化教学支持的完美解决方案 。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

本研究通过梳理多媒体学习认知理论（CTML）、自我决定理论（SDT）、控制-价值成就情绪理论（CVT）以及社会临场感理论，提炼出数字游戏化学习的四大元需求（Meta-Requirements, MRs） ：

- **MR1（认知）：** 通过管理认知负荷，促进有意义的认知参与 。
- **MR2（动机）：**通过支持基本心理需求，鼓励持续参与 。
- **MR3（情感）：**支持愉悦感，减少受挫焦虑 。
- **MR4（社会文化）：** 增强社交空间并坚守AI伦理责任（即设计公平） 。

**3. 游戏设计**

[图像 14：待版权审查，原图保存在私有归档]

本研究的应用场景是一款名为“初创企业竞赛（Start-Up Competition）”的商业模拟游戏。学生们分组运营一家初创的纺织公司，在5个回合内根据市场动态制定财务、营销和生产决策 。基于前期的需求分析和理论基础，研究团队提出了核心的 CAIS-GBL设计框架（包含4个设计原则 DP 和 15个设计特征 DF）并开发了名为 Lara 的AI对话代理 ：

- **DP1：基于指标的形成性反馈与按需指导。** Lara会抓取玩家游戏后台的19项核心数据，按照“FeedUp（总结目标）、FeedBack（反馈进度与指标关系）、FeedForward（提供改进建议）”的结构给予个性化反馈 。
- **DP2：无摩擦入场与持续参与。** Lara 直接内嵌在Moodle游戏平台右下角，通过解答基础的界面导航问题，降低新手的初始认知门槛 。
- **DP3：共情式对话互动。** Lara 会通过获取名字来称呼玩家，保持积极的“导师”语气。当后台检测到玩家的投资回报率（ROI）为负数时，它会表现出同理心，并主动提供情绪安抚和应对策略 。
- **DP4：社交性与公平设计（AI伦理）。** Lara 被严格限制访问最少量的个人数据（防偏见），其反馈仅基于客观的游戏内数据指标。此外，它支持软透明度——学生可以随时要求它用更简单的话解释某个经济学指标，或者质疑它的建议 。

**4. 方法与实验**

[图像 19：待版权审查，原图保存在私有归档]

本研究采用了经典的 行动设计研究（ADR） 方法，分为两轮核心迭代：

- **周期1（Alpha版评估）：**邀请了6名即将毕业的经济学师范硕士生参与工作坊。他们扮演玩家测试Lara，并从“未来教师”的视角提供可用性问卷反馈和开放式意见 。
- **周期2（Beta版实地测试）：** 在真实的BSG课程中开展了为期5周的纵向实地研究。共有122名本科生和研究生自愿使用Lara（其中112人至少使用了一次）。研究收集了学生的每次交互数据，并通过混合线性模型（LMMs）分析了时间推移、人口统计学（年龄、性别）、先验知识、AI态度以及游戏玩家类型对他们感知的影响 。

**5. 结果**

[图像 22：待版权审查，原图保存在私有归档]

- **总体评价极高：** 所有关于Lara的感知指标（社交临场感、认知临场感、自主学习支持、易用性、行为意图）均显著高于量表的中位数 。
- **时间序列的动态演变：**随着游戏的进行，学生对 Lara 的 社交临场感 和 自主学习支持 评价显著上升 ；实际交互量在第三周的“市场危机”关卡达到顶峰 。
- **真正的“教育公平”被证实（核心亮点）：** 数据强有力地证明，学生的年龄、性别和先验知识对Lara的感知和接受度没有可靠的显著影响。这意味着无论是“学霸”还是“学渣”，这款AI代理都能平等地服务好他们，没有扩大原有的教育鸿沟 。
- **被打破的预设——心理特质决定接受度：** 虽然人口统计学不影响结果，但学生的“对AI的态度”显著正向预测了他们的使用意图 。同时，“社交型（Socialiser）”玩家比“成就型（Achiever）”玩家更愿意与Lara互动，并在其中感受到更强的社交临场感和认知支持 。

**6. 讨论与总结**

[图像 34：待版权审查，原图保存在私有归档]

本研究不仅成功实例化了一个在真实课堂中运作的商业模拟AI代理（Lara），更重要的是，它提出了一套经受住实证检验的 CAIS-GBL 设计框架 。研究揭示了一个深刻的道理：缺失人口统计学上的差异，并不等同于绝对的教育公平 。既然学生对AI的态度和游戏动机直接塑造了他们对智能助手的感知，未来的教育游戏设计就必须针对这些“心理与动机差异”提供有针对性的入场引导，以防止那些对AI有抗拒心理的学生被技术抛弃 。

**教学启示**

[图像 36：待版权审查，原图保存在私有归档]

**对教师的教学启示：**引入AI助手（如智能助教）确实能大幅分担答疑和形成性评价的压力。但教师务必在游戏开始前进行“AI认知破冰”。研究证明，限制学生使用AI的往往不是知识水平，而是“AI焦虑”。向学生科普底层LLM的机制、提供优秀的Prompt模板，能有效提升他们的使用意愿和信任感 。

**对学校的启示：**在大面积采购教育AI产品时，学校管理层必须将“设计公平（Equity-by-design）”和“数据最小化”作为核心审核标准。优秀的教育AI不应过度抓取学生的隐私画像，而应仅仅依靠其“学习过程表现（如游戏内指标）”来生成指导 。

**对游戏设计师的启示（重点）：**

- 结构化反馈机制：不要让AI在游戏里随便闲聊！反馈必须遵循 Hattie 的三大黄金法则：FeedUp（当前目标是什么）、FeedBack（你刚才的数值有什么问题）、FeedForward（下一回合建议怎么改） 。
- 照顾“成就型（Achiever）”玩家：研究发现看重数值的“成就型”玩家对AI助手并不感冒。设计师应当在对话界面增加硬核的数据可视化分析，或者通过拓宽游戏内部的评价指标（不仅仅看ROI分数，还考核决策的逻辑性），来吸引这类玩家主动与AI探讨策略 。

**研究者如何复现内容和实验：**  剥离团队变量：目前的商业模拟是小组合作的，AI反馈往往基于“团队成绩”。未来的复现研究应采用“单人制（Individual）”商业模拟游戏，以便将AI干预的效果更干净地映射到个体认知改变上 。

- 采用RCT设计：未来应开展更严谨的随机对照试验（RCT），直接对比“有Lara辅助的BSG组”与“无辅助纯净BSG组”在最终学习成绩上的硬指标差异 。

**Gemini锐评**

[图像 38：待版权审查，原图保存在私有归档]

**“AI时代教育的最大鸿沟，不再是谁买不起电脑，而是谁更不敢向机器提问。”**

这篇文章用极具反差感的数据揭开了一个经常被忽视的盲区。我们在做教育游戏时，总在担心“学困生”会不会被复杂的AI系统劝退。但结果狠狠打脸：Lara这款代理在跨越“先验知识、性别、年龄”的鸿沟上做得极其完美，真正的拦路虎居然是学生“对AI的防御态度”和“自身的游戏动机类型”！

最讽刺也最精妙的地方在于，这套系统被刻意加上了“社交属性”和“同理心（Empathy）”，其目的不仅是为了让交互更好玩，更是作为一种“心理脚手架”去安抚学生在面临商业模拟破产时的焦虑。当算法被锁在冰冷的评价机制里时，它只会制造“唯分数论”的焦虑；但当算法被 CAIS-GBL 框架赋予了FeedForward（向前看）的耐心和不带有色眼镜的共情时，它才真正具备了作为“虚拟赛博良师”的资格。教育游戏的尽头，终究是一场关乎人性与信任的设计。
