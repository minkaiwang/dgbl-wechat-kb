**摘要**

[图像 05：待版权审查，原图保存在私有归档]

元宇宙的应用之一是创建用于培训的数字孪生。本研究分析了其在塑料注塑成型中的应用，作为一种强大的教育工具，它能够虚拟复制从模具准备到最终产品的整个制造过程。基于传统技术和工业培训的经验，研究假设该技术将有助于提高实践学习和理论理解，而不依赖昂贵的物理设施或造成材料浪费。为此，研究团队创建了一台塑料注塑机的 3D 副本（数字孪生），学生可以通过调整模具和材料温度、注射速度、压力、冷却时间等参数进行交互。这种交互允许学生在不使用物理机器的情况下，直观看到参数调整对最终产品的直接影响。结果表明，这是一种深度的体验式学习，学生可以在零风险、零浪费的环境中进行实验并从错误中学习。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

- **替代性：**基于元宇宙的数字孪生模拟器能否作为昂贵物理设备的有效替代或补充，用于复杂的工业操作培训？
- **体验感：** 学生在虚拟环境中的沉浸感（Presence）和易用性（Usability）如何？
- **教学价值：** 这种虚拟培训能否有效帮助学生理解注塑成型的复杂参数逻辑（如温度、压力与产品质量的关系）？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

塑料注塑行业需要高技能人才，但传统培训面临巨大挑战：机器昂贵、操作危险（高温高压）、原料浪费严重。新手在真机上试错的成本太高。工业 4.0 时代，数字孪生技术允许我们在虚拟空间创建一个与物理实体完全一致的模型。结合元宇宙的沉浸感，这为工程教育提供了新范式：在虚拟世界里“炸机”不要钱。本研究旨在验证这种高保真虚拟培训系统的可行性和有效性。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

- **元宇宙与工业：** 讨论了元宇宙不仅仅是社交，更是工业模拟的平台。引用 Grieves 的定义，强调数字孪生是物理系统的虚拟镜像。
- **VR在培训中的优势：** 相比传统视频或PPT，VR提供“做中学”的体验，能显著提高技能保留率。
- **注塑成型的特殊性：** 这是一个多参数耦合的复杂过程，非常适合利用计算机模拟来展示“参数-结果”之间的非线性关系。

[图像 12：待版权审查，原图保存在私有归档]

**3. 环境设计**

[图像 13：待版权审查，原图保存在私有归档]

这就不是一个简单的游戏，而是一个工业级仿真器。

**开发引擎：** Unity 3D。

**硬件设备：** Meta Quest 2 头显（提供6DoF自由度）。

**核心资产——注塑机数字孪生：**

- 团队高精度建模了一台真实的工业注塑机。
- 交互面板： 虚拟机器上的控制面板与真机一致，学生可以用虚拟手按下按钮、旋钮。

**核心玩法——参数调试与后果模拟：**

- 参数设置： 学生需要设置 注射温度、模具温度、注射压力、保压时间、冷却时间 等关键工艺参数。
- 物理反馈逻辑： 系统后台运行着注塑成型的物理算法。

  如果你温度设太低 -> 虚拟产品会出现“短射（Short Shot）”（缺料）。

  如果你压力太大 -> 虚拟产品会出现“飞边（Flash）”（毛刺）。

  如果你冷却太短 -> 虚拟产品会“翘曲变形”。
- 所见即所得： 学生取出虚拟零件时，能立即看到自己设置的参数导致了什么样的质量缺陷。

**设计亮点：** 它不仅仅模拟了“操作流程”，更模拟了“错误后果”。在现实中，制造出一堆废品会被老板骂，但在元宇宙里，制造废品是学习的最佳途径。

**4. 方法与实验**

[图像 26：待版权审查，原图保存在私有归档]

**参与者：**22名 材料工程硕士学位的学生（他们有一定的理论基础，但缺乏实操经验）。

**实验流程：**

- 理论导入（1小时）： 讲解注塑原理。
- 元宇宙实训： 学生佩戴头显，在虚拟工厂中操作注塑机。任务是生产一个完美的塑料杯，并尝试调整参数观察缺陷。
- 问卷评估： 体验结束后，填写基于 SUS（系统易用性量表） 和 Witmer & Singer 存在感量表 改编的问卷。

**评估维度：**易用性、沉浸感、视觉真实度、学习效能感。

**5. 结果**

[图像 30：待版权审查，原图保存在私有归档]

1. **极高的易用性：** 尽管工业机器很复杂，但 VR 系统的操作被评为非常直观。SUS 评分显示系统处于“优秀”区间。
2. **强烈的临场感：** 问卷中“我感觉我就在工厂里”这一项得分极高。学生表示，沉浸式环境让他们专注于操作，忘记了外部世界。
3. **学习信心提升：** 学生普遍反馈，经过虚拟训练后，他们对操作真实机器“更有底气了”。
4. **零成本试错：** 实验过程中产生了很多次“参数设置错误”，但这没有消耗一粒塑料米，也没有占用真实的机器工时。

**6. 讨论与总结**

[图像 34：待版权审查，原图保存在私有归档]

- **教育价值：** 数字孪生成功地将抽象的工艺参数（如 200°C vs 220°C 的区别）转化为了直观的视觉反馈（产品好坏）。
- **安全与环保：** 彻底消除了高温烫伤风险和塑料废弃物，符合绿色制造的理念。
- **局限性：** 目前缺乏触觉反馈（Haptic Feedback）。学生摸不到塑料件的温度，也感觉不到合模的震动，这在一定程度上削弱了真实感。

**教学启示**

[图像 36：待版权审查，原图保存在私有归档]

**👩‍🏫 对教师的教学启示**

- 作为“上机证”： 以后进实验室操作真机前，要求学生必须先在元宇宙里“通关”。这样可以大幅减少真机的维护成本和教学风险。
- 展示“反面教材”： 在虚拟环境里，故意演示错误的参数设置（如极高压），让学生看看机器“爆炸”或产品严重变形的样子，这在现实课堂是不可能做到的。

**🏫 对学校的启示**

- 虚拟实训中心： 职业院校和理工科大学应考虑建设“元宇宙实训室”。一套软件可以无限复制，解决大型设备“人多机少”的痛点。
- 远程教育： 这种系统可以打包发给学生，让他们在家用 VR 头显就能完成实训课作业。

**🎨 对游戏设计师的启示**

- 硬核模拟的魅力： 对于职业类严肃游戏，不要搞花哨的 UI 和积分。物理逻辑的真实性才是核心游戏性。让玩家通过调整参数获得完美产品，这种成就感不亚于打怪升级。
- 错误可视化： 设计重点不仅是“怎么做对”，更是“做错了会怎样”。把错误的后果（如产品缺陷）做得越逼真，教育效果越好。

**🔬 研究者如何复现？（Replication Guide）**

- 技术门槛： 复现该研究需要 Unity 开发能力和 CAD 机械建模能力。
- 改进实验设计： 本研究样本量较小（22人）且无对照组。未来的研究可以设置“元宇宙组 vs 传统视频组 vs 真机操作组”，对比三组的学习迁移效果和成本效益。

**Gemini锐评**

[图像 38：待版权审查，原图保存在私有归档]

这篇文章是职业教育数字化转型的一个缩影。

1. **极其务实：** 没有空谈“元宇宙”的概念，而是直接解决工业培训中的“贵、险、难”三大痛点。这种应用型研究是目前最缺的。
2. **概念混淆的嫌疑：**虽然题目叫“数字孪生（Digital Twin）”，但文中描述的系统似乎并没有与物理机器进行实时数据连接（Real-time data link），更像是一个“高保真仿真器（Simulation）”。真正的数字孪生应该能实时反映物理机器的状态。这一点在学术定义上略显不严谨。
3. **数据单薄：**只有 22 个样本，且全是主观问卷。缺乏客观数据（如：虚拟训练后的学生在真机上的操作失误率是否真的降低了？）。如果能补充这部分数据，文章的含金量将大增。
