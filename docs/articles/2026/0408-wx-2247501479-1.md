What do medical oncologists want for themselves at the end-of-life? Analysis of Go Wish Cards Game

**摘要**

[图像 06：待版权审查，原图保存在私有归档]

尽管讨论临终（EoL）价值观和优先事项对于以人为本和有尊严的护理至关重要，但在肿瘤学领域，这仍然是一个巨大的挑战 。本定性研究纳入了来自两家巴西癌症中心的49名参与者（31名临床肿瘤学家和18名肿瘤学住院医师） 。通过《Go Wish》卡牌游戏（GWCG），参与者从自身的临终价值观和优先事项出发，选择并讨论了对他们最有意义的卡牌 。研究结果揭示了五个主题类别，并发现两组医生在选择上存在显著差异：临床肿瘤学家优先考虑“有家人和朋友在身边”，而住院医师则强调“缓解疼痛和呼吸急促” 。研究表明，这款游戏能有效促进医学专业人士的伦理和存在主义反思，是一种极具潜力的临床肿瘤学教育和敏化工具 。

[图像 07：待版权审查，原图保存在私有归档]

**研究问题**

[图像 08：待版权审查，原图保存在私有归档]

- 通过体验《Go Wish》卡牌游戏，临床肿瘤学家和肿瘤学住院医师如何看待他们个人的临终价值观和优先事项？
- 他们对该工具在肿瘤学临床实践中的作用和适用性有何反思？

[图像 09：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 10：待版权审查，原图保存在私有归档]

临终（EoL）护理是肿瘤学的核心组成部分，需要医疗专业人员将技术专长与强大的沟通技巧相结合 。然而，由于情绪上的不适以及“治愈优于安慰”的生物医学文化，关于死亡的对话经常被回避 。肿瘤科医生在面对治疗限制和患者自主权时，常常会产生道德困境和情绪困扰 。大多数关于临终沟通工具（如《Go Wish》游戏）的研究都集中在患者和家属身上，很少有人研究参与这种游戏如何影响医生自己的临床态度和对生命有限性的敏感度 。

[图像 11：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 12：待版权审查，原图保存在私有归档]

- **沟通的障碍：**许多肿瘤科医生在讨论死亡、预后和护理偏好时缺乏安全感，害怕给患者带来情绪困扰 。这种对死亡的回避行为会损害医生的同理心，降低沟通质量 。
- **现有的沟通工具：**目前已有问题提示列表（QPLs）、决策辅助工具以及SPIKES和NURSE等结构化沟通框架 。
- **基于价值观的反思工具：**近年来，像《Hello Game》和《Go Wish》卡牌游戏这样的基于价值观的工具开始崭露头角，它们旨在帮助人们识别在生命尽头什么才是最重要的 。将这些工具用于医学教育，可以使医疗培训从严格的技术逻辑转向更加对话、注重关系的以人为本的实践 。

[图像 13：待版权审查，原图保存在私有归档]

**3. 环境设计**

[图像 14：待版权审查，原图保存在私有归档]

《Go Wish》是一款专为临终关怀沟通设计的物理桌游（卡牌游戏） 。它的机制非常简单但直击心灵：

**卡牌内容：**游戏包含36张卡牌，每张卡牌上都写有一项与临终价值观或优先事项相关的陈述（例如：“保持我的尊严”、“有家人和朋友在身边”） 。

**核心机制（强制排序）：**在研究中，医生被要求代入自己，将这36张卡牌分类放入三个不同颜色的信封中 ：

- 绿色信封（非常重要）：限制只能放入10张卡牌 。
- 黄色信封（有点重要）：放入10张卡牌 。
- 红色信封（不重要）：放入剩余的16张卡牌 。

**机制的意义：**这种“限制数量的优先级排序”机制，强迫玩家在多个都看似重要的价值观（如“不痛”和“家人陪伴”）之间做出艰难的取舍，从而直面内心的真实诉求。

**4. 方法与实验**

[图像 17：待版权审查，原图保存在私有归档]

**研究设计：**一项描述性定性研究，嵌套在一个更大规模的临床试验中 。

**被试群体：**49名巴西肿瘤科医生，包括31名经验丰富的临床肿瘤学家和18名肿瘤学住院医师（受训医生） 。

**实验流程（三个阶段）：**

- 卡牌分类：医生按照自己的真实想法，将卡牌分入三个信封 。
- 干预访谈（48小时后）：由两名独立研究人员进行半结构化访谈，专门针对医生选出的那10张“非常重要（绿色）”的卡牌进行深度讨论（例如：“当你选择这张卡牌时，你在想什么？”） 。
- 反馈评估（7天后）：询问医生是否会向患者推荐此工具及原因 。

**数据分析：**对录音和现场笔记进行转录，采用经典的Bardin内容分析法提取主题 。

**5. 结果**

[图像 20：待版权审查，原图保存在私有归档]

通过游戏，两组医生在“非常重要”卡牌的选择上出现了极其有趣的分歧：

- 临床肿瘤学家（老医生）的首选：“我希望家人和朋友在身边”（80.6%）；“我希望能说：谢谢、我爱你、对不起和再见”（77.4%） 。
- 肿瘤学住院医师（年轻医生）的首选：“我希望缓解疼痛和呼吸急促”（83.3%）；“我希望保持我的尊严”（61.1%） 。

研究提炼出医生们临终诉求的五个核心主题：

1. 症状控制和身体舒适（两组都极度重视，认为这是平静死亡的基础） 。
2. 尊严与自主权（年轻医生强调预先指示，老医生强调家属参与） 。
3. 人际关系和社会/家庭支持（老医生甚至特别提到了宠物陪伴的深层情感价值） 。
4. 灵性和存在主义问题（年轻医生偏向宗教仪式，老医生偏向对生命意义的广泛反思） 。
5. 沟通、遗产与反思（认为游戏本身就是促进这种沟通的绝佳工具） 。

**6. 讨论与总结**

[图像 22：待版权审查，原图保存在私有归档]

《Go Wish》卡牌游戏成功地激活了临床医生的“内心世界” 。研究揭示了一个深刻的现象：**随着专业经验的积累，医生对死亡的关注点会发生转移。**年轻的住院医师更关注生物医学和躯体层面（如疼痛控制），而经验丰富的肿瘤科医生则越来越关注关系的、情感的和存在主义的维度 。

将这款游戏作为自我反思的工具，不仅帮助医生明确了自己面临死亡时的优先事项，更重要的是，它打破了医生情感上的防御机制，极大地增强了他们倾听患者、理解多维度痛苦（包括精神和人际关系痛苦）的敏锐度 。

[图像 23：待版权审查，原图保存在私有归档]

**教学启示**

[图像 24：待版权审查，原图保存在私有归档]

- **👨‍🏫 对教师的启示（医学教育者）：**传统的医患沟通培训（如SPIKES协议）往往过于机械和刻板 。医学教育者应当引入像《Go Wish》这样的反思性游戏，让医学生在学习“如何通知坏消息”之前，先体验一次“如果我是临终者，我想要什么”的换位思考。
- **🏫 对学校的启示（医院/医学院）：**高强度的临床工作让医生极易产生情感倦怠。医院和住院医师培训项目应将这类游戏化反思活动纳入常态化的员工心理支持和同理心训练中（如巴林特小组讨论） 。
- **🕹️ 对游戏设计师的启示：**严肃游戏不一定非要依靠复杂的数字技术（如VR或AI）。《Go Wish》仅用简单的纸质卡牌和“分类与数量限制（10张）”的物理交互机制，就完美模拟了现实生活中的“资源与价值观权衡”。在设计心理健康或教育桌游时，“强制优先级排序”是激发玩家深度思考的黄金法则。
- **🔬 对研究者的复现建议：**这篇定性研究的设计非常严谨。未来的研究者在评估教育游戏时，可以借鉴其“游戏体验 -> 48小时沉淀 -> 深度访谈”的时间间隔设计，给玩家留出心理反思的缓冲期 。此外，使用Bardin内容分析法对游戏过程中的对话进行编码，是一种非常标准且有效的质性分析范式 。

**Gemini锐评**

[图像 26：待版权审查，原图保存在私有归档]

这篇文章的切入点堪称绝妙！它完成了一次极其深刻的“角色反转”。

在医疗语境中，医生通常是那个发号施令、询问患者“你需要什么”的权威角色。这层“白大褂”往往也成了他们屏蔽死亡焦虑的情感铠甲。而《Go Wish》游戏巧妙地卸下了这层铠甲，强迫医生面对他们每天都在处理，却从不敢在自己身上深思的问题：**“如果你躺在病床上，这36张牌，你选哪10张？”**

研究结果中“老医生选亲情，小医生选止痛”的对比更是令人动容。这说明医学教育不能仅仅停留在“控痛技术”上，终极的人文关怀是对生命联系的渴望。

这篇文献向我们证明了：最高级的教育游戏，不需要电竞级别的画面，不需要庞大的算力，**它只需要一套精准触及人类共同命运（如死亡、爱与尊严）的卡牌，以及一个促使你做出选择的机制**。 游戏化不仅可以用来学习知识，更可以用来“照见灵魂”。
