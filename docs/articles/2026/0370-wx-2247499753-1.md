Educational games for learning vocabulary in English as a Foreign Language

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

在当前的全球化背景下，英语作为标准交流语言的重要性日益凸显 。然而，将英语作为外语（EFL）学习的常见挑战是学生缺乏持久的参与度，导致学习进度不一致 。本研究探讨了一款虚拟现实（VR）游戏对EFL学习者英语词汇习得的影响 。该游戏模拟了一个厨房环境，要求用户在其中重现真实的食物食谱，这是一个跨文化共通的日常主题 。研究对40名参与者（均分为实验组和对照组）进行了测试 。前后测评估了词汇习得和听力理解，同时通过可用性问卷（UEQ）评估了VR系统的交互体验 。结果表明，实验组在词汇方面取得了显著进步（p值分别为0.02和0.01），而对照组的进步较为有限 。可用性测试显示了高水平的满意度和参与度，突显了VR工具作为EFL学习者词汇学习方法的巨大潜力 。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

- 整合VR和数字视频游戏（DVGs）是否能提高EFL学习者的词汇习得？
- 特定的日常生活环境是否能增强EFL学习者对词汇的记忆和实际应用？
- 沉浸式技术与极具吸引力的主题设计相结合，是否能提高学生在语言学习中的动机和参与度？
- 与传统学习方法相比，在语言学习环境中使用VR是否能增加学生的乐趣并降低焦虑？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

传统语言教学方法往往无法在整个学习过程中维持学生的兴趣 。虽然传统方法取得了一定成功，但它们缺乏维持学习动机所需的动态和参与元素 。引入诸如数字视频游戏和虚拟现实（VR）等变革性技术，可以为语言学习注入刺激感、互动性和沉浸感 。VR游戏（VRGs）允许学生在传统教室之外、语境丰富的环境中动态地与语言进行互动 。本研究旨在通过开发一款带有烹饪主题的VR严肃游戏，不仅将其作为辅助工具，更是作为语言学习策略的核心，来检验其在真实语境中应用语言技能的有效性 。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

- **自我决定理论 (SDT)：**游戏天然提供了锻炼控制力（自主性）、实现精通（胜任力）以及与游戏角色建立联系（归属感）的机会，从而激发内在动机 。
- **心流理论 (Flow Theory)：**当学生完全参与到难度适当的任务中时，会发生最佳学习 。
- 建构主义学习理论与双重编码理论 (Dual Coding Theory)：知识最好通过主动的、情境化的体验来建构（建构主义） 。结合口头语言和视觉元素（双重编码）能有效增强学习和记忆 。
- **设计干预策略：**本研究提炼了五大核心游戏化设计方法：语言沉浸（Linguistic immersion）、基于场景的学习（Scenario-Based Learning）、自适应模型（Adaptative Models）、引人入胜的叙事（Engaging Narrative）以及情境化反馈（Contextualized Feedback） 。

**3. 游戏设计**

[图像 14：待版权审查，原图保存在私有归档]

本研究使用Unity引擎开发，适配Oculus Quest 2等头显设备 。

**沉浸式厨房场景：**游戏设定在一个工业风格的大型仓库中，前方有三位评委的评委席，后方是包含多种厨具（烤盘、裱花袋、打蛋器等）的厨房以及包含食材的储藏室 。

**核心玩法与难度自适应：**玩家需要选择真实的食谱（如姜饼人或巧克力豆饼干）进行制作 。游戏包含三种难度：

- 简单模式 (Easy)：提供极其详细且按步骤的指令（如“将巧克力豆加入大碗中的面团里”） 。
- 普通模式 (Normal)：指令细节减少（如“混合面团材料”），需要玩家进行程序性推理 。
- 困难模式 (Hard)：引入时间限制，考验玩家在压力下的准确性和效率 。

**趣味化评估机制（评委小游戏）：**烹饪完成后，玩家需将菜品呈给评委 。三位评委分别主持三个迷你游戏（Mini-games）：完成语境句子、识别单词复数形式、选择正确的冠词 。这种设计将枯燥的语法和拼写测试无缝嵌入了游戏的“评审环节”中 。

**4. 方法与实验**

[图像 17：待版权审查，原图保存在私有归档]

**研究对象：**40名未在日常生活中频繁使用英语的EFL学习者（22-32岁），随机均分为实验组（VR游戏组，20人）和对照组（纸质材料组，20人） 。

**实验流程：**

- 前测：所有参与者完成词汇和听力测试 。
- 干预：实验组在“普通难度”下使用VR完成巧克力豆饼干的烹饪任务；对照组使用传统纸质材料学习完全相同的烹饪词汇和指令 。两组均由同一位导师指导以控制变量 。
- 后测：完成相同的词汇和听力测试 。

**测量工具：**

- 图片词汇测试（20题）：看图选择对应的烹饪工具/食材英语单词 。
- 听力理解测试（20题）：听取游戏/材料中出现过的原句录音并作答 。
- 用户体验问卷（UEQ）：仅实验组填写，评估游戏的吸引力、新颖性、效率和刺激度 。

**5. 结果**

[图像 20：待版权审查，原图保存在私有归档]

- **词汇习得成绩显著提升：**实验组的词汇正确率从前测的73.5%大幅飙升至后测的86.0% (p=0.02) ；而传统纸质对照组仅从72.5%微升至79.0% 。
- **听力理解能力增强：**实验组的听力正确率从75.5%提升至88.0% (p=0.03) ；对照组仅从74.5%提升至82.0% 。VR组在两项技能上均跑赢了传统学习组 。
- **极高的可用性与极低的学习焦虑：**UEQ数据证实，VR环境的高互动性不仅维持了极高的参与动机（刺激度），还通过愉悦的操作体验显著降低了外语学习特有的焦虑感，创造了一个“无压力”的学习环境 。

**6. 讨论与总结**

[图像 27：待版权审查，原图保存在私有归档]

本研究用翔实的数据证明，VR游戏干预能有效提高EFL教育中的词汇习得效率 。这种基于真实世界场景（烹饪）的沉浸式设计，巧妙利用了“双重编码（视觉+听觉反馈）”，让学生将抽象的单词与具体的物理动作（抓取、搅拌）绑定在一起，从而加深了长时记忆 。与传统的死记硬背相比，VR不仅提高了成绩，更重要的是它提供了一个安全、有趣的试错空间，大幅缓解了语言学习的焦虑 。尽管存在样本量较小、干预时间较短等局限性，但VR作为现代语言教学核心策略的潜力已不容忽视 。

**教学启示**

[图像 29：待版权审查，原图保存在私有归档]

**对教师的教学启示：**语言学习最大的痛点是“脱离语境的死记硬背”。教师应尽量创设“任务驱动型”的语言应用场景。如果条件允许，利用VR模拟真实的超市购物、餐厅点餐或厨房烹饪，让学生在“做中学”，通过肢体动作强化词汇记忆，能有效降低学生的“外语开口焦虑”。

**对学校的启示：**学校可以考虑在语言实验室引入如Oculus Quest等高性价比的独立VR头显 。将传统的词汇听写测试，部分转化为VR环境下的互动任务考核，真正实现“教、学、评”的一体化创新。

**对游戏设计师的启示：**

- 巧妙包装测试：本研究最精妙的设计之一，是将原本枯燥的“语法和拼写测试”包装成了“厨艺评委点评”的迷你游戏 。设计师在教育游戏中应避免生硬地弹出考试界面，而是将其融入游戏世界观的叙事中。
- 认知负荷管理（自适应难度）：UI指令必须分层。从新手期“保姆级”的图文并茂提示，到熟练后仅保留关键动词，再到引入倒计时压力，这种“褪除脚手架”的设计非常符合认知发展规律 。

**研究者如何复现内容和实验：**

- 未来的研究需要拉长干预周期（Longitudinal study），探究这种VR新奇效应（Novelty Effect）消退后，词汇记忆的长期保持率 。
- 除了“听”和“读”，未来的VR语言游戏实验应当利用大语言模型（LLM）或语音识别技术，将重点拓展到“口语表达（Speaking）”与NPC的实时语音交互上 。

**Gemini锐评**

[图像 31：待版权审查，原图保存在私有归档]

“别让语言死在课本里，把它扔进虚拟厨房的锅里炒一炒！”

这篇文章狠狠地戳中了一个语言教学的常识痛点：单词不是背出来的，是用出来的。传统的英语课本教你 "whisk"（打蛋器），你只能在脑子里勾勒一个抽象的金属网；但在VR的虚拟厨房里，你必须亲手抓起它去疯狂搅拌虚拟的面糊。这种通过肢体具身交互带来的“肌肉记忆”，是任何精美的纸质教材都无法比拟的降维打击！

更有趣的是，这篇论文给所有的教育游戏开发者上了一堂“如何优雅地考试”的课。把考试做成“评委试吃打分”，不仅没有破坏游戏的沉浸感，反而把玩家的胜负欲拉满了。技术终究是壳，把枯燥的语言规则无缝编织进真实的生活叙事中，才是数字游戏化学习能真正打动学习者（并且顺便拿高分）的核心密码！
