Biomedical signals acquisition methodology for emotion classification in virtual reality game environment

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

作为一种互动媒体，游戏为创作者提供了动态响应玩家行为的独特机会 。如果游戏能够识别玩家的情绪状态，将为游戏设计开辟创新的途径 。现代虚拟现实（VR）技术的出现引入了一系列新信号，VR系统通过头显、手柄以及用户在虚拟环境中的交互，生成了丰富的运动和位置数据 。这些空间数据为通过分析玩家的运动和姿势（这些通常随情绪状态而变化）来推断玩家的情绪状态提供了新机会 。本研究的主要目标是开发一种在玩VR游戏时采集生物医学信号的方法，并特别关注情绪的诱发机制 。研究开发了一款包含4个不同迷你游戏的VR应用程序，并使用现成的InceptionTime网络模型进行情绪时间序列分类 。结果证明了该方法的有效性，并指出了在VR游戏语境下情绪分类的复杂性 。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

- 如何在不使用额外侵入式生物医学传感器（以免破坏沉浸感）的情况下，仅利用VR设备自带的标准化输入（头显、手柄空间数据及眼动数据）来采集玩家的生理/行为信号？
- 如何在VR游戏环境中设计标准化的情绪诱发刺激（听觉、视觉、色彩），以确保在进行“独立于主体（Subject-independent）”的深度学习模型训练时数据的可靠性？
- 基于时间序列深度学习网络（InceptionTime），VR运动数据在多类别（4类）与二分类（唤醒度/效价）情绪识别任务中的表现如何？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

电子游戏一直与情绪的诱发紧密相连，人们玩游戏的主要动机之一就是体验包括快乐、兴奋甚至面对挑战时的挫败感和愤怒等一系列情绪 。如果游戏内的NPC能够根据玩家当前的沮丧或愤怒情绪动态改变互动方式，或者游戏机制能自动调整难度以适应玩家的情绪状态，那将带来前所未有的个性化沉浸体验 。然而，以往依赖纯摄像头数据的传统平台受限于算力和设备 。如今，VR技术提供了标准的头显和双控制器空间数据，这让我们能够通过捕捉玩家“随情绪而下意识改变的肢体动作与姿态”来精准推断其心理状态 。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

情感计算领域已经存在如 MAHNOB-HCI、VREED、WESAD 和 DEAP 等多个标准化情绪数据集，它们通常依赖脑电图（EEG）、心电图（ECG）、皮电活动（EDA）等传统生理信号 。然而，这些研究大多面临两个痛点：一是“依赖特定主体（Subject-dependent）”，即模型换个人就不准了，缺乏普适性 ；二是研究通常在实验室环境下进行，要求玩家佩戴各种繁琐的医疗传感器，这在VR游戏中会严重破坏玩家的沉浸感并干扰真实情绪的产生 。因此，亟需一种无侵入式的VR原生信号采集与分类方法论。

[图像 12：待版权审查，原图保存在私有归档]

**3. 游戏设计**

[图像 13：待版权审查，原图保存在私有归档]

研究团队利用Unity引擎开发了一款专用的VR测试应用，硬件采用带有眼动追踪功能的 HTC Vive Pro Eye 。

**情绪诱发机制（Stimulus）：**基于罗素的环形情绪模型（唤醒度 Arousal vs. 效价 Valence） 。在游戏前后及游戏过程中，系统会调用来自标准数据库（如IADS-E音频库、IAPS图片库）的360度全景视频、声音和特定场景颜色，精准诱发玩家的特定情绪（如放松、愤怒、恐惧等） 。

**四款代表性迷你游戏：**为了覆盖绝大多数主流VR游戏机制，团队设计了4个玩法极其简单（避免增加认知负荷）的迷你游戏 ：

- 射击打靶 (Shooting Range)：第一人称射击，玩家使用手柄瞄准并射击随机目标，包含装弹动作 。
- 水果忍者 (Fruit Slasher)：街机动作类，玩家挥舞虚拟剑切开飞来的水果，并躲避炸弹 。
- 躲避走廊 (Dodge Hall)：物理移动类，玩家必须通过身体移动来躲避迎面而来的墙壁障碍 。
- 金字塔解谜 (Pyramid Puzzle)：空间逻辑解谜，玩家需指出一条连续的路径 。

**4. 方法与实验**

[图像 18：待版权审查，原图保存在私有归档]

**实验对象与流程：**招募了30名参与者（10名女性，20名男性，年龄18-44岁） 。玩家在体验各个诱发特定情绪的迷你游戏时，系统以200Hz的频率在后台静默记录数据 。

**提取的“无感”生物医学信号 ：**

- 头显的3D位置（x, y, z）及3D旋转朝向（四元数）。
- 左右手柄的3D位置及旋转朝向。
- 左右眼的2D瞳孔位置（眼动追踪）。

**数据处理与模型：**研究不仅使用了原始的位置数据（记为 d0 集合），还提取了它们的一阶导数，即线速度和角速度（记为 d1 集合） 。为了确保模型是“独立于主体”的，训练集（27人）和测试集（3人）严格按照玩家ID进行物理隔离划分 。最后输入专门处理多变量时间序列的 InceptionTime 深度学习网络进行训练 。

[图像 19：待版权审查，原图保存在私有归档]

**5. 结果**

[图像 20：待版权审查，原图保存在私有归档]

- **四分类任务表现不佳：**在尝试将情绪精确划分为4个象限（如同时区分高唤醒/正效价与低唤醒/负效价）时，准确率仅为 0.4681–0.5929，表现不尽如人意 。
- **二分类任务表现优异：**当仅对“唤醒度（兴奋vs放松）”或“效价（积极vs消极）”进行二元分类时，准确率大幅提升至 0.5954–0.8298 。最佳成绩出现在使用 d1（速度/角速度）数据集预测唤醒度时，准确率高达 82.98% 。
- **“速度”比“位置”更懂情绪：**实验证明，相比于原始的位置坐标，基于导数计算出的肢体运动速度和头部转动角速度（d1集），在情绪分类任务中效果显著更好 。
- **全局数据优于切片数据：**输入完整的游戏过程信号（all）比切分成800个采样点的窗口数据获得了更高的准确率，说明情绪信息在整体连贯的动作中体现得更明显 。

**6. 讨论与总结**

[图像 24：待版权审查，原图保存在私有归档]

即便对于人类而言，完美识别他人的情绪也是极其困难的，更何况是机器 。然而，本研究证实了：**在完全不使用繁琐医疗传感器的情况下，仅靠VR设备的头显、手柄轨迹和眼动数据，通过捕捉线速度和角速度，就足以对玩家的“唤醒度（兴奋或放松）”进行高准确率的分类** 。虽然细粒度的4分类还有待优化，但这种二分类的成果对于游戏设计已经具有巨大的实战价值 。未来还可以结合具体游戏场景的上下文，或引入非侵入式的智能手表（如心率/皮电）来进一步提升多模态识别的精度 。

**教学启示**

[图像 26：待版权审查，原图保存在私有归档]

**对教师的教学启示：**在未来的VR教育元宇宙中，教师无需时刻询问学生的感受。系统后台完全可以通过捕捉学生头部的转动频率、握持手柄的微小颤动或移动速度，来自动判断他们当前是处于“心流（高唤醒）”状态，还是已经“无聊/受挫（低唤醒）”，从而为教师提供实时的学情预警。

**对学校的启示：**学校在开展教育神经科学或心理健康相关研究时，不一定非要采购昂贵的医疗级脑电波（EEG）设备。现代商业VR头显（自带眼动追踪）所产出的运动学时间序列数据，配合深度学习算法，本身就是一座巨大的“心理生理学数据矿山”。

**对游戏设计师的启示：**

- 情绪化动态难度调节（DDA）：不要执着于精确识别玩家是“悲伤”还是“恐惧”。研究表明，只要能准确识别出玩家处于“高唤醒的负面状态（如狂躁/极度受挫）”，系统就可以立刻暗中降低怪物血量或掉落补给，这足以大幅优化心流体验 。
- 关注“速度”而非“姿势”：在做行为数据埋点时，不要只记录玩家“站在哪里”，一定要计算出他们移动和挥舞手柄的“线速度与角速度”，因为人在紧张或兴奋时，动作的爆发力（加速度）是骗不了人的 。

**研究者如何复现实验：**

- 严格的主体隔离：在划分训练集和测试集时，千万不要先把所有数据打碎再按比例分（这会导致数据穿越）！必须严格按照“玩家ID”进行切分，用这27个人的数据训练，去预测另外没见过的那3个人，这样验证出的模型才具有泛化能力 。

**Gemini锐评**

[图像 28：待版权审查，原图保存在私有归档]

**“你以为你在玩VR，其实是VR在给你‘看相’。”**

这篇文章漂亮地踢开了传统情感计算的“绊脚石”——那些贴满玩家脑门和胸口的电极片。它向我们揭示了一个非常赛博朋克的真相：在VR世界里，你的身体是不会撒谎的。当你面对突如其来的怪物时，你头部那零点几秒的微小后仰、你手柄挥舞时瞬间增加的角速度，早就把你的恐惧和兴奋出卖给了深度学习网络。

虽然AI目前还分不清你是“感动”还是“开心”（四分类失败），但它已经能极其精准地闻出你是不是“上头了”（82.98%的唤醒度准确率）。未来的教育游戏，不再是你按键告诉系统你想干什么，而是系统通过你的肢体语言，提前预判你需要什么。这不仅仅是交互方式的革命，这是数字世界对人类心理防线的“降维打击”！
