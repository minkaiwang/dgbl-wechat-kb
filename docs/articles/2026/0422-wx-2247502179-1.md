▶ 摘要

本研究为**准实验对照试验**，探讨多人游戏 **Fortnite** 的可定制虚拟空间如何作为**元宇宙语言教学（MBLT）**环境，支持土耳其高中生 EFL 词汇学习。理论框架整合**自我决定理论（SDT）**与**活动理论**。

N = 81（实验组 41 / 对照组 40）：实验组在自定义虚拟商场「Diamond Shopping Mall」中完成 8 节×2 小时线上词汇课（共 80 词）；对照组接受相同目标的传统纸面课堂。结果显示：实验组**词汇增益显著更高**（t = 11.83, p < .001, d = 1.20）；**焦虑降幅更大**（U 检验 p < .001, r = 0.53）；**动机提升更大**（p < .001, r = 0.73）；学术任务参与为中等偏上，**认知参与最高**（M = 5.62/7）。

▶ 任务目标

- ▶ **RQ1**：Fortnite MBLT 是否提升 EFL 购物情境词汇成绩？
- ▶ **RQ2–3**：是否降低外语课堂焦虑、提高学习动机？
- ▶ **RQ4**：MBLT 过程中认知、行为、情感三维学术参与水平如何？

LV.01 介绍

虚拟学习环境（VLE）正在改变语言教与学的方式。**元宇宙**指由 VR 或屏幕端 3D 空间构成的沉浸式数字场域，支持互动与共在感，已被用于化学、数学、解剖与语言教学，并催生**元宇宙语言教学（MBLT）**这一新兴取向。

对 Z 世代学习者而言，在线多人游戏环境可提供课堂外的自主、社交与动机支持。SDT 强调**自主、胜任与关系**三种基本心理需求；活动理论则把学习视为在工具、规则与共同体中介下的目标导向活动。

外语焦虑（FLA）是 MBLT 的重要情感障碍；头像化、低压力社交情境可能缓解「怕犯错、怕评价」。本研究选择 Fortnite 因其可定制岛屿与社交玩法，在土耳其私立高中开展对照实验。

LV.02 文献综述

**MBLT 与 Fortnite：**MBLT 中学习者以化身在结构化 3D 世界中开展有意义的社会互动。既有研究提示 MBLT 可改善发音、降低焦虑、促进跨文化沟通，但也报告可及性与稳定性挑战。Fortnite 教育应用多聚焦 21 世纪技能，针对**词汇、焦虑、动机与参与**的综合实证仍较少。

**理论整合：**SDT 解释内在动机与参与；活动理论将 Fortnite 商场视为中介工具，重塑课堂活动系统（主体—工具—规则—共同体—对象）；情境学习强调在真实交际场景中建构意义。FLA 理论将焦虑作为影响参与的情感条件纳入框架。

研究缺口在于：沉浸式元宇宙环境如何在**同一设计**中同时考察词汇习得、动机、焦虑与多维学术参与，尤其缺少以 Fortnite 类社交游戏为载体的准实验证据。

**MBLT 环境 · Diamond Shopping Mall：**使用 Fortnite 用户创建的自定义岛屿（地图代码 **5581-8763-0702v1**），含超市、服装店、餐厅、书店、图书馆、音乐店等，PEGI 3 分级。学生以化身漫游、角色扮演与探索完成词汇任务。

**课程结构（2 周 / 8 课 × 2 小时 / 80 词）：**① 商场基础词汇；② 超市；③ 服装店；④ 餐厅点餐角色扮演；⑤ 书店；⑥ 音乐店；⑦ 咖啡馆健康与口味讨论；⑧ 综合复习。每课围绕 Nation 词汇学习「四链」与深度加工，在接收—产出—生成中重复词族。

**SDT 设计：**自主——自由逛商场与选择任务顺序；胜任——渐进挑战与角色扮演即时反馈；关系——结对协作（按座位配对以降低社交焦虑）。

**活动系统设计：**对象 = 词汇习得；工具 = 英语 + MBLT 环境 + 同伴互动；规则 = 任务说明与游戏机制；共同体 = 实验组班级。活动包括观察、讨论、角色扮演与反思。

**对照组：**同一教师、相同 8 课目标与词表、同样 2 周时长，但采用**纸质练习**（匹配、填空、书面反思），无元宇宙体验。干预结束后也向对照组补开 MBLT 课以避免学习不公。

★ LV.04 方法和实验 ★

**设计：**准实验前后测；集群随机（9–11 年级各 A/B 班抛硬币分配），实验 n=41、对照 n=40。年龄 14–16 岁，CEFR 以 B1 为主（组间分布无显著差异，χ² = 0.87, p = .648）。实验组自报元宇宙经验略高，但后续 Spearman 相关显示**游戏熟悉度与增益无关**（|ρ| ≤ 0.15）。

**工具：**20 题购物情境词汇测验（100 分）；S-FLCAS 外语焦虑短量表（α = .855）；ELLMS 青少年英语学习动机量表（α = .837）；Comp-TA 学术参与量表（仅实验组，前缀「在元宇宙中…」，α = .831）。

**分析：**词汇增益——独立样本 t 检验；焦虑与动机增益——Mann–Whitney U（非正态）；参与——描述统计。α = .05。

伦理：大学伦理委员会批准（222246），校方许可与家长知情同意。实验组需安装 Epic Games Launcher 与 Fortnite。

**RQ1 词汇：**实验组增益 M = 22.56（SD = 10.67）vs 对照组 M = 8.38（SD = 12.91），t(79) = 11.83, p < .001，Cohen's d = 1.20（大效应）。

**RQ2 焦虑：**实验组焦虑降幅更大（M = −0.37 vs 对照 +0.05），U = 319, z = −4.77, p < .001, r = 0.53, Cliff's Δ = −0.61。

**RQ3 动机：**实验组动机增益显著更高（M = 0.82 vs 0.04），U = 126, z = −6.58, p < .001, r = 0.73。

**RQ4 参与（仅实验组，7 点量表）：**认知参与 M = 5.62（最高）；行为 M = 5.05；情感 M = 4.98；总体 M = 5.21。整体为中等偏上，认知维度最为突出。

| 结果 | 实验组 | 对照组 | 效应 |
| --- | --- | --- | --- |
| 词汇增益 | 22.56 | 8.38 | d = 1.20\*\*\* |
| 焦虑变化 | ↓ 更大幅度 | 几乎不变 | r = 0.53\*\*\* |

综上，Fortnite MBLT 在词汇、情感与动机上均优于传统纸面教学，且学习过程中保持较高认知投入。

LV.06 讨论与总结

结果支持：游戏化元宇宙可为数字原住民提供**低焦虑、高动机、高参与**的词汇学习情境。虚拟商场将词汇嵌入「逛店—点餐—选书」等具身任务，符合情境学习与活动理论预测。

作者讨论头像带来的心理安全、结对降低评价恐惧、以及 SDT 需求满足。局限包括：单校、准实验无法完全排除选择偏差；实验组元宇宙经验基线略高；参与数据仅来自实验组；未追踪长期保持；依赖网络、设备与 Fortnite 平台稳定性。

对数字游戏学习研究的启示：**商业游戏平台 + 教师定制岛屿** 可作为低成本 MBLT 路径，但需与课程目标、词表与形成性评价严格对齐，并关注可及性与数字鸿沟。

★ 教学启示

■ 对教师

若试点 MBLT：先选**与单元主题匹配的虚拟场景**（如商场、机场），明确 8–10 个可观察的产出任务（角色扮演脚本、结对问答）。课前测试网络与账号；按熟悉度配对降低焦虑。不要只让学生「逛地图」——每站必须有词汇加工任务与反思问题。

■ 对学校

需评估设备、带宽、家长对商业游戏的接受度与年龄分级；制定数据与在线安全规范。集群分班随机可减少班级差异；干预后可为对照班补开体验以保公平。将 Fortnite 等平台写入「数字素养 + 语言」跨学科方案时需伦理审批。

■ 对游戏设计师

设计元宇宙语言任务时同步满足 SDT 三需求：可选路径（自主）、清晰层级挑战与即时反馈（胜任）、协作 NPC/真人互动（关系）。避免纯观光；用「任务—词汇—反思」三步闭环。教育游戏研究者可开源岛屿代码与课表（本文提供地图代码）以利复现。

■ 研究者复现

复现：N≥80，集群随机；前后测词汇测验 + S-FLCAS + ELLMS；实验组 2 周 MBLT（记录课时与词数）；对照组同等词表纸面活动。报告 t / U 与效应量；实验组加 Comp-TA。控制先验游戏经验并报告相关性。讨论中谨慎外推至非青少年或非 EFL 情境。

💬 锐评

这是把**Fortnite 直接搬进高中英语课堂**的对照研究，效应量大（词汇 d=1.2），对公众号读者很有话题性——但也要注意：实验组本身元宇宙经验就更高，尽管作者检验后称与结果无关。

亮点：理论（SDT + 活动理论）与任务设计（8 课商场主题）对应清晰，地图代码可复现，对照组内容公平。不足：仍是单校准实验、参与维度无对照、商业游戏依赖强。与 WMK 的 Minecraft 研究、Singh 的 Minecraft 元宇宙论文可形成「游戏平台 MBLT」对照阅读。

若你研究 DGBL 而非语言课：本文提醒——**平台选型 + 情境任务 + 情感变量** 应一起测量，别只盯成绩。
