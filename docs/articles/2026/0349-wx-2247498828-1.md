Integrating generative AI and the metaverse for cultural heritage: a case study on the preservation of Lamphun Brocade Fabric

**摘要**

[图像 06：待版权审查，原图保存在私有归档]

随着传统工艺的逐渐消逝，如何利用新兴技术保护非物质文化遗产（ICH）成为全球性挑战。本研究以泰国著名的南奔织锦（Lamphun Brocade）为例，开发了一个名为 “南奔织锦元宇宙（Lamphun Brocade Metaverse）” 的沉浸式学习平台。该研究创新性地将 生成式AI (ChatGPT-4o) 集成到元宇宙环境中，创造了一个能够进行实时语音交互的智能 “纺织策展人（Textile Curator）”。通过 SAM 模型进行开发，并对 400 名参与者进行了混合方法评估。结果表明，该系统不仅在用户体验（UEQ）的所有维度上均达到“优秀”水平，还显著提升了用户对织锦文化的知识掌握程度。这为文化遗产的数字化保护提供了一个可扩展的“AI+元宇宙”新范式。

**研究问题**

[图像 08：待版权审查，原图保存在私有归档]

- **技术融合：** 如何将生成式 AI（GenAI）与元宇宙环境有效整合，以创建一个互动的、智能的文化遗产学习空间？
- **效果评估：** 这种集成系统在提升用户知识水平、满意度以及用户体验（UX）方面的效果如何？

[图像 09：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 10：待版权审查，原图保存在私有归档]

泰国的创意经济在很大程度上依赖于其丰富的文化遗产，但著名的南奔织锦（Yok Dok）正面临传承危机：年轻一代缺乏兴趣，传统技艺后继无人。虽然现有的“虚拟博物馆”解决了物理访问的限制，但大多数仍是静态的（只能看说明牌），缺乏互动性。生成式 AI 的出现打破了僵局——它能让虚拟世界中的 NPC 像真人专家一样回答问题，提供个性化的导览服务。本研究旨在通过构建一个“活的”元宇宙博物馆，解决传统文化传播中的参与度低和互动性差的问题。

[图像 11：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 12：待版权审查，原图保存在私有归档]

- **元宇宙与文化遗产：** 讨论了元宇宙如何通过数字孪生（Digital Twin）技术，将濒危的物理文物（如织机、布料纹理）高保真地复刻到虚拟空间，实现“永恒保存”。
- **生成式AI在教育中的应用：** 传统的聊天机器人只能回答预设问题，而基于 LLM（大语言模型）的 GenAI 能够理解上下文，生成类似人类的对话，极大地提升了学习的沉浸感和个性化体验。
- **理论基础：** 本研究采用了 SAM（连续逼近模型） 进行敏捷开发，并结合建构主义学习理论，强调在虚拟环境中的主动探索。

**3. 环境设计**

[图像 15：待版权审查，原图保存在私有归档]

本研究构建的系统不仅仅是一个 3D 场景，其核心在于技术栈的整合。

开发平台：

- 前端： Spatial.io（一个支持多终端的元宇宙平台，易于访问）。
- 资产制作： Blender（3D建模）、Unity（交互逻辑）。
- AI 核心： OpenAI API (GPT-4o)。

**场景架构（四大区域）：**

- 历史区 (History Zone)： 展示南奔织锦的起源和皇家历史。
- 织造工艺区 (Weaving Process Zone)： 高精度复刻了传统的提花织机（Jacquard loom），用户可以近距离观察经纬线的交织结构（数字孪生）。
- 纹样识别区 (Identity Pattern Zone)： 展示特定的织锦纹样（如 Pikul 花），结合高清纹理贴图。
- 游戏测验区 (Quiz Game Zone)： 通过问答游戏巩固学习成果。

**核心创新 —— 智能策展人（AI Textile Curator）：**

- 形象： 一个身着传统泰式服装的 3D 虚拟人。
- 交互逻辑：

  语音输入： 用户通过麦克风提问（使用 OpenAI Whisper 模型进行语音转文字）。

  大脑处理： 文本发送给 GPT-4o，AI 根据预设的“南奔织锦知识库”生成专业回答。

  语音输出： 将 AI 的回答通过 TTS (Text-to-Speech) 转化为语音播放。
- 体验： 用户感觉自己在和一个博学的导游进行自然的语音对话，而不是在查搜索引擎。

**4. 方法与实验**

[图像 22：待版权审查，原图保存在私有归档]

**参与者：** 400名 参与者，包括游客、当地社区成员和大学生。

**开发模型：**SAM 模型（准备 -> 迭代设计 -> 迭代开发）。

**评估工具：**

- 知识测试 (Pre/Post-test)： 15道多项选择题，评估对织锦历史、工艺的了解。
- 用户满意度调查： 5点李克特量表。
- 用户体验问卷 (UEQ)：包含 26 个项目，涵盖吸引力、清晰度、效率、可靠性、刺激性和新颖性 6 个维度。

[图像 23：待版权审查，原图保存在私有归档]

**5. 结果**

[图像 24：待版权审查，原图保存在私有归档]

- **知识显著增长：** 配对样本 t 检验显示，参与者的后测成绩（Mean=13.45）显著高于前测成绩（Mean=6.82），p < 0.001。这证明了 AI 导览的有效性。
- **极高的满意度：** 总体满意度平均分为 4.63/5.00。其中得分最高的是“AI 策展人的回答准确且有用”。
- **卓越的用户体验 (UEQ)：** 在所有 6 个维度（吸引力、清晰度、效率、可靠性、刺激性、新颖性）上，该系统的得分均被评级为 “Excellent（优秀）”。特别是“新颖性”得分最高，说明 GenAI 的引入给用户带来了极大的惊喜。

**6. 讨论与总结**

[图像 27：待版权审查，原图保存在私有归档]

- **从“静态”到“动态”：** GenAI 的引入解决了传统虚拟博物馆内容僵化的问题。AI 可以根据不同用户的提问（是小学生还是专家）调整回答的深度，实现了真正的个性化教育。
- **数字孪生的价值：** 对复杂织机的 3D 复刻，让无法接触实物的年轻人也能直观理解复杂的纺织机械原理。
- **文化可持续性：** 该平台不仅是教育工具，还能作为旅游推广平台，促进当地的创意经济发展。

**教学启示**

[图像 29：待版权审查，原图保存在私有归档]

**👩‍🏫 对教师的教学启示**

- AI 助教进课堂： 教师可以借鉴此模式，在虚拟教学场景中设置“AI NPC”。例如在历史课的虚拟场景中，设置一个由 AI 驱动的“孔子”或“莎士比亚”，让学生直接与历史人物对话。
- 沉浸式实地考察： 利用 Spatial 等平台，组织“虚拟实地考察”，解决实地参观成本高、风险大的问题。

**🏫 对学校的启示**

- 校本课程数字化： 学校可以利用类似的低代码平台，将本校的特色课程或当地非遗文化开发成元宇宙课程，这是一种低成本、高科技含量的创新。

**🎨 对游戏设计师的启示**

- API 连接是关键： 未来的教育游戏设计，“美术”不再是瓶颈，“连接能力”才是。学会如何调用 OpenAI 或其他大模型的 API，赋予游戏角色“灵魂”，是下一个竞争高地。
- 多模态交互： 本研究中的 语音-语音 (Speech-to-Speech) 交互模式比传统的 文字-文字 交互更具沉浸感，特别适合移动端或 VR 端体验。

**🔬 研究者如何复现？（Replication Guide）**

- 技术路线：

  建模： Blender 建模型。

  平台： 注册 Spatial.io 开发者账号。

  脚本： 在 Unity 中编写 C# 脚本，调用 OpenAI API（需要 API Key）。

  Prompt Engineering： 关键在于如何写好 System Prompt，限制 AI 只回答关于“织锦”的问题，防止它胡说八道（幻觉）。
- 实验设计： 这种“前测-后测 + UEQ量表”的混合方法评估模式非常标准且扎实，适合硕博论文参考。

**Gemini锐评**

[图像 31：待版权审查，原图保存在私有归档]

这篇文章是“技术落地”的优秀范本。

1. **紧跟技术前沿：** 文章使用了 GPT-4o 和 Whisper，这是目前公认最强的多模态模型组合。这让研究具有极强的时间效力。
2. **解决了痛点：** 以前的虚拟博物馆 NPC 只会几句固定的台词，很傻。这篇文章展示了 LLM 如何让 NPC 变得“聪明”，这真正改变了元宇宙教育的游戏规则。
3. 局限性：
4. **成本问题：** 调用 API 是要花钱的（Token 计费）。如果大规模推广，运营成本谁来承担？文中未详细讨论。
5. **平台依赖：** 完全依赖 Spatial 平台和 OpenAI。如果平台规则变更或 API 涨价，项目可持续性存疑。
6. **AI 幻觉：** 虽然文中提到满意度高，但未深入探讨 AI 是否会编造虚假的文化历史信息，这在严肃的文化遗产保护中是一个潜在风险。
