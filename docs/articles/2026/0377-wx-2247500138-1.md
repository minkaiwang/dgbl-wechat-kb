EquiliBubble: An adaptive serious game for assistance in static balance rehabilitation

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

平衡康复对于行动不便者的恢复和生活质量至关重要，特别是老年人和神经系统疾病患者 。本研究提出了一款名为 EquiliBubble 的严肃游戏。患者通过在真实的测力平台上进行内-外侧（左右）移动，来控制游戏内的移动挡板，使弹球反弹并击破中心的泡泡 。该游戏最大的创新在于“持续适应性”：游戏会实时分析患者的表现，找出其最难控制的区域，并将挑战和奖励专门集中在这些薄弱区域 。通过对10名志愿者的技术接受度模型（TAM）评估，参与者高度认可了该游戏的易用性和实用性，证明了其作为监督下平衡训练互动工具的巨大潜力 。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

1. 如何将动态难度调整（DDA）算法融入临床姿势图测力平台，以针对性地训练患者的平衡薄弱区？
2. 基于测力平台的平衡康复游戏在终端用户中的技术接受度（易用性与感知有用性）如何？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

保持人体平衡需要视觉、前庭和体感系统的协同工作，尤其是在双脚站立时，内-外侧（ML）轴的稳定性直接决定了人是否会跌倒 。在传统的康复环境中，平衡训练需要大量枯燥的重复，极易消耗患者的动力 。严肃游戏通过提供“心流（Flow）”体验和情感沉浸，能够将干预变成一种个性化的挑战 。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

研究团队盘点了以往基于Wii平衡板、Kinect以及Tymo等设备开发的康复游戏 。分析发现，现有研究普遍存在一个巨大的设计空白：**缺乏基于患者实时表现的动态适应性（Adaptability to patient performance）**。大多数游戏只是让患者“过关”，而无法敏锐地察觉到“患者左侧重心转移没问题，但右侧非常吃力”，从而无法做到“缺哪补哪” 。

**3. 游戏设计**

[图像 17：待版权审查，原图保存在私有归档]

EquiliBubble 借鉴了经典的《打砖块（Arkanoid）》机制，但做了深度的康复化改造 。

- **交互核心：** 游戏上下各有一个挡板，屏幕中心是一堆宇宙泡泡。患者站在Horus测力平台上，将身体重心向左或向右倾斜，挡板就会同步移动来接球 。
- **动态难度调整（DDA）的绝妙应用：** 游戏将屏幕垂直划分为7个区域 。如果玩家没接住球（球飞出上下边界），系统就会在对应的区域记录一次“错误” 。核心机制来了：某个区域的错误率越高，系统就越频繁地把“增益道具（Power-ups）”空投到这个区域！ 这迫使并吸引患者主动去练习他们最薄弱、最不敢发力的那一侧 。
- **多维挑战与道具：** 游戏包含10个关卡，加入了需要击打两次的“坚硬泡泡”和不可摧毁的障碍物 。道具包括：放大/缩小挡板、强化球（一击击碎坚硬泡泡）、操作反转等 。
- **防认知超载：** 游戏采用高对比度的2D深空背景，抛弃花哨的光效，并配有极强的多模态听觉反馈（如纠错提示音），确保老年人不会感到眼花缭乱 。

**4. 方法与实验**

[图像 27：待版权审查，原图保存在私有归档]

- **系统架构：**基于Unity引擎（C#），采用MVC架构。最硬核的是打通了与Horus医疗级测力平台的串行通信。游戏提取患者X轴（左右）的位移数据，并将其标准化为-1到1的值来控制挡板 。
- **实验对象：** 10名来自老年学跨学科研究中心的志愿者（7女3男），注意，他们并非真正的平衡障碍患者 。
- **实验流程：** 志愿者在正常难度下试玩了第1、5、8关 。随后填写了基于技术接受度模型（TAM）的李克特5点量表问卷，评估“易用性”和“感知有用性”，并留下了开放式评论 。

**5. 结果**

[图像 30：待版权审查，原图保存在私有归档]

- **极高的技术接受度：** 在“易用性”方面，62%的参与者“非常同意”，34%“同意”；在“感知有用性”上，数据更高，78%“非常同意”，22%“同意” 。
- **用户痛点反馈（极具参考价值）：** 尽管数据好看，但玩家在评论中提出了非常真实的意见。例如，有玩家表示：玩着玩着眼睛全盯在球上了，忘记了自己脚站歪了。他们强烈建议在游戏UI里加一个“脚部位置指示器（雷达图）”，并在偏离安全站姿时发出警报音 。另外，还有人建议给球加上“轨迹预测虚线”，以帮助反应慢的老年人 。

**6. 讨论与总结**

[图像 35：待版权审查，原图保存在私有归档]

本研究成功验证了将测力仪硬件与自适应游戏引擎相结合的可行性 。通过算法记录区域错误率并诱导练习，EquiliBubble 提供了一种具有高度针对性的物理处方 。不过，研究的局限性也很明显：样本量太小、受试者是健康人而不是患者、仅进行了一次干预而没有追踪长期疗效。此外，为了降低初期操作门槛，当前版本彻底舍弃了测力板上的Y轴（前后倾斜）数据，仅保留了左右移动 。

[图像 36：待版权审查，原图保存在私有归档]

**教学启示**

[图像 37：待版权审查，原图保存在私有归档]

**对治疗师的启示：** 游戏后台那“7个垂直分区的错误率”就是完美的数字化诊疗单。它能比肉眼更精准地量化出患者在动态重心转移中，对具体哪一个角度存在“肌肉无力”或“发力恐惧”，从而方便调整后续的线下物理治疗方案。

**对医疗/科研机构的启示：** 不要盲目追求极其昂贵的大型外骨骼机器人。采用“市售高精度测力板 + 定制化Unity小游戏”的轻量化组合，其造价极低，完全可以大规模部署在社区康复中心。

**对游戏设计师的启示（重点）：**

- “反向”的动态难度： 我们平时的游戏设计是“哪里不会考哪里（增加惩罚）”。但这款游戏是“哪里不会，道具就刷在哪里”。用极具诱惑力的正向奖励，骗着患者去突破自己的生理极限，这才是康复游戏的最高境界！
- 防跌倒UI设计： 沉浸感在医疗游戏里是把双刃剑。患者沉迷看屏幕极易导致脚下踩空。必须在屏幕边缘设计醒目的“重心雷达UI”和脱轨蜂鸣器。

**研究者如何复现：**下一步的复现千万别再找健康人做TAM问卷了。直接招募真实的卒中后遗症或帕金森患者群体，开展严谨的随机对照试验（RCT），并通过引入Y轴数据（前后倾斜），将游戏升级为二维全向控制！

**Gemini锐评**

[图像 39：待版权审查，原图保存在私有归档]

“机制设计是个天才，实验验证却像个敷衍的实习生。”

这篇论文最绝妙的闪光点在于它的DDA（动态难度调整）底层逻辑。绝大多数康复游戏只是在做“大屏交互”，而它却利用分区错误率算法，把“弱点惩罚”变成了“弱点诱惑”——你越不敢往左边倒，我越往左边掉大宝剑。这种精准打击偏瘫患侧的设计思路，简直是教育/康复游戏策划的教科书！

但是！一看到实验部分就让人泄气。辛辛苦苦接通了医疗级测力平台，最后居然找了10个不需要康复的健康人来填了一份“这游戏好不好用”的主观问卷！这就像是造了一把绝世屠龙刀，却拿去切了切黄瓜证明它很锋利。没有临床随机对照、没有肌电图数据、没有平衡量表（如BBS）的客观变化。它用极好的工程设计，做了一个极浅的疗效验证。期待这个团队2.0版本的真正临床大考！
