Comparing Gamified and Traditional Assessment Environments: A Quasi-Experimental Study in a University Python Course

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

本研究旨在比较两种截然不同的评估环境——传统的纸笔考试与复杂的数字化游戏化考试——对大学生Python编程入门课程表现的影响 。研究在匈牙利约翰·冯·诺依曼大学进行，63名大一IT专业学生根据自我意愿选择考试形式，其中27人参加了传统纸笔考试，36人则在定制的、受《太空狼人杀（Among Us）》启发的网页应用“CodingUs”中完成了考试 。这个游戏化环境不仅融入了游戏设计元素，还包含了AI自动生成的个性化任务、禁用的剪贴板操作以及独特的用户界面 。同构的Python任务是通过结合GPT-4o-mini和GPT-4o的AI生成管道生成的 。数据分析显示，两组在平均成绩上没有统计学上的显著差异（游戏化组63.06%，传统组68.89%） 。尽管没有发现显著的成绩差异，但非正式的课堂观察和学生的反馈初步表明，游戏化组的参与度更高，且对防作弊机制的认知较为正面 。该研究贡献了一个可复制的、AI支持的编程题目生成工作流 。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

- **RQ1:**游戏化考试所产生的学生表现（平均分、中位数、方差）是否与传统考试具有可比性？
- **RQ2 (探索性):**基于非正式的课堂观察和学生主动提供的反馈，这两种评估形式在学生参与度、感知的公平性以及威慑学术不端行为方面，出现了哪些初步迹象？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

高等教育的评估方式正面临着跟上“数字原住民”学生步伐的压力 。虽然游戏化（将积分、徽章和排行榜等元素用于非游戏环境）已被证明能提升学习动机，但它在评估阶段（如测验、考试）的作用仍未被充分探索 。大多数实证研究停留在课堂参与度层面，而没有衡量游戏化评估是否能产生与传统笔试一样可靠和公平的成绩 。本文填补了这一空白，直接比较了真实大学编程课程中两种评估环境的学习成果和体验 。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

- **高等教育中的游戏化评估：**现有的游戏化研究多集中于形成性评价或低风险的课堂练习，将游戏化用于高风险的总结性考试（Summative assessment）的实证报告寥寥无几 。将游戏引入考试，人们最担心的是引入“与构念无关的变异（construct-irrelevant variance）”，比如学生不熟悉界面导致丢分 。
- **AI辅助生成编程考题：**随着LLM的爆发，利用AI生成编程练习成为热点。研究表明，仅靠AI生成还不够，必须结合自动化测试来进行专家级审查或验证 。
- **数字时代的学术诚信：**生成式AI让传统的“查重（相似度检测）”几乎失效 。学界呼吁从“监控/事后检测（如录屏、眼动追踪）”转向“基于设计的防作弊（Design-based approaches）”——即通过个性化题目和环境限制，让学生“诚实作答”成为最阻力最小的路径 。
- **理论框架（自我决定理论 SDT）：**游戏化考试设计需满足学生的自主性、胜任感和归属感，将考试从“强迫性的评价”转变为“自愿参与的挑战” 。

[图像 12：待版权审查，原图保存在私有归档]

**3. 游戏设计**

[图像 13：待版权审查，原图保存在私有归档]

研究开发了一款名为 CodingUs 的客户端-服务器网页应用，视觉主题深度致敬了知名游戏《太空狼人杀（Among Us）》 。

**交互机制：**玩家（考生）在动画地图中移动虚拟角色，触碰收集“金币”来触发弹窗中的编程任务 。

**AI驱动的动态关卡生成（极度硬核）：**为防止学生抄袭，游戏后台接入了五轮AI生成与验证管道：

- 使用经济高效的 GPT-4o-mini 根据教师提供的知识点生成代码题和解答 。
- 使用能力更强的 GPT-4o 审查生成的代码是否达标 。
- 执行空运行（Dry run）确保无语法崩溃 。
- AI再次为该题生成自动化单元测试（Unit test）脚本 。
- 后台用测试脚本跑一遍生成的答案，全部通过后，这道独一无二的题才会发给考生的游戏客户端 。

**环境限制（反作弊）：**为了增加作弊成本，游戏内置的代码编辑器彻底禁用了剪贴板操作（禁止复制、剪切和粘贴）。学生即使找到了AI答案，也必须一行行手打进去 。

**4. 方法与实验**

[图像 19：待版权审查，原图保存在私有归档]

- **研究设计：**准实验设计，采用“学生自我选择（Self-selection）”机制 。考前让学生自主选择考传统的纸笔，还是考游戏化版本，这符合SDT理论中的“自主性（Autonomy）”原则 。
- **参与者：**63名约翰·冯·诺依曼大学信息技术专业的大一学生。其中27人选择了传统笔试，36人选择了游戏化考试 。
- **实验过程：**为了避免操作不熟练带来的丢分，学生在平时的实验课上已经用 CodingUs 练习过 。正式考试限时90分钟，考核的底层核心能力完全一致 。传统组考后人工批改，游戏化组提交后由单元测试自动给出即时反馈 。
- **数据分析：**因成绩分布不符合正态分布，主要采用非参数的 Mann-Whitney U 检验进行对比 。

[图像 20：待版权审查，原图保存在私有归档]

**5. 结果**

[图像 21：待版权审查，原图保存在私有归档]

- **平均分对比：**游戏化组的平均分为 63.06%（中位数60%），传统纸笔组的平均分为 68.89%（中位数80%） 。
- **统计学差异：**Mann-Whitney U 检验结果显示，两组的成绩并没有统计学上的显著差异 (p=.383) 。传统考试略高的分数在统计上可归因于随机误差。
- **分数分布特性：**传统组的分数呈现两极分化（双峰分布，高分多），而游戏化组的分数分布较宽，偏向右偏态（中等分数多） 。作者指出，游戏化组禁止粘贴必须手敲代码、且每个人题目完全不同，这些严苛的条件很可能在客观上拉低了游戏化组的得分上限 。

**6. 讨论与总结**

[图像 26：待版权审查，原图保存在私有归档]

研究表明，游戏化考试可以作为传统纸笔考试的有效替代方案，两者的考核结果具有统计学上的可比性 。虽然没有证明游戏化能“提高”考试分数，但 CodingUs 平台成功展示了**如何利用AI自动化生成海量同构考题，并通过环境限制（禁粘贴、游戏化界面监控）从设计根源上掐断了作弊的可能** 。局限性在于本研究允许学生“自选”考试方式，可能存在动机和数字素养的偏差（Self-selection bias） 。

**教学启示**

[图像 28：待版权审查，原图保存在私有归档]

- **👨‍🏫 对教师的启示：**当你想把某款数字化工具或游戏作为期末考试时，“考前演练”是不可打破的铁律。本研究的成功前提是学生在平时上课时已经花了十几分钟熟悉《CodingUs》的操作 。不要让界面的陌生感毁了你精心设计的专业考试。
- **🏫 对学校的启示：**面对AI时代的防作弊难题，学校采购昂贵的“摄像头监考、眼动追踪”系统不仅引发学生焦虑，还涉及隐私争议 。更好的思路是“基于设计的防御”：利用AI为每个学生生成参数、情境不同的题目，让互相对答案或网上搜答案的时间成本远高于自己动脑做题 。
- **🕹️ 对游戏设计师的启示：**将评估平台游戏化时，除了积分和排行榜，更要把控交互底线。本文中极为精妙的设计是——禁用复制粘贴键 。这看似反人类，但在编程考试情境下，它既强迫学生手打代码练习语法，又从物理层面阻断了将题目丢给ChatGPT或直接抄袭代码的行为 。
- **🔬 对研究者的复现建议：**本研究最遗憾的地方是采用了“学生自选（Self-selection）”而非“随机分配（Randomized allocation）” 。未来的研究必须进行严格的随机对照试验（RCT），同时需要运用项目反应理论（IRT）去对AI生成的不同题目进行严谨的“难度等值心理测量校准（Psychometric item calibration）”，证明AI出的题难度真的完全一样 。

**Gemini锐评**

[图像 30：待版权审查，原图保存在私有归档]

将“游戏化”用到上课不稀奇，但敢把它用到“大学期末考试”中，这篇论文可谓胆大心细。

文章最惊艳的不是最终那个“无显著差异”的成绩对比，而是其背后那套极其工程化、逻辑闭环的“以AI制AI，以游戏防作弊”的底层哲学。

在ChatGPT泛滥的今天，传统机考几乎成了作弊的温床。而这篇文章给出了一个教科书级的解法：第一步，用小模型（GPT-4o-mini）疯狂造题，大模型（GPT-4o）在后台做质检并写测试脚本，确保每个考生的题目都是全网独一份，掐断“搜答案”的路；第二步，套上《太空狼人杀》的UI壳子，监考老师只需扫一眼屏幕，如果谁没在操控彩色小人跑图，肯定是在切屏作弊；第三步，系统内狠心切断“Ctrl+C / Ctrl+V”，你就算找人代写，也得在考场上满头大汗地照着敲完几百行代码。

虽然因为允许学生自己选考试方式，导致实验存在样本偏差（所以作者很诚实地报告了没有成绩差异）。但这篇实证研究向我们证明了：**未来的教育游戏，不仅仅是提供多巴胺的玩具，更是重塑教育生态底层规则（如测评公平性、学术诚信）的坚实武器**。
