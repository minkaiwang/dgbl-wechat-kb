# 游戏开始：比较emoWELL严肃游戏与电脑纸牌在初显期成年人中的减压效果

**Title**

Game on: comparing stress reduction effects between emoWELL serious game and computer solitaire in emerging adulthood

游戏开始：比较emoWELL严肃游戏与电脑纸牌在初显期成年人中的减压效果

**DOI**

10.1016/j.entcom.2025.101075

**Keywords**

Serious games（严肃游戏）, Stress management（压力管理）, Emerging adults（初显期成年人）, Heart coherence（心脏连贯性）, Emotion dysregulation（情绪失调）, Commercial off-the-shelf games（商业现成游戏/COTS）

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

初显期成年人（18-29岁）由于生活角色面临诸多转变，通常伴随着高水平的压力 。本研究比较了一款专为压力管理设计的严肃游戏（emoWELL）与传统的商业现成游戏（电脑纸牌游戏）的减压效果，同时评估了客观生理指标（心脏连贯性）和主观指标（感知压力） 。结果表明，严肃游戏组在心脏连贯性方面有显著改善（43.3%的人实现可靠增长，而纸牌组仅为24%） 。此外，严肃游戏组有36.7%的参与者感知压力显著降低，而纸牌组仅为8% 。调节效应分析揭示，那些存在严重“情绪失调”的个体，从严肃游戏中的获益最为明显 。定性反馈显示，严肃游戏带来了多维度的心理益处，而纸牌游戏则主要被视为转移注意力和训练执行功能的工具 。研究证实，严肃游戏与商业休闲游戏在压力管理中扮演着不同的互补角色 。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

- 严肃游戏在改善客观生理指标（心脏连贯性）方面是否比商业休闲游戏更有效？
- 严肃游戏在降低主观感知压力方面是否比商业休闲游戏带来更显著的降幅？
- 玩家先前的“情绪失调”水平是否会调节干预方式与感知压力变化之间的关系？
- 在主观评价上，严肃游戏组的玩家是否比休闲游戏组更认为游戏有助于他们管理压力？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

18至29岁的“初显期成年人”正处于从青春期向独立迈进的关键阶段，他们在学业、职业和人际关系上面临着巨大动荡，这也是压力相关心理问题的高发期 。如何科学评估并缓解这一群体的压力？传统上，压力评估分为主观问卷和客观生理指标（如代表身心动态平衡的“心脏连贯性”） 。虽然传统的心理治疗（如CBT或ACT）卓有成效，但直接面对内心往往会让年轻人在初期感到抗拒或痛苦 。电子游戏作为一种非侵入式的媒介，展现出了巨大的干预潜力 。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

目前的数字疗法主要分为两大阵营：一是目的明确的“严肃游戏（Serious Games）”，专门为了弥补认知或心理缺口而设计 ；二是纯粹为了娱乐的“商业现成游戏（COTS）”，如各类休闲小游戏 。已有文献表明，严肃游戏能有效识别和降低青年人的焦虑 ；而休闲游戏也能带来积极情绪 。然而，部分商业大作包含的社交属性、成瘾机制和高挑战性，反而可能导致玩家情绪失调恶化 。因此，探究到底哪种游戏机制更适合初显期成年人的日常压力管理，成为了亟待解决的实证空白 。

[图像 12：待版权审查，原图保存在私有归档]

**3. 游戏设计**

[图像 13：待版权审查，原图保存在私有归档]

本研究进行了两款游戏的硬核对决：

**游戏 A：emoWELL（压力管理严肃游戏）**

叙事隐喻：玩家扮演的角色正在进行一趟火车旅行，由于不可抗力，列车必须停靠在一个以古希腊城市为原型的车站（Acros） 。

心理机制植入 ：

- ACT（接纳承诺疗法）隐喻体验：游戏将经典的“拔河比赛”和“国际象棋”隐喻具象化为小游戏，帮助玩家反思自己在压力下的“功能失调策略”。
- 认知重构选择题：向玩家展示年轻人在现实中常遇到的压力认知，玩家必须在三个选项中选出最具适应性的“解压认知路径”。
- 正念与时间管理：游戏内设置了角色对话，探讨设定心理边界、自我照料（如休息和锻炼），并引导玩家在游戏内“安排真实的日程表”，甚至包含一段正念冥想训练。

**游戏 B：电脑纸牌游戏（商业休闲游戏代表/COTS）**

机制：经典的接龙纸牌（Solitaire）。

设计意图：研究者保守地选择了纸牌而非现代网游，是为了剔除商业游戏中可能存在的成瘾机制和过度社交焦虑，单纯测试“休闲分散注意力”带来的减压效果 。

[图像 14：待版权审查，原图保存在私有归档]

**4. 方法与实验**

[图像 15：待版权审查，原图保存在私有归档]

**实验对象：**55名18-29岁的初显期成年人，随机分为严肃游戏组（30人）和纸牌游戏组（25人） 。

**实验流程：**单次实验设计。参与者首先佩戴耳垂脉搏传感器（emWave Pro设备）采集基线心率数据，并填写主观问卷 。随后，他们在实验室中连续游玩分配的游戏45分钟 。结束后立即再次进行生理数据采集和问卷评估 。 \* 测量工具：

- 客观生理：心脏连贯性（Heart Coherence），频段在0.04 Hz - 0.26 Hz之间，连贯性越高代表生理抗压状态越好 。
- 主观心理：PSS-14 感知压力问卷、DERS 情绪失调困难量表 。

**数据分析：**使用MANCOVA、多元分层回归以及可靠变化指数（RCI）对数据进行严格的对比和调节效应分析 。

**5. 结果**

[图像 19：待版权审查，原图保存在私有归档]

- **生理抗压（客观指标）：**严肃游戏组碾压纸牌组。游玩emoWELL后，玩家的“平均心脏连贯性”、“连贯性达成率”和“高连贯性持续时间”均显著提升 。43.3%的严肃游戏玩家生理抗压水平实现了可靠增长，而纸牌组仅为24% 。
- **主观感知压力：**36.7%的严肃游戏组玩家表示压力显著下降，而纸牌组只有少得可怜的8% 。
- **情绪失调的“调节效应”（核心亮点！）：**数据揭示了一个有趣的现象——那些在日常生活中“情绪调节能力最差、最容易崩溃”的年轻人，在玩了严肃游戏后，压力下降得最为显著 ！而纸牌游戏对这部分人群毫无额外帮助 。
- **玩家的真实评价：**96.7%的严肃游戏玩家认为游戏帮到了他们，而只有60%的纸牌玩家这么认为 。定性分析显示，严肃游戏玩家感受到的是“情绪认知的重塑”，而纸牌玩家表示这仅仅是“转移了注意力和训练了专注度” 。

**6. 讨论与总结**

[图像 26：待版权审查，原图保存在私有归档]

本研究用客观的心理生理学数据证明：带有明确心理学意图（如CBT/ACT）的严肃游戏，在实质性降低压力和改善生理动态平衡方面，优于普通的商业消遣游戏 。商业休闲游戏虽然好玩，但它缺乏系统引导玩家进行“认知反思”的机制，因此更像是一片“数字阿司匹林”——只能提供短期的注意力转移和缓解 。特别是对于那些天生情绪敏感、自我调节困难的年轻人来说，严肃游戏提供了他们迫切需要的“数字情绪脚手架” 。

**教学启示**

[图像 28：待版权审查，原图保存在私有归档]

**对教师/心理辅导员的启示：**面对大学里焦虑、承压的学生，直接进行心理谈话往往容易引起防御机制。本研究证实，让学生游玩约45分钟融入了接纳承诺疗法（ACT）的严肃游戏，就能有效平复其生理心率并改变其压力认知 。这是一种极佳的“课前破冰”或心理中心辅助干预手段 。

**对学校的启示：**学校心理健康中心不应只配备沙发和沙盘，应当引入“生物反馈设备（如心脏连贯性监测）+ 心理严肃游戏”的组合干预舱 。客观的数据反馈能让理工科或对心理学抱有怀疑态度的学生更直观地看到情绪调节的科学性。

**对游戏设计师的启示：**

- 打通“商业+严肃”的次元壁：纯粹的严肃游戏容易显得枯燥，而商业游戏缺乏疗效。未来的解压游戏设计，可以将“拔河隐喻”、“时间规划”等认知行为机制 ，无缝包裹在诸如《动物森友会》这种拥有极致商业美术和心流体验的壳子里，实现真正意义上的“寓医于乐” 。
- 警惕高刺激设计的反噬：对于旨在减压的产品，必须克制加入诱导成瘾机制、高压竞技排行榜或社交逼迫感，因为这会让情绪失调的玩家雪上加霜 。

**研究者如何复现内容和实验：**

- 未来的复现实验应当抛弃“接龙纸牌”这种过于古板的对照组，换成当下年轻人真正沉迷的休闲手游（如三消游戏或放置类游戏），以获得更具生态效度的对比数据 。
- 增加纵向追踪（Longitudinal tracking）：不仅仅看玩了45分钟后的效果，更要追踪一个月后，玩家是否将游戏中的“认知重构”策略内化到了真实生活的压力事件中 。

**Gemini锐评**

[图像 30：待版权审查，原图保存在私有归档]

“休闲游戏只是压力的‘止痛药’，严肃游戏才是对症下药的‘手术刀’。”

这篇文章无情地戳破了一个伪常识：我们总以为“压力大了打把游戏放松一下就好”。但数据证明，如果你本来就是一个容易情绪失控的人，玩个“接龙纸牌”或者“开心消消乐”，除了帮你逃避现实45分钟、训练一下你那可怜的专注力之外，对根除你的压力认知毫无用处 。

真正的抗压，需要你在游戏里直面那些让你痛苦的认知，并在虚拟的隐喻中（比如跟内心的怪物“拔河”）完成心理重构 。这篇文章给了数字疗法一剂强心针——只要游戏机制设计得符合认知行为学，它不仅能说服你的大脑，甚至能直接驯服你狂乱的心跳！
