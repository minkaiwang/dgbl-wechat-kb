The Role of Gamified Artificial Intelligence-Based Learning Environments on Different Types of Cognitive Load in Gifted Students

**摘要**

[图像 06：待版权审查，原图保存在私有归档]

这是一项探索性及以设计为导向的研究，调查了超常学生在基于AI的游戏化学习环境中所经历的不同类型认知负荷的可行性和描述性模式 。研究采用单组前测-后测设计，涵盖了2025-2026学年的49名超常学生 。学生们在“Machine Learning for Kids”平台上通过对行星图像进行分类来训练AI模型，并将其应用于基于Scratch的游戏化环境“星球侦探 (Planet Detective)”中 。该过程包含了积分和等级等游戏化元素 。结果表明，该模块提高了学生的学业成绩，平衡了性别差异，并产生了中高水平的内在认知负荷、低水平的外在认知负荷以及高水平的有效认知负荷，这表明该学习体验在概念上非常丰富，同时又清晰有效 。

[图像 07：待版权审查，原图保存在私有归档]

**研究问题**

[图像 08：待版权审查，原图保存在私有归档]

本研究旨在实现以下具体目标：

1. 揭示超常学生在AI驱动的游戏化学习活动中，其内在、外在和有效（相关）认知负荷水平所观察到的变化和模式 。
2. 检验超常学生在参与通过“Machine Learning for Kids”平台开发的“星球侦探”模块期间，有关学业成就指标的描述性发现 。

[图像 09：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 10：待版权审查，原图保存在私有归档]

随着教育数字转型的加速，AI支持的学习环境能够提供动态且个性化的学习过程 。然而，AI系统不仅影响学业成绩或动机，还会显著影响学生的认知负荷（即学习过程中工作记忆的心理努力程度） 。认知负荷理论（CLT）将认知负荷分为三类：内在认知负荷（由内容复杂性引起）、外在认知负荷（由糟糕的教学设计引起的无效负荷）和有效认知负荷（用于意义学习的认知努力） 。

超常学生虽然具有极高的认知潜力和抽象思维能力，但在面对复杂且多组件的任务时，他们依然可能会经历认知超载、失去动机或感到单调 。因此，为他们设计能平衡认知需求的AI游戏化学习环境显得尤为重要 。

[图像 11：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 12：待版权审查，原图保存在私有归档]

- **认知负荷与多媒体学习：** 早期研究表明，基于认知负荷理论的教学设计能直接提升学习成绩 。随后，研究进一步发现，合理使用视听多媒体材料、改善界面设计可以有效降低外在认知负荷 。
- **游戏化与认知负荷的复杂关系：** 游戏化（Gamification）可以提升学习者动机并降低认知负荷，但并非总是如此 。有研究指出，如果游戏化设计带来不必要的压力或过多的视觉刺激，反而会增加外在认知负荷 。最近的趋势强调“微游戏化（micro-gamification）”策略，以在不增加额外负荷的情况下维持参与度 。
- **超常儿童教育：**超常学生在标准教学环境中往往得不到充分支持，他们需要差异化、个性化且富含挑战性的学习环境 。

[图像 13：待版权审查，原图保存在私有归档]

**3. 游戏设计**

[图像 14：待版权审查，原图保存在私有归档]

本研究开发了一个名为“星球侦探 (Planet Detective)”的AI学习模块，设计紧扣认知负荷理论的原则：

**开发工具：** 结合使用了“Machine Learning for Kids”平台与“Scratch”编程环境 。

**活动流程：** 学生收集不同行星（如地球、火星、木星等）的图像来构建训练数据集，训练一个视觉分类模型，并测试其准确性 。

**游戏化整合：** 训练成功的模型被整合到Scratch游戏中，游戏可以识别学生上传的图像并预测行星，学生验证这些预测来推进游戏进度 。游戏包含了积分 (points) 和 关卡 (levels) 机制 。

**认知负荷设计策略：**

- 管理内在负荷： 分阶段教学（先学AI概念，再训练模型，最后做游戏），并且仅限制有限类别的行星图像，以控制信息复杂度 。
- 减少外在负荷： 游戏界面极其简单，去除了不必要的图形和文字；Scratch的积木块结构让学生无需面对复杂的代码语法 。
- 增加有效负荷： 要求学生自己创建数据集并测试模型，特别是分析模型分类错误的案例，促使他们进行深度的认知加工和图式构建 。

[图像 15：待版权审查，原图保存在私有归档]

**4. 方法与实验**

[图像 16：待版权审查，原图保存在私有归档]

**研究设计：** 采用单组前测-后测的定量探索性研究设计 。

**被试：**49名中学的超常学生（25名女生，24名男生） 。

**实验流程：** 为期4周，每周2小时 。

- 第1周：前测，介绍AI与数据准备 。
- 第2周：在ML for Kids上训练模型 。
- 第3周：模型测试与Scratch整合 。
- 第4周：调试优化，进行后测与认知负荷评估 。

**测量工具：**

- 学业成就测试： 包含25道选择题，涵盖数据分类、模式解释、逻辑排序等（KR-20信度为0.84） 。
- 不同类型认知负荷量表： 共10个条目（包含内在、外在、有效三个维度） 。

**5. 结果**

[图像 21：待版权审查，原图保存在私有归档]

**学业成就大幅提升：** 学生的前测平均分为60.41，后测飙升至79.85，差异极其显著（p < 0.001） 。Cohen's d 效应量计算显示女生（2.26）和男生（1.77）均达到了“巨大（Very large）”的效应量 。

**消除了性别差异：** 在前测中，男生的成绩显著高于女生 ；但在经历了AI游戏化学习后，后测中男女生的成绩差异不再显著，表明该环境对所有学生都是均衡且包容的 。

**优化的认知负荷分布：** \* 内在认知负荷为 6.2（中等偏高）： 任务具有一定的心理挑战性，既不太简单也不太难 。

- 外在认知负荷为 3.8（低）： 任务指令清晰，界面结构良好，没有造成不必要的负担 。
- 有效认知负荷为 7.5（高）： 学生将大量心智努力导向了核心的学习与图式构建过程 。

**相关性分析：** 有效认知负荷与学业成就之间存在中等程度的正相关（r = 0.45, p < 0.01） 。

**6. 讨论与总结**

[图像 27：待版权审查，原图保存在私有归档]

研究表明，AI支持的游戏化学习环境不仅没有成为增加认知超载的因素，反而充当了调节工具，引导超常学生的认知资源流向有意义的学习 。对于超常学生而言，中高水平的“内在认知负荷”并非障碍，这反而是他们对复杂任务进行长时间、深层次认知投入的积极指标 。该“星球侦探”模块成功实现了自主性、控制感和认知挑战之间的平衡，是一次极具启发性的教学设计验证 。

[图像 28：待版权审查，原图保存在私有归档]

**教学启示**

[图像 29：待版权审查，原图保存在私有归档]

- **👨‍🏫 对教师的启示：** 教师不应仅仅将游戏化作为一种“激励工具（motivational tool）”，更应将其作为一种“深化认知参与的教学工具” 。应当提供个性化的反馈，支持学生的自我调节技能，以此强化他们主动参与和管理认知负荷的能力 。
- **🏫 对学校的启示：**AI教育需要适应学生的个人学习节奏和认知风格 。学校在开展资优教育时，应当积极引入这种能够动态调节任务复杂度的AI游戏化课程，摆脱单一的讲授模式 。
- **🕹️ 对游戏设计师的启示：** 设计时必须对学生的认知负荷极度敏感。通过减少不必要的信息、说明和视觉元素来最小化“外在认知负荷” 。同时，积分和关卡的设计应严格服务于教学目标，帮助学生聚焦注意力，而不是分散注意力 。
- **🔬 对研究者的复现建议：**未来的研究必须采用对比设计（例如，对比“有游戏化的AI环境”与“无游戏化的AI环境”）以分离各组件的具体作用 。强烈建议使用混合研究方法（结合量化数据与学生访谈、反思日志）以深度挖掘认知体验，并拓展到非超常儿童群体进行对比 。

**Gemini锐评**

[图像 31：待版权审查，原图保存在私有归档]

这篇文章最大的亮点在于它的极高实操性。很多AI教育的论文只是停留在理论构建，而本文直接给出了一个中小学一线教师完全可以直接复刻的教学范例：“Machine Learning for Kids” 结合 “Scratch”。这是一套极其成熟且免费的K-12人工智能积木编程工作流，它把黑盒的AI训练过程（数据收集 -> 标注 -> 训练 -> 测试）变成了一个清晰的、可视化的探究游戏。

从理论视角来看，文章巧妙地运用了“认知负荷理论（CLT）”。在教育游戏设计中，我们常犯的错误是为了让游戏“好玩”而堆砌了极其复杂的UI界面和炫酷的特效，这往往导致“外在认知负荷”爆表，学生玩得很嗨但什么都没学到。本文通过极简的UI和聚焦于排错（Debugging）的设计，成功拉高了“有效认知负荷”，这是非常值得称道的。

当然，本研究的局限性也很明显：缺乏对照组。单组前测后测的设计，让我们很难从统计学上绝对证明，成绩的提高究竟是因为“AI技术”、因为“游戏化机制”、还是因为单纯的“花时间学习了4周”。未来的研究如果有条件，一定要设置严格的RCT（随机对照试验），才能进一步确立这种教学模式的科学效度。
