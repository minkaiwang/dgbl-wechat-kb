Current serious game genres for stroke neurorehabilitation: A scoping review of randomized controlled trials

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

中风康复越来越依赖严肃游戏来提升患者的动机与恢复效果，但应用于神经康复的游戏类型却缺乏系统的分类 。本范围综述（基于PRISMA-ScR指南）严格筛选了2019至2025年间发表在Q1-Q2期刊上的87项随机对照试验（RCT），以绘制中风后治疗中严肃游戏的主类型和子类型图谱 。结果显示，在所审查的系统中，商业系统占71%，定制化原型占29% 。“动作”、“解谜”和“模拟”是最常见的一级（核心）游戏类型 。在机制上，强调“街机风”和“指令执行”的情境最为普遍，而认知和社会-情感领域的干预则被严重边缘化 。大众娱乐中极受欢迎的三消、塔防和回合制战术等类型在临床中完全缺席，凸显了当前设计的局限与创新机遇 。研究开发了一个多层标签分类图，为将游戏机制选择与临床治疗目标对齐提供了结构化视角 。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

- 近年来在游戏化中风康复中，主要使用了哪些类型和流派的商业或定制严肃游戏？
- 在中风康复严肃游戏的分类和使用方面，当前文献存在哪些空白或新兴趋势？
- 建立全面的严肃游戏分类体系，将如何有助于未来设计出能优化患者依从性和临床预后的个性化干预措施？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

中风会导致患者出现长期的运动、认知和情感障碍，因此中风后康复至关重要 。为了恢复神经功能，患者必须进行高强度的重复性训练，但这极易导致患者感到枯燥甚至产生挫败感 。严肃游戏（SG）作为一种专门为治疗或教育等非娱乐目的设计的完整游戏，正逐渐被整合到神经康复中，以解决患者动机不足的问题 。然而，在当前的文献中，“游戏化”和“严肃游戏”等术语常常被混为一谈，导致设计特征模糊不清 。为了实现真正的个性化康复，临床必须深入理解游戏类型（Genres）究竟是如何影响治疗体验的 。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

为了寻找理论基础，研究团队首先对过去15年内探讨“严肃游戏类型”的23篇文献进行了快速回顾 。分析结果令人吃惊：关于游戏类型的研究绝大多数集中在“教育”（39%）、“游戏设计与技术”（22%）以及“心理健康”（13%）领域 。而在康复领域（尤其是中风等神经康复）的研究仅仅占17% 。许多现有的医疗游戏分类要么过于笼统，要么只关注特定的轻度休闲游戏，根本无法涵盖目前中风康复中日益复杂的商业设备与定制化虚拟现实（VR）方案 。

**3. 游戏设计**

[图像 14：待版权审查，原图保存在私有归档]

为了打破“游戏标签大杂烩”的乱象，本研究构建了一套极具实操性的多层标签映射系统（Multilayer labeling map） ：

- **Tier 1（核心主类型）：** 决定了游戏的情感基调和叙事框架 。包含：动作（Action）、解谜（Puzzle）、模拟（Simulation）、冒险（Adventure）、体育（Sports）、策略（Strategy）和RPG等 。
- **Tier 2（核心子机制）：** 决定了具体的交互方式 。包含：休闲（Casual）、射击（Shooter）、街机（Arcade）、迷宫（Maze）、卡牌（Cards）等 。例如，同样是“动作”类，子机制是“街机”就意味着高频的时间压力，而“休闲”则意味着宽松的试错空间 。
- **视觉与拟真度 (Realism)：**被明确划分为街机风（Arcade）、混合风（Hybrid）、写实（Realistic）和超写实（Hyper-Realistic） 。
- **临床情境 (Clinic Context)：** 游戏被分为三大应用场景：指令执行（Instructions，按部就班地完成动作并获得反馈）、日常生活活动（ADL）和运动游戏（Exergames） 。

[图像 15：待版权审查，原图保存在私有归档]

**4. 方法与实验**

[图像 16：待版权审查，原图保存在私有归档]

- **研究类型：** 遵循PRISMA-ScR指南的范围综述 。
- **数据来源：** 全面检索了PubMed、IEEE Xplore和ScienceDirect三大核心数据库 。
- **极其严格的筛选标准：** 只纳入2019年1月至2025年4月发表在JCR Q1-Q2级别期刊上的研究 ；研究设计必须是随机对照试验（RCT） 。这意味着本综述过滤掉了所有粗糙的原型测试，只看那些经受住了最高级别临床检验的游戏化方案 。
- **最终样本：**共纳入87项高质量的临床RCT试验 。
- **数据提取：** 详细提取了游戏软硬件类型（商业设备 vs. 定制化）、主类型、子类型、每次干预时长、外设输入（机械臂、跑步机、眼动仪等）以及治疗领域 。

**5. 结果**

[图像 20：待版权审查，原图保存在私有归档]

- **硬件生态：****商业系统为主导。** 68%（或71%）的试验依赖于成熟的商业设备（如Lokomat机械臂、任天堂Wii等），定制化游戏系统占32% 。
- **主流游戏类型高度集中：** “动作 (26%)”、“解谜 (21%)”和“模拟 (13%)”三大类型统治了中风康复领域 。在子机制（Tier 2）层面，高达50%的游戏采用了“休闲（Casual）”机制 。
- **康复领域存在严重偏科：** 76%的研究死磕“大运动功能（Gross Motor）”的恢复，23%关注认知康复，而旨在改善患者中风后抑郁、焦虑的社会-情感（Socio-affective）领域仅占可怜的1% 。
- **“沉浸感”的代价：** 64%的游戏为了普及，采用了粗糙的“街机风”画面 。而那些追求“写实/超写实”的场景（占23%）几乎100%绑定了昂贵且笨重的VR头显设备或复杂的外骨骼，严重限制了它们在居家康复中的应用 。

**6. 讨论与总结**

[图像 31：待版权审查，原图保存在私有归档]

本研究揭示了一个发人深省的现象：在目前最顶级的临床试验中，主导市场的依然是画风简陋、机制简单的游戏。而诸如三消（Match-3）、塔防（Tower Defense）、多人竞技（MOBA）或回合制战术等在娱乐市场大红大紫的游戏类型，在严谨的中风康复研究中面临“全军覆没” 。这并非巧合，而是因为中风患者往往伴随认知加工迟缓、工作记忆受损以及手部精细动作障碍，难以应对复杂机制带来的“高认知负荷”和“多线任务” 。**作者提出了一种循证游戏设计的三步法**：第一步，选择Tier 1类型以激发患者动机；第二步，分配Tier 2子机制来控制运动和认知剂量；第三步，在小规模临床中验证叙事与机制的融合度 。

**教学启示**

[图像 33：待版权审查，原图保存在私有归档]

- **对教师/康复治疗师的启示：**在为患者开具“数字疗法处方”时，不能盲目追求“3D大作”或高度沉浸感。数据显示，基于简单指令（Instructions）和休闲机制（Casual）的游戏在临床表现最为稳定 。治疗师需根据患者病程动态调整游戏类型（例如：认知受损严重的急性期患者使用简单的“拖拽解谜”，慢性期患者可引入带有一定时间压力的“射击/动作”游戏）。
- **对学校/临床机构的启示：** 昂贵的VR设备和庞大的机械臂虽然能提供极高的评估精度，但也成为将治疗延伸至患者家庭的障碍 。机构应采取“高低搭配”策略：在专业门诊保留商业级高保真设备，同时大力开发能在普通平板、手机上运行的定制化轻量级SG应用，以提升长期居家康复的依从性 。
- **对游戏设计师的启示（重点）：** 打破设计的“黑盒”！商业康复设备常常把无数小游戏打包成一团，且不开放后台核心数据 。设计师应当尝试将目前文献中完全缺失的爆款机制（如三消、塔防）进行临床视角的“无障碍降维改造”——例如放宽操作的容错时间、减少屏幕上的动态刺激源，在不引发患者挫败感的前提下，将现代游戏深度的反馈机制（Combo、策略规划）融入枯燥的关节屈伸动作中 。
- **研究者如何复现内容和实验：**未来的研究论文绝不能只干巴巴地写一句“我们使用了某某厂商的VR游戏”！必须按照本文提出的多层标签体系，在方法学部分明确报告：游戏的一级类型是什么？核心子机制是什么？视角拟真度如何？反馈机制的频次怎样？  只有将游戏机制的数据彻底结构化，后人才能真正复现你的干预效果并进行元分析。

**Gemini锐评**

[图像 35：待版权审查，原图保存在私有归档]

“在真实的临床痛点面前，许多闭门造车的‘炫酷’疗法正在节节败退。”

这篇文章如同一把手术刀，精准剖析了当前数字游戏化医疗领域的尴尬现状：我们在实验室里高呼“用游戏化重塑医疗”，但在最严谨的RCT临床检验场上，**最后活下来的居然全都是简单粗暴的“按指令打地鼠”**。那些被寄予厚望的复杂玩法（RPG、MOBA、策略塔防）一碰到真正存在偏瘫、失语或认知障碍的中风患者，就出现了严重的“水土不服”。

这不仅是游戏界的傲慢，也是技术与临床脱节的缩影。很多设计师把健康人的反应速度和多线程处理能力理所当然地投射到了神经损伤患者身上。真正的康复游戏设计，绝不是给枯燥的拉力器套上一个花哨的3D虚拟外壳，而是要深入临床一线，去体会患者每一次无法完成抓握时的沮丧。未来的数字医疗爆款，必然属于那些愿意俯下身子倾听康复治疗师诉求的团队——**我们需要的是“懂医疗的游戏人”与“懂游戏的治疗师”在底层机制上的深度共创**！
