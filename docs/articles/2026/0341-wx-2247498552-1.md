**Title**

Game Changer: Unveiling the Significance of Game Design Elements as Encouragement Strategies during Maximal Exercise Testing

游戏规则改变者：揭示游戏设计元素作为最大运动测试中激励策略的重要性

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

最大运动测试（如测VO2max）是评估体能和诊断疾病的关键，但其有效性高度依赖于参与者是否“拼尽全力”。传统的激励方式（如语言鼓励）缺乏标准化且效果不一。本文提出了一种创新观点：**利用游戏设计元素作为激励策略**。通过引入沉浸式、互动性的游戏机制，可以转移受试者对生理痛苦的注意力（分离效应），从而在不自觉中达到更高的运动强度。文章结合Exergame（运动游戏）的研究成果，详细列举了可应用于测试的具体游戏特征，呼吁建立一个新的研究领域——**最****大运动测试的游戏化**，以提高测试的信度和效度。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

**核心痛点：**在进行最大强度运动测试时，当强度超过通气阈值，强烈的生理不适（呼吸困难、肌肉疼痛）会导致消极情绪，促使受试者在真正达到生理极限前就提前放弃。解决方案探索： 如何利用数字化手段（特别是游戏设计）来提供比传统语言鼓励更有效、更标准化的激励，从而“骗”过大脑，让受试者坚持得更久？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

最大运动测试的准确性取决于受试者的努力程度（Effort Investment）。根据双模式理论（Dual Mode Theory），高强度的生理压力会压倒认知控制，导致强烈的负面情绪。目前的激励手段主要是“语言鼓励”（比如医生在旁边喊“再坚持一下！”）。但这种方法存在很大缺陷：不标准化（喊得大声与否全看医生心情）、缺乏互动。文章认为，是时候引入高感知负荷（High Perceptual Load）的游戏元素来抢占大脑的注意力资源了。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

- **注意力分离理论：** 音乐和视频已被证明能通过“抢占”有限的认知资源，减少对疲劳的感知。
- **游戏的优势：** 相比被动的音乐/视频，电子游戏需要主动参与、处理信息和做出反应，因此能产生更强的沉浸感（Immersion）和心流（Flow），从而更有效地屏蔽身体的痛苦信号。
- **Exergame的证据：** 引用了 ExerCube 的研究，证明在精心设计的游戏中，玩家可以在不知不觉中达到极高的运动强度（心率达到最大值的97%），且体验到的乐趣远高于枯燥的跑步机测试。

[图像 12：待版权审查，原图保存在私有归档]

**3. 游戏设计**

[图像 13：待版权审查，原图保存在私有归档]

本文并非介绍某一款特定游戏，而是提出了一个**通用的设计框架**（见文中 Table 1 和 Fig 1）。想要把体测变得像玩游戏一样上瘾，需要植入以下8个核心元素：

1. **挑战性任务 (Challenging Tasks):** 引入虚拟对手（Ghost），它的表现会根据测试标准动态调整，激起好胜心。
2. **即时反馈 (Prompt Feedback):**不要只给枯燥的数据。让虚拟教练或观众在旁边欢呼，或者用视觉特效展示当前的功率输出。
3. **叙事结构 (Narrative Structure):**给跑步一个理由！比如“你正在逃离怪兽”或“正在星际穿越”。随着测试阶段的推进，场景也要随之进化。
4. **沉浸感 (Foster Immersion):** 利用环绕立体声和动态变化的虚拟环境（如天气变化），让受试者忘记自己是在实验室里。
5. **互动参与 (Interactive Involvement):** 增加反应任务（如躲避障碍物），迫使受试者必须保持专注，不能走神去想“腿好酸”。
6. **动态奖励 (Dynamic Rewards):**设立积分、徽章和排行榜。比如达到某个心率区间就疯狂掉金币。
7. **用户控制感 (User Control):**允许用户自定义Avatar（化身）或选择喜欢的虚拟场景，增强自主性。
8. **社交互动 (Social Interaction):**引入实时或异步的排行榜竞争，或者让朋友通过弹幕加油。

**5. 结果**

[图像 19：待版权审查，原图保存在私有归档]

虽然本文没有新数据，但引用的 ExerCube 研究显示：

- **高强度达成：** 玩家在游戏中能达到平均 86% 的最大心率，甚至有个体达到 97% 。
- **人口统计学无关性：** 有趣的是，年龄、性别、BMI 和体能水平并没有显著影响游戏中的努力程度。这说明好玩的游戏能让所有人都动起来 。
- **超越传统：** 14% 的参与者在游戏中测得的心率和摄氧量，竟然比在标准跑步机测试中还要高。这意味着游戏比传统测试更能“榨干”体能 。

[图像 20：待版权审查，原图保存在私有归档]

**6. 讨论与总结**

[图像 21：待版权审查，原图保存在私有归档]

- **标准化优势：** 游戏化不仅是为了好玩，更是为了科学性。由程序控制的视觉/听觉反馈是完全标准化的，消除了“测试员喊得不够卖力”这一人为误差，提高了测试的信度（Reliability） 。
- **体验重塑：** 将痛苦的力竭测试转化为一场“史诗般的旅程”，可能会改变人们对体测的恐惧心理 。
- **呼吁：** 作者呼吁建立一个新的跨学科研究领域，联合医生、运动生理学家和游戏设计师，共同开发下一代体测系统 。

**教学启示**

[图像 23：待版权审查，原图保存在私有归档]

**👩‍🏫 对体育教师/教练的启示**

- 别只靠吼： 学生的体测成绩不好，可能不是体能不行，而是过程太无聊。尝试引入简单的竞争机制或视觉反馈（如投影大屏显示实时排名）。
- 叙事的力量： 即使没有高科技设备，也可以通过语言构建情境（“最后100米，丧尸追上来了！”）来激发学生的潜能。

**🏫 对学校/体测中心的启示**

- 设备升级方向： 未来的体测室不应该只有冷冰冰的仪器。引入 VR/AR 或 投影交互系统，将体测变成“体感游戏厅”，能显著提高学生的配合度。

**🎨 对游戏设计师的启示**

- 8大元素清单： 文中的 Table 1 是极佳的设计检查表。在设计运动游戏时，不仅要关注好玩，还要关注如何通过“高感知负荷”来屏蔽玩家的疲劳感。
- 安全红线： 在设计最大强度测试游戏时，必须平衡“沉浸感”与“安全性”，避免玩家过于投入而忽略身体的危险信号（如跌倒风险） 。

**🔬 研究者如何复现？（Replication Guide）**

- 研究空白： 目前缺乏直接对比“传统测试”与“游戏化测试”的随机交叉对照研究。这正是研究生发论文的绝佳选题！
- 变量控制： 设计实验时，应系统地改变单一游戏元素（如：有无虚拟对手、有无叙事），以拆解出哪个元素对提升运动表现最有效 。

**Gemini锐评**

[图像 25：待版权审查，原图保存在私有归档]

这篇文章提出了一个极其性感的概念，但落地仍有挑战：

1. **理论的完美与现实的骨感：**文章设想很美好，但在医疗或学校场景中，成本是最大障碍。搭建一套沉浸式 ExerCube 系统的成本，远高于医生喊两嗓子。
2. **安全性的双刃剑：** 文章提到了利用“分离效应”让受试者忽略痛苦。但这在医疗诊断中是有风险的。如果患者因为太沉浸游戏而忽略了心绞痛等预警信号，后果不堪设想。如何在“鼓励尽力”和“保证安全”之间寻找平衡点，文中讨论较少。
3. **不仅是游戏，更是心理学：** 这篇文章最深刻的洞见在于指出了体测的本质——这是一场大脑与身体的博弈。游戏设计实际上是在进行认知干预，这一点对于所有教育游戏设计都通用。
