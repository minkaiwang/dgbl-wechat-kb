Designing an educational game framework with multi-scaffolding mechanism to facilitate communication and contextual analysis skills

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

在商业和政府组织中，情境分析与沟通互动是被高度重视的关键软技能。然而，传统教学往往缺乏真实的互动语境。本研究整合了多维情境分析支架机制，开发了一款名为 "Give Me the Water" 的教育游戏。游戏提供了一个高度逼真的历史游戏空间（基于200年前的台湾），让学习者扮演历史人物，参与真实的水资源分配历史事件。通过准实验研究（60名参与者），结果表明，无论是小组合作还是个人学习模式，该游戏都能显著提升学习者的沟通与情境分析技能，且活动焦虑水平较低。研究还发现，小组合作在心流体验的特定维度上优于个人学习。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

1. **效果评估：** 这款整合了多维支架的游戏，在提升学习者的沟通技能、情境分析能力以及心流体验方面效果如何？
2. **模式对比：** 个人学习（Individual Learning）与小组合作学习（Group Collaboration）在上述指标及支架有用性感知上是否存在显著差异？
3. **用户画像：**基于学习效果和体验，可以将学习者分为哪些不同的聚类（Clusters）？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

沟通不仅仅是说话，更重要的是“看脸色、懂局势”（Contextual Analysis）。如果不能理解对话发生的物理环境、社会关系和对方的隐性需求，沟通往往会失败。传统的沟通课程多为理论讲授，缺乏“试错”的机会。游戏化学习（GBL）提供了沉浸式环境，但如果没有适当的引导（支架），学习者容易在复杂的剧情中迷失。本研究提出了一个**“多维情境分析支架（Multi-dimensional Contextual Analysis Scaffolding）”**框架，旨在通过游戏内的引导机制，帮助学生从环境、人际和策略等多个维度解析沟通情境。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

- **情境分析的重要性：** 引用了 Guffey 等人的观点，强调在沟通中分析物理环境、非语言表达和社会地位的重要性。
- **支架理论：** 传统的支架（Scaffolding）多为认知层面的帮助。本研究将其扩展为多维结构，包括认知、元认知、情感和空间支架。
- **协作 vs 个人：**文献对于“一起玩”还是“自己玩”更好存在争议。协作可能带来更深的讨论，但也可能导致责任分散或社交焦虑。本研究试图在同一游戏框架下对比这两种模式。

[图像 12：待版权审查，原图保存在私有归档]

**3. 游戏设计**

[图像 13：待版权审查，原图保存在私有归档]

这款游戏基于 Gather Town 平台开发，背景设定在 200年前的台湾南部。

**核心剧情：** 玩家扮演一名地方官员，面临严重的干旱和村民争水冲突。任务是调查缺水原因，安抚村民，并制定分配政策。

**多维支架机制 (核心创新)：**

- 概念支架 (Conceptual Scaffolding): 游戏中内置了“沟通秘籍”文档，玩家随时可查阅基础沟通理论（如倾听技巧）。
- 空间情境支架 (Spatial Context Scaffolding): 游戏地图还原了真实的历史地形（如水坝、农田）。玩家必须实地考察地形，才能理解为什么上游村庄截断了水源，从而在对话中通过“摆事实”说服下游村民 。
- 沟通情境支架 (Communication Context Scaffolding): 与 NPC（村民/官员）的对话通过 Google Forms 模拟分支剧情。

  机制： 如果玩家没有识别出 NPC 的情绪（如愤怒、无奈）或选错了沟通策略（如居高临下地命令），对话会进入死胡同（Bad End），任务失败。玩家必须重新思考策略再试一次。
- 元认知支架 (Metacognition Scaffolding): 游戏要求玩家在关键节点停下来，记录线索并反思：“我现在掌握了什么信息？我的沟通目标是什么？”
- 同伴支架 (Peer Scaffolding): （仅限小组组）队友之间通过语音讨论策略，分工收集线索。

**4. 方法与实验**

[图像 18：待版权审查，原图保存在私有归档]

**参与者：** 60名 成年学习者（平均年龄36.5岁，包含在职人员和学生）。

**分组：** 随机分为 个人组 (n=30) 和 小组组 (n=30, 3人一组)。

**流程：**

- 前测（15分钟）：沟通与情境分析能力测试。
- 游戏时间（45分钟）：在 Gather Town 中完成“抢水”任务。
- 后测（20分钟）：再次测试能力，并填写心流、焦虑和支架有用性问卷。

**测量工具：**

- 情境分析能力测试： 使用情境判断题（Situational Judgment Tests），让学生在模拟职场对话中选择最佳回应。
- 心流与焦虑量表： 改编自经典量表。

**5. 结果**

[图像 23：待版权审查，原图保存在私有归档]

**双赢局面：**无论是个人玩还是组队玩，后测成绩均显著高于前测 (p < .001)。这证明了多维支架游戏本身是有效的教学工具。

**组队更快乐：**

- 在心流（Flow）体验上，小组组显著高于个人组 (t = 2.15, p < .05)。互动讨论让游戏过程更投入、更有趣。
- 在焦虑感上，两组都很低，且无显著差异。这说明游戏设计得足够友好，没有给个人玩家造成过大压力。

**支架感知：** 两组对“支架有用性”的评分都很高（>4.3/5），说明玩家确实感觉到了游戏里的提示和引导对他们有帮助，而不是干扰。

**6. 讨论与总结**

[图像 31：待版权审查，原图保存在私有归档]

- **支架的隐形引导：** 游戏没有生硬地教学，而是通过“对话失败-重来”的机制，让玩家在使用支架（查阅文档、观察地形）的过程中自然习得技能。
- **协作的红利：** 虽然个人也能学好，但小组讨论提供了额外的“社会性支架”，队友的观点补充了彼此的盲区，从而提升了心流体验。
- **低焦虑环境：** RPG 的角色扮演属性为学习者提供了一个“安全失败空间”，即使说错话得罪了 NPC，也不过是重开一局，这对于社恐人士练习沟通非常有益。

**教学启示**

[图像 33：待版权审查，原图保存在私有归档]

**👩‍🏫 对教师的教学启示**

- 不仅要教“怎么说”，还要教“在哪说”： 在沟通课程中，引入空间分析（Environment Analysis）环节。让学生分析对话发生的物理环境（如办公室布局、噪音干扰），这往往是被忽略的关键因素。
- 善用“分支剧情”： 在设计案例教学时，不要只给一个标准答案。设计“多结局”的剧本，让学生体验错误沟通带来的后果。

**🏫 对学校的启示**

- 软技能实训室： 利用类似 Gather Town 的低成本平台，搭建虚拟实训社区。学生可以在里面扮演不同角色（如客户、经理），进行常态化的社交演练。

**🎨 对游戏设计师的启示**

- 把“环境”变成“线索”： 不要让游戏地图只做背景板。设计必须让玩家与环境互动（如查看河道干涸程度），并将环境信息作为沟通的筹码，这样的沉浸感才强。
- 多维支架植入： 别只给文字提示。设计视觉线索（NPC 表情变化）、工具线索（记事本功能）和反馈线索（失败原因提示），全方位辅助玩家。

**🔬 研究者如何复现？（Replication Guide）**

- 平台复用： Gather Town 是一个非常适合做 2D 社交 RPG 的平台，门槛低，支持多人视频。研究者可以复用此架构，将剧情换成“商务谈判”或“医患沟通”。
- 聚类分析： 本文使用了 K-means 聚类分析学习者类型（如“高成就-低焦虑型”）。未来的研究可以借鉴此方法，深入探讨不同性格玩家对游戏机制的偏好。

**Gemini锐评**

[图像 35：待版权审查，原图保存在私有归档]

这篇文章是“小而美”设计的典范。

1. **切口巧妙：**它没有宏大叙事，而是聚焦于“Contextual Analysis（情境分析）”这个具体的软技能点，并将其与游戏地图探索完美结合。
2. **设计扎实：** “多维支架”不是空话，文中详细列出了每种支架在游戏里的具体对应功能（如 Table 2），非常具有实操参考价值。
3. **样本局限：** 只有 60 人，且实验时间较短（45分钟）。对于沟通这种复杂技能，短期干预的长期保持效果存疑。此外，Google Forms 模拟对话的交互形式略显生硬，如果能接入 LLM（如 ChatGPT）进行自由对话，效果会是质的飞跃。
