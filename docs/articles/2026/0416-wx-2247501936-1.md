**Title**

Identifying World Types to Deliver Gameful Experiences for Sustainable Learning in the Metaverse

识别元宇宙中的世界类型，以提供游戏化体验促进可持续学习

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

元宇宙通过多种技术的融合，有望将想象变为现实，它应被视为一种打破时空限制的、用于可持续教育的新媒介 。本研究旨在识别元宇宙中的具体“世界类型（World Types）”，以为用户提供游戏化体验 。研究首先分析了游戏化体验与学习动机之间的关系 。随后，研究采用自下而上的方法，基于真实案例识别出可用于元宇宙教育的5种世界类型：生存类、迷宫类、多项选择类、竞速/跳跃类以及密室逃脱类 。这些发现可以帮助创造创新的教育环境，为学习者提供平等的教育机会，从而助力实现联合国第四项可持续发展目标（SDG 4） 。

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

（注：原文采用探索性研究框架，核心研究问题可提炼为）

1. 在元宇宙环境中，有哪些具体的“虚拟世界类型”能够有效地为学习者提供游戏化体验？
2. 这些游戏化体验（Gameful Experience）是如何与学习动机产生联系，并促进可持续学习的？

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

新冠疫情加速了技术的进步，人们在线上的时间激增 。在后疫情时代，元宇宙已经成为连接线上与线下领域的媒介 。当前元宇宙的主要用户是“Z世代”（1995年以后出生的人），他们伴随着PC和移动游戏成长，天然偏好“游戏化体验” 。

传统的在线学习（如普通的视频会议）由于缺乏互动，往往会对学生的学习动机和态度产生负面影响 。为了解决这个问题，“游戏化（Gamification）”成为了关键抓手——即将积分、徽章、排行榜等游戏元素应用到非游戏环境中 。在教育中引入游戏化，可以让学生在不经意间获得“仿佛在玩游戏一样”的体验，从而显著提升参与度 。

**2. 文献综述**

[图像 13：待版权审查，原图保存在私有归档]

本研究的理论基础非常扎实，主要涵盖以下三个维度：

**元宇宙的分类：**研究采用了ASF（加速研究基金会）的经典分类，将元宇宙分为增强现实（AR）、镜像世界、虚拟世界（Virtual Worlds）和生命日志（Lifelogging） 。当前主流平台如Zepeto、Roblox、Gather.town和Fortnite都属于典型的“虚拟世界” 。

**体验的三个线索（Threads of Experience）：**基于Kim提出的框架，体验被解构为：

- 感官体验线索：包括物理存在感、社会存在感和自我存在感 。
- 判断体验线索：核心是控制点（内部控制点 vs 外部控制点） 。
- 结构体验线索：包括时间的连贯性、社会关系和结构关系 。

**游戏化与动机：**游戏化教育的基本结构是：教师提供真实任务 -> 学习者积累分数/提示 -> 兑换奖励 -> 享受成长的乐趣 。这种机制能激发学习者的责任心、外向性、想象力等6大内在因素，实现可持续学习 。

**3. 游戏设计**

[图像 20：待版权审查，原图保存在私有归档]

通过对主流平台的案例分析，作者总结出了5种可以直接用于教学设计的元宇宙世界类型（重点记笔记！）：

1. **生存世界 (Survival World) ⚔️**

   机制：玩家必须与其他用户进行知识竞争，答错即淘汰，直到决出最后一名幸存者 。

   案例：韩国旅游发展局在Roblox上利用《鱿鱼游戏》IP打造的江陵市知识生存游戏 。

   体验特征：极强的竞争性和紧张感，能激发高度的“自我存在感” 。
2. **迷宫世界 (Maze World) 🌀**

   机制：世界由大面积的迷宫组成，知识信息隐藏在墙壁或岔路口中，玩家必须利用这些信息做出选择才能逃离 。

   案例：Zepeto上的“GUCCI别墅”，玩家在迷宫中探索并被动接收品牌文化（教育信息） 。

   体验特征：核心是“探索”，玩家与环境结构的互动极强 。
3. **多项选择世界 (Multi-choice World) ✅❌**

   机制：由主持人（教师）引导，进行OX问答、找茬或解谜。玩家控制虚拟化身移动到代表正确答案的区域 。

   案例：Gather.town上的OX问答地图 。

   体验特征：容错率高（没有“失败”概念，可以重试），具有很强的社交连结属性，适合大班互动 。
4. **竞速/跳跃世界 (Racing/Jump World) 🏃‍♂️**

   机制：操控化身跨越地形障碍，最先到达终点者获胜。知识点通常作为背景板或必经路径出现，利用“被动学习理论”让学生在重复曝光中记忆 。

   案例：Zepeto上的三星Galaxy竞速跑酷图 。

   体验特征：对玩家的操作反应要求高，能带来极强的“物理存在感” 。
5. **密室逃脱世界 (Escape Room World) 🔐**

   机制：玩家被锁在特定空间，必须寻找隐藏的线索并解开谜题（如填写面试技巧填字游戏）才能通关 。

   案例：在Gather.town上为求职大学生设计的减压与就业信息逃脱室 。

   体验特征：集大成者，高度锻炼问题解决能力、团队协作和沟通技巧 。

**4. 方法与实验**

[图像 27：待版权审查，原图保存在私有归档]

- **研究方法：**本研究并没有采用传统的量化控制组实验，而是采用了软件工程中常见的“自下而上（bottom-up approach）”定性研究方法 。
- **实施过程：**研究者收集并亲自进入了Zepeto、Roblox、Gather.town和Fortnite等真实元宇宙平台中的场景 。通过提取这些场景中共有的、同时具备“游戏化体验”和“教育价值”的模式，最终向上归纳提炼出了上述5种宏观的世界类型模型 。

[图像 28：待版权审查，原图保存在私有归档]

**5. 结果**

[图像 29：待版权审查，原图保存在私有归档]

研究证实，这5种世界类型完美契合了游戏化学习的基本结构：它们都为用户提供了清晰的胜利条件（活到最后、拿到高分、率先冲线、成功逃脱）和任务/任务线（给出正确答案、寻找隐藏线索） 。用户在为了获胜而应用知识的过程中，不仅获得了游戏般的体验，更引发了与他人的互动，从而将其转化为强大的学习动机 。

[图像 30：待版权审查，原图保存在私有归档]

**6. 讨论与总结**

[图像 31：待版权审查，原图保存在私有归档]

研究指出，为了打破Zoom等传统在线教育的局限性，教育者应积极考虑在元宇宙中采用这5种游戏化世界设计 。这种模式打破了物理和空间的限制，能够为处于弱势环境（如灾区或偏远地区）的学生提供平等的学习机会，是实现联合国可持续发展目标（提供公平、优质教育）的有力工具 。

**教学启示**

[图像 33：待版权审查，原图保存在私有归档]

- **👩‍🏫 对教师的启示：**别再对着PPT干讲了！你可以利用Gather.town这种低门槛工具，把随堂测验变成“OX多项选择世界”或者“密室逃脱”，让学生操控小人跑动答题，课堂气氛绝对瞬间点燃。
- **🏫 对学校的启示：**学校在进行数字化转型时，应跳出“把录播课放到网上”的思维局限。可以鼓励建立基于元宇宙的虚拟校园空间，为学生提供跨越物理限制的互动沉浸式学习体验。
- **🎨 对游戏设计师的启示：**这篇论文直接给出了5套现成的模板。在设计教育游戏时，可以直接套用：文科记忆类知识适合“迷宫”和“竞速跑酷”（被动曝光），理科逻辑类适合“密室逃脱”（深度解谜），而测验评估环节则最适合“生存淘汰赛”。
- **🔍 给研究者的复现建议：**本研究属于框架构建类的定性研究。后续研究者可以进一步实证检验：针对特定的知识类型（如外语词汇 vs 物理公式），这5种世界中哪一种的学习效果最好？或者针对本文提到的增强现实（AR）和镜像世界，进一步开发相应的教育分类模型 。

**Gemini锐评**

[图像 35：待版权审查，原图保存在私有归档]

**这篇文章是典型的“实践指导意义 > 理论突破意义”的佳作。** 对于一线教育工作者和游戏设计师来说，这篇论文简直是“久旱逢甘霖”。以往谈到教育元宇宙，大家总是觉得虚无缥缈，不知道从何下手。而这篇文章直接去当红的Roblox、Zepeto里“抄作业”，提炼出的5个模型（生存、迷宫、问答、跑酷、密室）非常接地气，拿着这套框架，明天就能在课上用平台搭个雏形出来。

**但是，批判的眼光也不能少：**

作为一篇发表在SCI期刊上的论文，它的“实验”部分显得有些单薄。它只是总结了“别人是怎么做的”，但缺乏核心的实证数据支持。比如，文中虽然断言“这些世界能提升学习动机”，却没有提供任何A/B测试的数据、学生访谈记录或成绩对比分析。它告诉了我们元宇宙里“有这5种玩法”，但到底哪种玩法对提升哪种学习目标最有效？有没有带来认知超载的负面风险？这些硬核的教育学验证工作，还需要我们同仁在未来的研究中去填补空白！
