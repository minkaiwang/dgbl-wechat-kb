# 在元宇宙里越完美，现实中越焦虑？元宇宙游戏体验背后的心理机制与身份异化

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

元宇宙游戏为用户提供了一个构建理想化虚拟身份的沉浸式环境。然而，关于虚拟自我认同形成的心理机制及其情感影响的研究还很有限。本研究整合了体验经济理论 (EET)、自我认同理论和自我差异理论，调查了383名元宇宙游戏用户。结果发现：

①EET的四个维度（娱乐、教育、审美、逃避）都能显著增强虚拟自我认同，其中娱乐体验影响最大，逃避体验影响最小。

②虚拟自我认同是一把“双刃剑”：它虽然来自愉快的游戏体验，但会导致焦虑增加和自尊降低。

③自我异化 (Self-estrangement) 在其中起到了关键的中介作用——即用户越认同虚拟的完美自我，越容易感到与现实自我的疏离，从而产生负面情绪。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

①元宇宙游戏中的不同体验因素（娱乐、教育、审美、逃避）如何影响用户的虚拟自我认同？

②虚拟自我认同在游戏体验与用户心理变化（焦虑、自尊）之间扮演什么角色？

③虚拟自我与现实自我之间的转换机制是什么？（特别是负面心理后果是如何产生的？）

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

元宇宙游戏（如 Roblox, Minecraft, Animal Crossing）不仅仅是娱乐，它们允许用户通过虚拟化身（Avatar）表达“理想自我”。这种“理想我”（Ideal Self）往往比现实中的自己更强大、更漂亮。虽然这带来了满足感，但当用户下线回到现实，巨大的落差可能引发心理问题。以往研究多关注技术或单一心理维度，本研究试图打开这个黑箱：**快乐的游戏体验是如何一步步转化为现实中的焦虑的？**

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

**体验经济理论 (EET)：**将体验分为四个维度——娱乐 (Entertainment)、教育 (Educational)、审美 (Esthetic)、逃避 (Escapist)。这解释了用户为什么沉迷元宇宙。

**自我认同理论 (Self-Identity Theory)：**用户将虚拟化身的特征内化，形成“虚拟自我认同”。

**自我差异理论 (Self-Discrepancy Theory)：**解释了“理想自我”与“现实自我”的差距（Discrepancy）如何导致负面情绪。

**核心变量：**自我异化 (Self-estrangement)：指个人感觉与真实的自己脱节。在元宇宙语境下，指过度认同虚拟形象而导致现实自我的价值感丧失。

**3. 游戏设计**

[图像 15：待版权审查，原图保存在私有归档]

(注：本研究并非针对某一款特定教育游戏的设计，而是分析了主流元宇宙游戏（如Roblox, Minecraft, Eggy Party等）中普遍存在的四种EET设计元素)

研究者将元宇宙游戏的设计特性映射到了体验经济的四个维度：

**娱乐体验设计 (Entertainment)：**

核心机制：丰富的社交互动、趣味挑战、情感连接。

例子：在《蛋仔派对》(Eggy Party) 中与朋友互动，在 Roblox 中体验各种小游戏。这是吸引用户最直接的手段。

**教育体验设计 (Educational)：**

核心机制：通过完成任务、解谜或策略互动来获取技能和知识，提供成就感。

例子：在 Minecraft 中学习建筑结构，或在《名侦探柯南》联动活动中寻找线索、推理破案。这种设计提升了用户的自我效能感。

**审美体验设计 (Esthetic)：**

核心机制：高度精致的视觉效果、环境设计、角色皮肤定制。

例子：Fortnite 绚丽的天空和建筑纹理，或者用户自己在 Animal Crossing 中精心布置的岛屿。这满足了用户对美的追求和个性化表达。

**逃避体验设计 (Escapist)：**

核心机制：提供一个脱离现实压力的“乌托邦”，给予用户绝对的控制权。

例子：在 Minecraft 创造模式中随心所欲地改变地形，暂时忘记现实的烦恼。

**4. 方法与实验**

[图像 17：待版权审查，原图保存在私有归档]

**参与者：**

通过小红书、知乎、微博等平台招募了 383名 有元宇宙游戏经验的用户。

覆盖游戏包括：Roblox, Animal Crossing, Minecraft, Fortnite, Eggy Party (蛋仔派对), GTA, Axie Infinity, Second Life。

主力人群为18-34岁的年轻人（占71%）。

**测量工具：**

采用问卷调查法，量表改编自成熟文献（如EET量表、焦虑量表、自尊量表）。

使用 SmartPLS 4.0 进行偏最小二乘结构方程模型（PLS-SEM）分析。这是一个非常适合探索性研究和复杂模型验证的统计工具。

**数据分析步骤：**

信效度检验（Cronbach's Alpha, CR, AVE）。

区分效度检验（Fornell-Larcker, HTMT）。

路径系数分析与中介效应检验。

**5. 结果**

[图像 19：待版权审查，原图保存在私有归档]

**什么让用户认同虚拟形象？**

娱乐体验 (beta=0.335) 对虚拟自我认同的影响最大。快乐是第一生产力。

审美 (beta=0.183) 和教育 (beta=0.172) 体验次之。

逃避体验 (beta=0.135) 的影响最小。这与以往认为“玩游戏就是为了逃避现实”的观点略有不同，说明元宇宙用户更看重互动和创造，而非单纯的躲避。

**虚拟认同的代价是什么？**

虚拟自我认同显著增加焦虑 (beta=0.114)。

虚拟自我认同显著降低自尊 (beta=-0.117)。

中介效应：自我异化起到了关键的桥梁作用。虚拟认同越强 -> 自我异化越严重 (beta=0.437) -> 导致焦虑增加 (beta=0.187) 和自尊下降 (beta=-0.186)。

**6. 讨论与总结**

[图像 29：待版权审查，原图保存在私有归档]

**虚拟的双刃剑：**元宇宙游戏通过提供完美的视觉和成就感（EET维度），让用户爱上了那个虚拟的“理想我”。但这种爱越深，用户越会觉得现实中的自己“不够好”，从而产生自我异化。

**自我异化的机制：**当用户下线后，虚拟的完美与现实的局限（如外貌焦虑、能力平庸）形成巨大反差。这种落差感不仅让人失落，更让人觉得“现实中的我”不是“真正的我”，从而引发心理危机。

**结论：**元宇宙游戏不仅是技术的胜利，也是心理挑战的开始。设计者和用户都需要警惕过度沉浸带来的身份撕裂。

**教学启示**

[图像 31：待版权审查，原图保存在私有归档]

**🏫 对教师与学校的启示**

引导学生区分“理想”与“现实”：教师在进行元宇宙或游戏化教学时，应引导学生认识到虚拟形象是工具而非本体。

利用“教育体验”而非“逃避体验”：研究发现逃避体验对身份认同贡献最小。学校引入游戏时，应强调其技能构建（Educational）和审美创造（Esthetic）功能，避免学生将其作为单纯的避风港。

关注“退游”后的心理落差：如果学生在课堂游戏中表现出极强的虚拟代入感（如非要用某个皮肤才肯做任务），教师需警惕其现实自尊可能较低，需及时进行心理干预。

**🎮 对游戏设计师的启示**

平衡体验设计：不要只做“爽游”（娱乐体验）。研究显示教育和审美体验也能有效提升用户粘性。

设置“心理着陆”机制：鉴于虚拟认同会导致焦虑，良心的设计师可以在游戏中加入连接现实的元素（如AR功能、现实奖励），或者设计反思环节，提醒玩家虚拟成就与现实努力的联系，减少“自我异化”。

**🔬 研究者如何复现 (Replication)**

工具推荐：SmartPLS 是处理此类心理机制模型的神器，特别适合处理非正态分布数据和小样本（n=383）。

量表复用：文中使用的“自我异化量表”（Self-estrangement scale，改编自Seeman等）和“虚拟自我认同量表”在教育技术研究中用得不多，值得大家在研究“学生对学习类Avatar的认同感”时借鉴。

样本扩展：本研究样本多为PC/手机端用户。如果你的实验室有VR设备，可以尝试复现该实验，看看在VR高沉浸环境下，这种“自我异化”效应是否会更强？（推测可能会更强）。

**Gemini锐评**

[图像 33：待版权审查，原图保存在私有归档]

作为数字游戏学习的研究者，这篇文章给了我们一个非常清醒的“防沉迷”视角：

**反直觉的发现：**我们常以为“逃避现实”是玩家沉迷元宇宙的主因，但数据告诉我们，“娱乐”和“审美”才是构建虚拟认同的大头。这意味着玩家不是因为想躲起来才玩，而是因为那里“更好玩、更漂亮”。

**揭示了GBL的阴暗面：**教育游戏常鼓励学生通过Avatar获得自信（Proteus Effect），但这篇文章警告我们：这种自信可能是“虚”的。如果这种自信无法迁移到现实，反而会加剧学生对现实无能的痛苦（Self-estrangement）。这是我们在设计教育元宇宙时必须伦理考量的问题。

**方法论的典范：**用体验经济理论（商科视角）+ 自我差异理论（心理学视角）来解释游戏行为，这种跨学科理论融合非常值得研究生写论文时模仿。
