**摘要**

[图像 05：待版权审查，原图保存在私有归档]

这项研究开发了一套商业模拟游戏系统（BSGS），旨在探究学生的目标导向（GO）如何影响他们在商业管理教育中的学习成就。研究邀请了209名大学生参与了一项准实验，他们被分为实验组（VR沉浸式学习）和对照组（传统动画学习） 。

**核心发现：**

①大多数学生倾向于采用“掌握/学习”目标导向来完成学习任务。

②游戏系统与现实世界的高度拟合（即“模型-现实拟合度”）能显著降低学生的学习焦虑 。

③一个有趣的点是，学习焦虑本身并未直接影响最终的学习成就 。

④“模型-现实拟合度”在提升学习期望和成就方面扮演了关键角色。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

不同的目标导向（GOs）如何在基于VR/动画的商业模拟游戏（BSGS）学习情境中影响模型-现实拟合度，进而如何影响个体的学习动机和学习焦虑，并最终提升学习成就？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

近年来，VR等教育技术在管理教育中越来越受欢迎。商业模拟游戏系统（BSGS）作为一种创新的教学工具，为学生提供了宝贵的体验式学习环境。它们通过模拟真实世界的商业场景，让学习变得更加灵活和互动。

然而，尽管BSGS应用广泛，但很少有研究关注一个核心问题：学生的个人特质，特别是他们的“目标导向”（Goal Orientations, GO），是如何与这些高科技学习工具互动的？ 。

本研究的创新之处在于，它整合了三大经典理论来构建一个全面的分析框架：

**目标导向理论 (GO)：**解释学生的内在驱动力。

**任务-技术匹配理论 (TTF)：**强调技术功能与学习任务的契合度。

**ARCS动机模型：**系统地评估和设计学生的学习动机。

通过这个框架，研究者旨在揭示VR/动画BSGS如何通过满足不同学生的需求，最终提升他们的学习表现。

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

**商业模拟游戏 (BSGS):**BSGS被广泛认为是管理教育的有效工具。它能提供多感官的互动环境，激发学习兴趣，帮助学生在“零风险”的环境中解决现实问题，从而提升高阶思维能力。

**任务-技术匹配 (TTF) 与模型-现实拟合度:**TTF理论认为，当一项技术的功能与用户的任务需求高度匹配时，绩效就会提升。本研究将其具体化为“模型-现实拟合度” (Model-Reality Fit)，即BSGS模拟的商业场景与真实零售环境的准确性和适宜性程度。高拟合度的系统能有效降低学生的认知负荷和焦虑感。

**目标导向理论 (GO):**GO理论将学生的成就动机分为三种主要类型：

①掌握/学习导向 (Mastery/Learning-GO): 核心目标是学习、理解和解决问题，不畏挑战。

②表现导向 (Performance-GO): 核心目标是向他人展示自己的能力，希望获得优于他人的评价。

③回避导向 (Avoidance-GO): 核心目标是避免失败和负面评价，倾向于回避有挑战性的任务。

**ARCS学习动机模型:** 这是一个经典的动机设计模型，包含四个维度：

①注意 (Attention): 教学内容是否新颖有趣，能吸引并维持学生的好奇心。

②相关 (Relevance): 内容是否与学生的经验、价值观和目标相关联。

③信心 (Confidence): 任务难度是否适中，能否提供清晰的指导和成功的机会，建立学生的自信。

④满意 (Satisfaction): 学生完成任务后能否获得内在的强化和积极的反馈，感到满足。

**3. 游戏设计**

[图像 14：待版权审查，原图保存在私有归档]

这部分是研究的精髓！研究者并非随意设计一款游戏，而是将三大理论深度融入了游戏的设计哲学中。

**系统名称: 球形视频虚拟现实系统 (Spherical Video-based Virtual Reality, SVVR)。**

**设计理念与理论融合:**

融合目标导向 (GO) 理论:

游戏设置了多层次、可重复的决策任务 。

如果玩家决策失误，游戏不会直接判定“失败”，而是重置当前关卡，并提供额外的提示和信息 。

这种设计鼓励学生自由探索、反思自己的决策后果，并不断优化策略，从而培养了内在动机、自我调节和毅力，特别契合“掌握/学习导向”的学生。

融合任务-技术匹配 (TTF) 理论:

VR系统提供了直观的用户界面和沉浸式场景 。

玩家通过手柄（joystick）与环境互动，可以触发图像、文本和声音，获得实时反馈 。

这种设计确保了技术（VR）的功能与学习任务（信息处理、决策制定）高度匹配，即实现了高的“模型-现实拟合度”。

融合ARCS动机模型:

注意 (A): 通过可爱的宠物动画、声音、动态视觉元素和突发挑战来吸引玩家。

相关 (R): 场景设置在学生熟悉的商业运营环境（宠物店）中，与他们的专业兴趣紧密相连。

信心 (C): 系统提供适应性指导、脚手架式任务，并在玩家遇到困难时给予鼓励的话语和宠物愉快的叫声，帮助他们逐步建立信心。

满意 (S): 玩家成功完成任务后，会收到掌声、赞扬等积极反馈，让他们能直观地看到自己的进步并获得成就感。

**游戏玩法:**玩家戴上VR眼镜，在虚拟向导的指引下，探索一个模拟的宠物用品店。他们需要仔细观察场景，阅读文字提示，并使用手柄为虚拟顾客选择合适的产品。选择正确，系统会播放愉悦的音效并进入下一阶段；选择错误，则需要重新学习和尝试，直到成功为止。

**4. 方法与实验**

[图像 19：待版权审查，原图保存在私有归档]

研究采用了严谨的准实验设计，以确保结果的可靠性。

**参与者:**209名来自中国台湾的大学生。

**分组:**

实验组 (EG, n=95): 使用沉浸式VR商业模拟游戏，通过头戴式显示器和手柄进行学习。

对照组 (CG, n=114): 使用传统的非沉浸式2D动画版商业模拟游戏，通过手机或电脑进行学习。

**实验流程 (总时长50分钟):**

前测 (10分钟): 进行知识前测，筛选合格的参与者并获取基线数据。

实验干预 (20分钟): 两组学生分别使用各自的系统完成相同的零售管理学习任务。

问卷调查 (10分钟): 实验结束后，立即填写问卷，测量目标导向、模型-现实拟合度、学习焦虑和ARCS动机等心理变量。

延迟后测 (10分钟): 四周后，对所有参与者进行知识后测，以评估长期记忆保持情况，而非短期记忆。这是一个非常亮眼的设计，能更真实地反映学习效果！

**测量工具:** 学习成就通过（后测分数 - 前测分数）的差值来计算。其余变量均采用经过验证的量表，以7点李克特量表形式进行测量。

**5. 结果**

[图像 22：待版权审查，原图保存在私有归档]

研究通过PLS-SEM结构方程模型分析数据，得出了以下关键路径关系（见下图）：

**假设支持情况:**

学习导向 (Learning-GO) → 正面影响 → 模型-现实拟合度 (H1b) (支持 ✅)

学习导向 (Learning-GO) → 正面影响 → ARCS动机 (H1a) (支持 ✅)

表现导向 (Performance-GO) → 正面影响 → 学习导向 (H2b) 和 回避导向 (H2c) (支持 ✅)

模型-现实拟合度 → 正面影响 → ARCS动机 (H4a) (支持 ✅)

模型-现实拟合度 → 负面影响 → 学习焦虑 (H4b) (支持 ✅)

学习焦虑 → 负面影响 → ARCS动机 (H5a) (支持 ✅)

ARCS动机 → 正面影响 → 学习成就 (H6) (支持 ✅)

**未支持的有趣发现:**

三种目标导向均未直接显著影响学习成就 (H1c, H2d, H3c 不支持)。这说明目标导向是通过影响动机等中介变量来间接起作用的。

学习焦虑并未直接影响学习成就 (H5b 不支持)。这可能因为模拟游戏提供了一个安全的试错环境，缓解了焦虑对表现的负面冲击。

**模型解释力:**所有变量最终解释了学习成就10%的方差 ，以及ARCS学习动机44%的方差 。

**6. 讨论与总结**

[图像 28：待版权审查，原图保存在私有归档]

这项研究的核心贡献在于，它揭示了在VR/动画BSGS环境中，学习成就的提升是一个复杂的、多因素驱动的过程。

①目标导向是起点，但不是终点。学生的个人倾向（特别是“学习导向”）决定了他们如何看待和使用学习工具。

②“模型-现实拟合度”是关键桥梁。一个设计精良、高度还原现实的模拟系统，是激发学生动机、降低他们焦虑的核心。当学生觉得“这个东西很真实、很有用”时，他们才会更投入。

③动机是核心引擎。最终，是强烈的学习动机（ARCS）直接驱动了学习成就的提升。

**结论：**一个成功的数字游戏化学习体验，其路径是：契合学生的学习导向 → 提供高现实拟合度的工具 → 激发全面的学习动机 → 最终达成优异的学习成就。

**教学启示**

[图像 30：待版权审查，原图保存在私有归档]

这项研究为我们提供了非常具体和可操作的启示：

**对教师的启示:**

选择比给予更重要：在选择教学游戏或模拟软件时，优先考虑那些“模型-现实拟合度”高的工具。与其使用一个通用的、与课程无关的游戏，不如选择一个能精确模拟真实工作场景的系统。

引导学习导向：在课堂中，多鼓励学生将游戏视为探索和成长的工具，而不是单纯为了“赢”或“比别人好”。强调从失败中学习的价值，以培养学生的“学习导向”。

关注动机而非焦虑：研究发现焦虑不直接影响成绩，但会削弱动机。当发现学生焦虑时，教师应着重通过提升学习材料的相关性、趣味性来重建他们的动机，而不是仅仅进行心理安抚。

**对学校的启示:**

明智投资：在采购VR/AR等教育设备时，应评估其与核心课程的结合潜力。硬件投资需要与高质量、高拟合度的软件内容相匹配，才能发挥最大效用。

提供教师培训：组织工作坊，帮助教师理解如何将目标导向、ARCS动机模型等理论应用于技术支持的教学设计中，实现“人机合一”的教学效果。

**对游戏设计师的启示:**

理论驱动设计：这篇论文提供了一个黄金设计框架。在设计教育游戏时，请务必思考：

①我的设计如何支持不同目标导向的学生？（例如，为学习型玩家提供探索空间，为表现型玩家设置排行榜）

②我如何提升模型-现实拟合度？（真实的场景、专业的术语、符合逻辑的因果反馈）

③我如何系统地植入ARCS元素？（用心的音效、视觉、与学生生活相关的任务、难度递增的挑战、及时的正面反馈）

降低焦虑的设计：高拟合度是降低焦虑的法宝。清晰的引导、安全的试错环境、鼓励性的反馈，都是减少用户挫败感和焦虑感的关键。

**研究者如何复现:**

实验设计: 可借鉴其“前测-干预-问卷-延迟后测”的准实验范式，这对于测量长期学习效果非常有价值。

变量测量: 研究中使用的目标导向、ARCS动机、学习焦虑等量表均来自成熟的文献，具有高信度和效度，可以直接引用或改编。

技术实现: 复现的关键在于开发两个版本（VR沉浸式 vs. 2D非沉浸式）的学习系统，并确保两者在学习内容、任务流程上保持一致，仅在交互媒介上存在差异。

**优点:**

理论整合强大：将三个重要理论无缝融合到一个模型中，逻辑清晰，解释力强。这为后续研究提供了一个非常坚实的理论框架。

设计细节满满：论文详细阐述了如何将抽象的理论转化为具体可玩的游戏机制，对教育游戏开发者极具启发性。

延迟后测是亮点：采用4周后的延迟后测，有效避免了“新鲜感效应”的干扰，测量的是更稳固的知识留存，这在同类研究中并不多见，显著提升了研究的严谨性。

**值得商榷与未来展望:**

学习成就的解释力有限：模型对学习成就的解释方差仅为10% (R2=0.10)，这意味着还有90%的影响因素未被纳入模型。未来研究可以探索更多变量，如学生的自我效能感、认知风格、协作学习等。

焦虑的作用需要深思：研究发现焦虑不直接影响学习成就，这与许多传统教育研究的结论相悖。这是否是模拟游戏“安全试错”环境的独特效应？这个发现本身就构成了一个极具价值的未来研究课题。

缺乏社交元素：本次研究的游戏是单人模式。未来的研究可以设计协作或竞争模式的BSGS，探讨社交互动在学习过程中的作用，这可能会对表现导向和回避导向的学生产生截然不同的影响。

统计阈值的选择：作者承认使用了p<0.1作为显著性水平，这比传统的p<0.05更为宽松，可能会增加犯第一类错误的风险。尽管在探索性教育研究中可以理解，但这确实是本研究的一个局限性，读者在解读结果时需保持审慎。

总而言之，这篇研究不仅为我们展示了VR商业模拟游戏的巨大潜力，更提供了一套科学、系统、可操作的设计与评估方法论。它告诉我们，最有效的教育科技，永远是那些最懂学习者内心的科技。
