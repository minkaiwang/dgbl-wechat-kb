**Title**

The Use of Interactive Narratives in Educational Games to Assess Vocational Interests: An Application of the RIASEC Test Integrated With OpenAI

在教育游戏中使用互动叙事评估职业兴趣：集成OpenAI与RIASEC测试的应用

**期刊**

IEEE TRANSACTIONS ON LEARNING TECHNOLOGIES

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

本研究探讨了如何通过一款严肃游戏，将霍兰德职业兴趣测试（RIASEC）融入互动叙事中，以进行职业指导。这款游戏的核心创新在于，它利用**人工智能（特别是OpenAI的GPT-4 Turbo）**实时生成动态、个性化的场景，极大地增强了学生的参与感和测评的真实性。研究对200名高中生和大学生进行了测试，通过满意度调查、定性访谈以及游戏前后的数据对比来评估其有效性。

**核心研究结果：**

学生满意度极高（5分制下平均分在4.2-4.5之间）。

游戏中的职业兴趣选择与学生的学业成绩呈现显著正相关，成功地将学生的职业兴趣与学术优势联系起来。

这些发现证明，严肃游戏在个性化职业指导和支持学生全面发展方面具有巨大潜力。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

本研究的核心旨在回答以下关键问题：

与传统测评方式相比，由人工智能（AI）驱动的互动叙事，能否提升职业兴趣测评的真实性及其与学生能力的契合度？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

在现代教育中，帮助学生识别职业兴趣至关重要。RIASEC测试是广泛应用的工具，但其传统形式对年轻人来说可能单调乏味，甚至导致回答失真。如何让职业测评更吸引人、更贴近现实？

互动叙事教育游戏提供了一个解决方案。通过将测评问题巧妙地嵌入游戏故事中，学生在做决策时便自然地流露出自己的倾向，减少了被评估的感觉。然而，现有的大多数此类游戏依赖于预设的、静态的决策树，限制了个性化和适应性。

本研究的关键创新在于，我们整合了OpenAI的大语言模型（LLM），来实时、动态地为每个学生生成独一无二的个性化游戏场景 。这种前所未有的实时叙事改编，极大地提升了学生体验和测评的可靠性。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

**游戏化与严肃游戏：**游戏化是将游戏设计元素用于非游戏情境，已被证明能提升乐趣和参与度。严肃游戏则更进一步，它本身就是一个完整的游戏，旨在模拟真实情境，帮助学生在无风险的环境中识别兴趣和才能。

**互动叙事：**叙事驱动的环境（如“亚特兰蒂斯探秘”）通过激发情感共鸣和提供情境化理解，能有效改善学习成果。然而，将叙事机制与职业测评结合的研究仍相对较少。

**现有挑战：**许多现有的职业指导游戏使用静态、预定义的决策路径，这限制了个性化和适应性，可能降低测评结果的真实性。同时，将标准化的测评工具（如RIASEC）改编进游戏，也存在信度和效度方面的挑战。

[图像 12：待版权审查，原图保存在私有归档]

**3. 游戏设计**

[图像 13：待版权审查，原图保存在私有归档]

本研究的核心是一款基于Unity平台开发的、集成了RIASEC测试的互动叙事严肃游戏。其最大的亮点是利用OpenAI API实现了故事的实时动态生成 。

**设计理念：测评于无形**

核心概念：游戏的目标是让学生感觉不到自己正在被“测试”。RIASEC测试的题目被巧妙地伪装成游戏中的各种决策和行动。

叙事框架：故事围绕一个主角的冒险展开，分为多个章节。例如，在一个章节中，玩家的任务是探索一个未知星球，旅途中遇到的各种抉择都暗含着RIASEC测试的评估点。

**AI驱动的动态叙事：千人千面的体验**

这是本游戏与传统教育游戏的根本区别。

技术实现：游戏后端通过Node.js和Express.js，将玩家在游戏中的行为实时发送给OpenAI的GPT-4 Turbo模型 。

实时生成：AI模型根据玩家的输入，实时创作出接下来的故事情节和对话，然后将这些内容无缝嵌入到Unity游戏引擎中。

个性化 Anpassung：系统会分析玩家的行为模式。例如，一个持续表现出艺术倾向的学生，将会收到更多强调创造力和自我表达的叙事和挑战。

**AI工作流程示例：**

①玩家行为（输入）：玩家在探索一个殖民地时，遇到一个请求帮助修理设备的角色。

②发送给OpenAI的Prompt（指令）：“玩家正在执行探索任务，遇到有人请求帮助。请生成一段叙事，让玩家在‘继续任务’和‘留下帮忙’之间做出选择。”

③OpenAI的响应（输出）：“莱拉焦急地看着你：‘我一个人修不好，你能帮我吗？’你犹豫了。停下来帮忙，可能会错过集合时间；继续前进，则能更快完成任务。你将如何选择？”

④测评映射：这个看似简单的选择，实际上同时关联了RIASEC测试中的社会型（Social）和事业型（Enterprising）维度。

**沉浸式体验设计**

视觉与听觉：游戏采用高质量的画面和多样化的艺术风格，从未来科技感到复古历史感，并配有与场景情绪相匹配的动态音乐和音效，以增强沉浸感。

互动机制：通过解谜、探索环境、与NPC互动等方式，让玩家的所有行为都与RIASEC的评估维度相关联，并提供即时反馈来维持玩家的兴趣。

**4. 方法与实验**

[图像 19：待版权审查，原图保存在私有归档]

**研究设计：**采用定量与定性相结合的混合研究方法，对游戏的有效性、可靠性和实用性进行多维度评估。

**参与者：**

200名正处于职业决策关键阶段的学生。

100名高中生（16-18岁）和100名大一学生（18-20岁）。严格保持性别均等（男女各半）。

**实验流程：**

为期四周，每周进行两次游戏，共八个场次 。每场游戏持续45-60分钟，以平衡沉浸感和避免疲劳。实验前后，学生们都完成了一次传统的RIASEC问卷测试，用于数据对比。

**数据收集工具：**

游戏前后的传统RIASEC问卷。游戏内的决策记录（共1600份游戏会话记录）。游戏后的满意度调查问卷（5分制李克特量表）。对30名学生进行的

深度定性访谈 。

**数据分析：**

定量分析：使用SPSS和R软件，进行了方差分析（ANOVA）、配对样本t检验、组内相关系数（ICC）和皮尔逊相关性分析。

定性分析：使用NVivo软件对访谈记录进行编码和主题分析。

**5. 结果**

[图像 22：待版权审查，原图保存在私有归档]

研究取得了非常积极和显著的结果：

**学生参与度极高：**在200名参与者中，仅有8人中途退出，整体依从率高达96%，证明了游戏极强的吸引力。

**测评结果高度可靠：**

一致性：通过ICC分析，发现在不同游戏场次中，学生的回答表现出高度的稳定性（所有维度的ICC值均>0.65），证明游戏测评结果不是随机的。

**精确性：**通过皮尔逊相关性分析，发现游戏得出的RIASEC分数与传统纸笔测试的分数呈强正相关（所有维度的r值均>0.75），证明了游戏测评结果的准确性 。

**学生满意度爆棚：**

在5分制的满意度调查中，所有维度的平均分都在

4.2分以上 。其中，学生对“叙事”（4.5分）

和“职业影响”（4.4分）的评价最高。

**定性反馈正面：**从访谈中提取的词云显示，“沉浸式”、“引人入胜”、“有启发性”、“实用”等正面词汇是主流。虽然也有“令人困惑”、“无聊”等负面词汇，但主要指向初期的技术小故障或界面延迟，而非核心体验。

**重大发现：**职业兴趣与学业优势的连接：

研究发现，学生在游戏中表现出的职业兴趣与他们的真实学业成绩呈现显著正相关。

例如，在科学（r=0.42）、社会研究（r=0.38）和数学（r=0.35）等科目上都发现了强关联。这表明，这款游戏不仅能测出学生的“兴趣”，还能反映出他们的“优势”。

**6. 讨论与总结**

[图像 32：待版权审查，原图保存在私有归档]

本研究成功证明，通过将AI驱动的互动叙事与严肃游戏相结合，可以**彻底改变传统职业指导的面貌**。与以往依赖预设脚本的教育游戏不同，本研究的**核心创新在于利用AI实现了真正的实时个性化**，从而极大地提升了测评的真实性和学生的参与感。

游戏不仅有效地评估了学生的职业兴趣，其结果还与学生的学业优势高度一致，这为连接职业指导与学业发展提供了双重益处。

当然，研究也存在局限性，如样本可能无法完全代表更广泛的学生群体、自我报告数据可能存在偏见，以及将标准化测试改编为游戏格式的效度问题等。尽管如此，这项研究仍为教育技术领域的创新开辟了新的可能性。

**教学启示**

[图像 34：待版权审查，原图保存在私有归档]

这份开创性的研究，为不同角色的教育相关人员提供了清晰的行动指南：

**对教师与职业规划师的启示：**

告别枯燥问卷：可以利用这类工具，将职业指导从一次性的问卷填写，变为一个持续、有趣、互动的探索过程。

数据驱动的指导：将游戏测评结果与学生的学业成绩相结合，可以为学生提供更全面、更有说服力的个性化指导。

**对学校与教育机构的启示：**

投资未来：投资于AI驱动的个性化指导工具，不仅能提升学生满意度，还可能对学生的长期学业和职业成功产生积极影响。

伦理先行：在应用这类技术时，必须建立严格的数据隐私和安全措施，确保学生数据的安全。

**对游戏/教育技术开发者的启示：**

AI+叙事=蓝海市场：真正的个性化是未来教育游戏的“圣杯”。利用大语言模型进行实时动态叙事生成，将是下一个技术和商业的爆发点。

这是一个绝佳范例：本研究从设计理念、技术架构（Unity + Node.js + GPT-4 API）到评估方法，都提供了一套完整、可行的开发蓝图。

**研究者如何复现与拓展：**

复现：本研究的方法论部分极其详尽，为后续研究提供了坚实的基础。研究者可以在不同文化背景、不同年龄段或使用不同的测评工具（如大五人格测试）来重复和验证这一框架。

拓展：未来的研究可以探索该方法在其他发展领域（如情商、团队协作能力）的应用，或进一步验证其长期影响。

**Gemini锐评**

[图像 36：待版权审查，原图保存在私有归档]

**AI当“算命先生”，真的靠谱吗？**

这项研究最大的亮点，也是最大的“风险点”，就是把一个经过千锤百炼的心理学量表（RIASEC）“魔改”成了一个电子游戏。虽然数据显示结果与传统测试高度相关，但这仍然引出一个灵魂拷问：在科幻故事里选择“帮助一个落难的外星人”，真的能等同于在问卷上勾选“我喜欢帮助别人”吗？将严肃的心理测量“游戏化”，其内在的信度和效度永远是悬在头顶的达摩克利斯之剑。

**为每个学生定制一部“互动电影”，钱包顶得住吗？**

这款游戏的技术核心是为每个玩家的每次决策都调用一次GPT-4 Turbo的API。这听起来非常酷，但也意味着极高的运营成本。对于一个拥有数千名学生的学校来说，这到底是“未来教育”，还是一个“烧钱的无底洞”？在技术成本大幅下降之前，这种高度个性化的体验恐怕还只是少数人的“奢侈品”。

**学习好理科就该当科学家？别让数据强化了刻板印象。**

研究发现学生的职业兴趣与学业成绩正相关，这固然令人鼓舞，但也隐藏着风险。它可能会无形中强化一种观念：“你数学好，所以你应该学工科”，从而限制了学生探索那些他们目前成绩不佳、但未来可能产生浓厚兴趣的领域。好的职业指导应该是拓展可能性，而不是用数据过早地“锁定”人生。

**但这无疑是教育测评的未来！**

尽管存在上述种种挑战，但这项研究的开创性是毋庸置疑的。它标志着一个新时代的黎明：我们终于可以告别那些百年不变、枯燥乏味的静态问卷，走向一个由AI驱动的、动态的、真正“懂你”的个性化评估时代。这不仅仅是一个更好玩的测试，它代表了一种全新的、更人性化、更精准地理解个体的方式。
