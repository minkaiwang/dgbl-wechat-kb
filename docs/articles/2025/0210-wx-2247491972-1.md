**摘要**

[图像 05：待版权审查，原图保存在私有归档]

为了更好地帮助高校毕业生适应其职业生涯早期，大学教育迫切需要弥合课堂理论与行业技能需求之间的鸿沟，尤其是在采购领域。本研究将**体验式学习理论**与**游戏化学习**相结合，提出了一个创新的综合模型。基于该模型，研究采用了一款名为“suPlay”的采购专业游戏，通过一项严格的对照组实验，比较了体验式游戏化学习与传统讲座式教学在培养学生采购技能、认知及情感学习成果上的差异。实验持续四年，共包含337名学生（游戏组N=202, 讲座组N=135）。研究发现，游戏化学习能有效培养与专业实践高度相关的采购与供应链管理（PSM）技能。此外，学生对游戏的学习体验评价极高，并且在大多数技能、认知和情感成果的测量上，游戏组的表现均优于传统讲座组，最终还带来了更高的考试成绩。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

**RQ1:**如何在商业教育，特别是在采购与供应链管理（PSM）领域，有效地设计和实施体验式游戏化学习？

**RQ2:** 在提升学生的表现和学习体验方面，体验式游戏化学习方法与传统讲座式教学相比，效果如何？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

当今的商业环境瞬息万变，对毕业生的实践能力提出了前所未有的高要求。尤其在采购与供应链管理（PSM）领域，从业者需要掌握大量专业技能，而非泛泛的通识教育。然而，传统的讲座式教学常常导致学生难以将理论应用于实践。更糟糕的是，随着生成式人工智能（AI）的兴起，传统的案例教学法也面临危机——AI可以轻易地完成案例分析，削弱了学生的批判性思考。

在这一背景下，以严肃游戏为代表的创新教学法显得尤为重要。严肃游戏作为一种体验式学习，能让学生沉浸在模拟的商业环境中，通过主动参与和反思来发展关键能力。尽管供应链管理领域已有一些教育游戏（如经典的“啤酒游戏”），但**专门针对采购（Purchasing）的严肃游戏却非常罕见** 。本研究正是为了填补这一空白，通过一款名为“suPlay”的专业采购游戏，来系统性地检验体验式游戏化学习的真实效果。

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

本文最大的理论贡献在于，它将两大经典的教育学理论无缝地融合成了一个统一的、可操作的教学设计框架（见原文图3）。

**理论一：科尔布的体验式学习周期 (Experiential Learning Cycle)**

该理论认为，学习是一个通过转化经验来创造知识的过程，包含四个循环阶段：

①具体体验 (Concrete Experience): 亲身参与一个活动。

②反思性观察 (Reflective Observation): 回顾和分析这个体验。

③抽象概念化 (Abstract Conceptualization): 从反思中提炼出普适的理论或概念。

④主动实验 (Active Experimentation): 将新形成的概念应用到新的情境中去。

**理论二：加里斯等人的游戏化学习“输入-过程-输出”模型 (Input-Process-Output Model)**

该模型为设计教育游戏提供了一个清晰的结构：

①输入 (Input): 包含教学内容和游戏特征（如可用性、趣味性、竞争与合作等）。

②过程 (Process): 核心是“游戏循环”，即玩家做出判断、采取行为，系统给予反馈，玩家再根据反馈做出新的判断。

③输出 (Output): 通过游戏后的复盘（Debriefing），将游戏体验转化为具体的学习成果（技能、认知、情感）。

**两大理论的融合：**

本研究创造性地将“游戏循环”嵌入到“体验式学习周期”之中。在游戏中，玩家的每一次决策（用户行为）都构成一次“具体体验”；游戏系统提供的实时反馈（如利润变化、供应商满意度）促使玩家进行“反思性观察”；在教师的引导下，玩家将这些观察提炼为策略（抽象概念化）；最后，他们在下一轮游戏中应用新策略（主动实验）。这个融合模型（见原文图3）为设计既好玩又有效的教育游戏提供了坚实的理论基础。

**3. 游戏设计**

[图像 16：待版权审查，原图保存在私有归档]

本研究采用了一款专门为PSM教育设计的在线多人模拟游戏——“suPlay”。

**游戏名称:** suPlay

**核心玩法:**

学生以2-3人为一组，扮演一家中型啤酒厂的采购专员。

游戏模拟了四个“商业年度”，学生从初级采购员一路晋升到首席采购官。

**教学内容与技能对齐：**

游戏的设计与PSM领域的18项核心专业技能（见原文表1）紧密对齐。

游戏的每个“商业年度”都有一个明确的教学主题，并对应不同的采购任务：

第二年（供应商满意度）： 学生需要将供应商视为战略伙伴，通过投资来发展关系，以获取稀缺资源和创新机会。

第三年（成本优化）： 学生需要运用成本削减技术，包括全球采购和开发新供应商。

第四年（创新管理）： 学生需要识别创新型供应商，并与之合作实施创新项目，最后通过“反向拍卖”模块将创新产品卖回市场。

**游戏机制：**

竞争与合作： 游戏创造了一个动态的市场环境。所有团队都在争夺有限的供应商资源，一个团队的决策（如大量采购）会影响其他团队（如导致价格上涨）。同时，游戏也允许团队之间进行合作，如联合采购以降低成本。

实时反馈： 游戏提供一个仪表盘（Dashboard），实时显示各团队的关键绩效指标（KPI），如利润、成本节约、供应商满意度等，营造出强烈的竞争氛围。

**4. 方法与实验**

[图像 20：待版权审查，原图保存在私有归档]

本研究采用了一套非常严谨的前后测对照组实验设计，并持续了四年，数据极具说服力。

**参与者:**共337名学生，来自同一所大学的学士和硕士项目。

实验组（游戏组）： 202人

对照组（讲座组）： 135人

**实验流程 (见原文图4):**

高度可比性： 两组的教学目标、学习材料、授课教师、期末考试完全相同。唯一的区别是教学形式。

实验组： 参加3个90分钟和1个45分钟的游戏课程。每次课程都遵循\*\*“45分钟短讲座 + 45分钟游戏实践 + 课后反思讨论”\*\*的模式（见原文图5）。

对照组： 参加2个90分钟的传统讲座。

**测量工具：**

技能成果（硬指标）： 采用客观的20道选择题期末考试成绩作为核心测量指标，以避免自我报告的偏差。

认知与情感成果（软指标）： 通过问卷测量学生的参与度、精力水平、努力程度、同伴互动、乐趣和享受度等。

技能自评： 游戏组还需完成一份前后测自评问卷，评估自己在18项PSM核心技能上的能力变化。

**5. 结果**

[图像 24：待版权审查，原图保存在私有归档]

**游戏化学习取得了压倒性的胜利！**

技能提升（客观考试成绩）：

连续四年，游戏组的期末考试平均分都显著高于传统讲座组 。

汇总四年的数据，游戏组的平均分（15.67/20）显著优于讲座组（14.59/20），效应量为中等（Cohen's d = 0.477）。

**技能提升（主观自我评估）：**

游戏组学生在所有28项PSM技能的自我评估上，后测得分均显著高于前测。

提升效果最大的技能，正是那些在游戏中被反复练习的核心技能，如“准备询价”、“供应商关系管理”等（效应量d > 0.8）。

**认知与情感体验：**

全面超越！ 游戏组在几乎所有认知和情感维度的得分上，都显著优于讲座组。

尤其在“与同学的互动”上，效应量高达1.90，这是一个非常巨大的差异。

学生们在游戏中感受到了更高的参与度、趣味性和精力水平 。

**6. 讨论与总结**

[图像 32：待版权审查，原图保存在私有归档]

本研究通过一个整合的理论模型和为期四年的严谨实验，强有力地证明了体验式游戏化学习相对于传统讲座的优越性。游戏不仅能更有效地培养学生的专业硬技能（体现在更高的考试分数上），还能带来更积极的认知和情感体验。

**结论是：**在商业教育领域，特别是对于PSM这样实践性强的学科，体验式游戏化学习是一种更优越的教学方法。它不仅能有效应对AI对传统案例教学的挑战，还能更好地弥合学术界与产业界之间的技能鸿沟。

**教学启示**

[图像 34：待版权审查，原图保存在私有归档]

**对教师的启示：**

拥抱GBL： 严肃游戏是提升教学效果的强大工具，尤其适合教授那些动态、复杂、实践性强的商业知识。

遵循“讲授-游戏-反思”模式： 游戏不能完全取代讲授。本文提出的“短讲座输入 + 游戏内化 + 课后反思”的混合模式，是一个非常值得借鉴的黄金法则。

成为“教练”： 在GBL课堂中，你的角色从“知识的灌输者”转变为“学习过程的引导者”，重点在于组织好游戏后的复盘和讨论。

**对学校/商学院的启示：**

投资于高质量的严肃游戏是应对AI时代教学挑战、提升毕业生就业竞争力的有效策略。

GBL能够有效解决大班教学中体验式学习难以实施的痛点。

**对游戏设计师的启示：**

这是一个严肃游戏设计的“样板工程”！

理论驱动设计： 本文的“融合模型”清晰地展示了如何将抽象的教育学理论转化为具体、可操作的游戏设计原则。

与课程内容深度绑定： 游戏的核心任务（成本、创新、供应商关系）与课程的18项核心技能一一对应，实现了完美的“建构性对齐”。

精心设计的竞争与合作机制： 游戏通过模拟真实的市场动态，让竞争和合作变得自然且有意义，这是其高度吸引力的关键。

**对研究者的启示 (如何复现与推进):**

采用严谨的实验设计： 本文的“前后测对照组设计”+“长达四年的数据收集”+“客观考试成绩作为因变量”的组合，是进行GBL效果研究的黄金标准。

未来的方向：

探索GBL在培养软技能（如沟通、领导力）方面的效果。

进行长期追踪研究，评估游戏化学习对知识和技能的长期留存效果。

**Gemini锐评**

[图像 36：待版权审查，原图保存在私有归档]

**拿“学士”打“硕士”，这对照组是不是有点“不讲武德”？**研究最大的一个方法论瑕疵是，实验组是

学士生，而对照组是硕士生 。虽然作者解释说两组的先验知识水平相当，但这终究是两个完全不同的群体。最后得出“学士游戏组成绩优于硕士讲座组”这个惊人结论，虽然能凸显游戏的威力，但也让这个比较的公平性打上了一个大大的问号。

**用爱发电的游戏？作者利益相关声明了解一下**。在利益冲突声明中，作者坦言，本研究所使用的“suPlay”游戏，正是由本研究的两位作者亲自开发的（这...好像也很正常呀） 。这就像是“王婆卖瓜，自卖自夸”。虽然研究过程看起来很严谨，但这种作者既是“运动员”又是“裁判员”的情况，难免会让人对其结果的客观性持一丝保留态度。

**游戏时间更长，效果更好是理所当然？**作者承认，游戏组的总教学时长（3 x 90 + 45 = 315分钟）要显著长于讲座组（2 x 90 = 180分钟）。实验组多出了近一倍的“学习时间”，他们取得更好的成绩似乎也是情理之中。这使得我们很难完全分清，效果的提升究竟是因为“游戏”这种形式更好，还是仅仅因为“学得更久”。

**软技能的“黑箱”：**测了，但又不完全测。尽管游戏设计中包含了大量的合作与竞争元素，非常适合培养沟通、谈判等软技能，但研究却以“难以客观测量”为由，

将软技能排除在了核心分析之外 。这无疑是一个巨大的遗憾，也让这次评估的全面性打了折扣。
