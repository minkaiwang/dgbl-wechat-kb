**Title**

The impact of different combinations of game elements for gamified learning in higher education on student learning outcomes: a multilevel meta-analysis

高等教育中不同游戏元素组合对学生学习成果的影响：一项多层次元分析

**DOI**

10.1080/03075079.2024.2416498

**Keywords**

Gamified learning (游戏化学习); combination of game elements (游戏元素组合); higher education (高等教育); multilevel meta-analysis (多层次元分析); learning outcomes (学习成果)

**作者**

Wei Xu, Guang-Ru Xu & Qian-Wen Xing

**期刊**

Studies in Higher Education

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

本研究通过一项多层次元分析，系统评估了游戏化学习在高等教育中的整体效果，共整合了2013年至2024年间32项研究中的143个效应量。研究的核心在于，评估了不同游戏元素组合对学生认知、技能和情感三类学习成果的影响。研究发现，与非游戏化教学相比，游戏化学习对学生的学习成果有中等程度的积极影响 (g=0.515) 。其中，对认知成果 (g=0.716) 和技能成果 (g=0.605) 的影响达到中等偏高水平，而对情感成果 (g=0.317) 的影响则为中等偏低。研究还为三类学习成果找到了各自的“最佳游戏元素组合配方”。这些发现为教育工作者设计有效的游戏化学习体验提供了明确的指导。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

**RQ1:**游戏化学习在高等教育中是否可行？具体来说，实施游戏化学习的总体效应量是多少？

**RQ2:**在高等教育的不同教学过程（认知、技能、情感）中，应如何选择合适的游戏元素组合？

**RQ3:**在高等教育的教学过程中，不同学习领域和干预时长如何调节游戏化学习对学习成果的影响？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

游戏化作为一种流行技术，已被广泛应用于商业、健康和教育等多个领域。然而，尽管许多研究证实了游戏化能提升学生参与度、互动性和学业表现，但也有研究报告了平庸甚至负面的效果。一个核心的难题在于，研究者们通常将多个游戏元素（如积分、徽章、排行榜）捆绑使用，导致我们无法确切知道到底是哪个元素或哪种组合在起作用。因此，本研究旨在通过元分析的方法，专门探究在高等教育情境下，不同游戏元素的“组合拳”对学习成果的真实影响。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

**学习成果的分类：**本研究采用Garris等人（2002）的经典分类法，将学习成果分为三类：

认知成果：包括事实性知识、程序性知识和策略性知识。

技能成果：指技术或运动技能的掌握。

情感成果：包括自信心、自我效能感、态度和偏好等。

**游戏元素的分类框架：**为了系统地分析游戏元素，本研究采用了Toda等人（2019）提出的、经过专家验证的五维分类框架，该框架与教育情境高度相关。这五个维度是：

表现/测量 (Performance/Measurement)

生态 (Ecological)

社交 (Social)

个人 (Personal)

虚拟 (Fictional)

[图像 12：待版权审查，原图保存在私有归档]

**3. 方法**

[图像 13：待版权审查，原图保存在私有归档]

由于本研究是一项元分析，它并未设计一个新游戏，而是对现有研究中的游戏化设计进行了系统的

分类和编码。其核心“设计”在于采用了Toda等人（2019）的五维游戏元素分类框架，这是整个研究的分析基石。

**五维游戏元素分类框架:**

表现/测量 (P/M): 与环境反馈相关的元素，用于向学习者展示其表现。例如：积分、进度条、等级、统计数据、成就/徽章 。

生态 (E): 与学习环境的属性相关的元素。例如：机会/随机性、强加选择、经济系统、稀有度、时间压力 。

社交 (S): 与学习者之间的互动相关的元素。例如：竞争、合作、声望、社交压力 。

个人 (P): 与学习者自身相关的元素。例如：感官刺激、目标、谜题、新颖性、更新/改造 。

虚拟 (F): 融合了用户与环境的混合维度。例如：叙事和故事情节 。

研究团队将32篇文献中的游戏化设计，按照这五个维度的组合进行了编码，最终形成了五种主要的组合类型进行分析。

**4. 方法与实验**

[图像 17：待版权审查，原图保存在私有归档]

**研究方法：**采用多层次元分析 (Multilevel Meta-analysis) 。

**为何选择此方法？**传统元分析要求所有效应量相互独立，但许多研究会报告多个来自同一批被试的效应量，这打破了独立性假设。多层次模型能够科学地处理这种数据的“嵌套结构”（即多个效应量嵌套在同一项研究中），从而得出更准确的估计结果。

**文献筛选：**通过Web of Science、Scopus等六大数据库，检索了2013年1月至2024年7月期间的文献。经过严格的筛选流程，最终纳入了32项研究，共包含143个效应量和3388名被试。

**数据编码：**两名研究者独立对文献进行编码，内容包括：研究基本信息、游戏元素组合（根据五维框架）、学习领域、干预时长、学习成果类型以及计算效应量所需的数据。

**统计分析：**

效应量计算：采用Hedges' g作为效应量指标，因为它对小样本研究的偏差进行了校正。

模型构建：使用R语言的metafor包构建三层次元分析模型，分别评估总体效应、不同元素组合的效应以及调节变量（学习领域、干预时长）的影响。

**5. 结果**

[图像 22：待版权审查，原图保存在私有归档]

**游戏化学习的总体效果**

游戏化学习对高等教育学生的整体学习成果有显著的中等程度积极影响（g = 0.515, p < .001） 。

分类来看：对认知成果（g = 0.716）和技能成果（g = 0.605）的影响达到了中等偏高水平；而对情感成果（g = 0.317）的影响则为中等偏低 。

**不同游戏元素组合的效果（核心发现）**

研究揭示了针对不同学习目标的“最佳配方”：

①促进认知成果的最佳组合：P/M + E + S + P（表现/测量 + 生态 + 社交 + 个人），效应量高达 g = 0.897 。

②促进技能成果的最佳组合：P/M + S + P（表现/测量 + 社交 + 个人），效应量达到了惊人的 g = 0.993 。

③促进情感成果的最佳组合：P/M + E + S + P + F（表现/测量 + 生态 + 社交 + 个人 + 虚拟），效应量为 g = 0.627 。

④值得警惕的组合：仅有P/M以及P/M + S + P的组合，对情感成果产生了负面影响 。

**调节变量的影响**

学习领域：游戏化在工程学、人文艺术、社会科学等领域均有显著的中等积极效应。但在数学科学领域，其效果微乎其微且不显著（g = 0.089）。

干预时长：时长有显著的调节作用。效果最好的是“一天以内”的短期干预（g = 1.186），可能是由于新奇效应。而效果最差的是“三到六个月”的干预（g = 0.379），此时新奇感已消退，而内在动机可能尚未完全建立。

**6. 讨论与总结**

[图像 31：待版权审查，原图保存在私有归档]

这项研究为高等教育中的游戏化学习实践提供了强有力的证据和精细化的指导。

**游戏化确实有效：**总体来看，游戏化学习是一种比传统教学更有效的方法，尤其在提升认知和技能方面。

**情感提升是短板：**游戏化对情感成果的影响较弱，这可能是因为当前的游戏化设计更侧重于外在激励和表现，而忽视了内在心理需求的满足。过度强调竞争和排名甚至可能带来压力和焦虑，对情感产生负面影响。

**“组合”是关键，不存在万能元素：研究最大的贡献在于揭示了“对症下药”的重要性。**

想提升认知？你需要一个包含反馈、动态环境、社交互动和个人挑战的复杂系统。

想训练技能？你需要一个聚焦于反馈、同伴互动和明确任务的精简组合，避免无关元素（如故事、随机性）增加认知负荷。

想涵养情感？你需要一个能够满足学生自主、胜任和归属感等基本心理需求的“全家桶”，特别是加入“叙事/故事”这类虚拟元素，让学习更有意义。

**教学启示**

[图像 33：待版权审查，原图保存在私有归档]

**对教师的启示**

按需“配菜”，而非“大杂烩”：教师在设计游戏化教学时，应首先明确教学目标是认知、技能还是情感，然后参照本研究的“最佳配方”来选择游戏元素组合。

认知目标：引入进度条、排行榜等反馈机制，并设计新颖的、带有社交互动性的挑战任务。

技能目标：设计包含反馈和团队协作的模拟操作场景，但要避免过多的游戏元素分散学生注意力，造成认知过载。

情感目标：避免过度依赖分数和排名。多采用能满足学生心理需求的元素，如提供选择（自主）、设置合作任务（归属）和角色扮演（代入感）。

**对学校的启示**

推广游戏化时需考虑学科差异：游戏化并非在所有学科中都同样有效。在工程、人文等实践性、互动性强的学科中可以大力推广。但在数学等强调抽象逻辑思维的学科，需要更谨慎地设计和探索适合其特点的游戏化策略。

**对游戏设计师的启示**

从关注“元素”到关注“组合效应”：本研究为设计师提供了一份宝贵的“设计指南”，清晰地指出了不同元素组合的优劣势。

情感设计需谨慎：要特别注意，单纯的“表现/测量”类元素（如积分、排名）可能会损害用户的情感体验。在设计时，必须用满足内在需求的元素（如选择、合作、故事）来平衡外在激励。

**研究者如何复现**

采用多层次元分析模型：这是处理有依赖性的效应量的标准做法，能显著提升元分析的准确性。

使用成熟的分类框架：Toda等人（2019）的五维游戏元素分类框架为后续研究提供了一个可靠的编码工具。

关注调节变量：未来的研究可以继续深入探索其他调节变量（如文化背景、学生个人特质）对游戏化效果的影响。

**Gemini锐评**

[图像 35：待版权审查，原图保存在私有归档]

**终于有“说明书”了！** 这篇研究最大的价值，就是把游戏化设计从一门“玄学”变成了一门“配方科学”。它告诉我们，别再盲目地往课程里堆砌积分、徽章、排行榜了，搞不好还会起反作用。想达到什么教学效果，就按“配方”来，简单、直接、有效！

**情感成果的“惨淡”数据，打了谁的脸？**游戏化最常吹嘘的就是能“激发动力、提升情感”，结果这篇元分析发现，它在这方面的效果最差，甚至某些组合还有副作用。这无疑是对那些只注重外在激励、把学生当成“巴甫洛夫的狗”一样训练的游戏化设计的当头一棒。

**数学学科再次成为“游戏化黑洞”。**研究发现游戏化在数学领域效果不佳，这与之前的某些研究结果一致。这是否意味着，对于高度依赖抽象逻辑思维的学科，目前流行的这些“花里胡哨”的游戏化元素根本无法触及其学习的核心？这值得所有数学教育者和游戏设计师深思。

**短期干预效果最好？**这到底是“鸡血”还是“疗效”？ “一天内”的干预效果拔群，这听起来更像是“新奇效应”带来的昙花一现。这种“三分钟热度”式的提升，到底有多大的教育价值？研究虽然给出了动机转变的解释，但这依然是游戏化学习有效性中最令人不安的一个谜团。
