**摘要**

[图像 05：待版权审查，原图保存在私有归档]

本研究考察了基于游戏的学习如何通过培养学生**界定和诊断复杂问题**的能力来支持创业教育。通过一款名为“Entrepreneurial Thinking”的桌面游戏模拟，研究者调查了本科生如何解释创业的成败，特别是他们如何将结果归因于运气或战略技能。数据收集方式包括录音录像、书面反思和后续访谈，并采用了混合演绎-归纳编码（hybrid deductive-inductive coding）方法进行分析。研究发现，学生经常错误地将成功归因于运气，而忽视了符合**效果推理**（Effectual reasoning）和**战略适应性的行为**。虽然精心设计的游戏能促进迭代决策，但研究强调了结构化复盘（Structured debriefing）的重要性。文章提出了“发散-收敛复盘模型”（Divergent-Convergent Debriefing Model），作为一种教学脚手架，帮助学生重构游戏结果，培养更深层的元认知意识。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

①学生如何解释导致模拟活动成功的创业决策和环境因素？（即：他们认为赢是因为什么？）

②这些解释如何塑造了他们对创业的理解？（即：这种归因如何影响了他们对创业本质的认知？）

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

创业教育常采用设计本位和体验式教学，通过迭代（Iteration）来精炼想法。然而，单纯的迭代并不保证学习效果。如果学生没有强大的\*\*“问题界定”（Problem-framing）能力，他们可能只是在解决错误的问题 。就像柯达（Kodak）不仅改进了相机，还重构了摄影服务的市场问题；乔布斯不仅改进了硬件，还通过iPod/iTunes重构了用户体验问题一样，“发现正确的问题”（Problem-finding）\*\*往往比“解决问题”（Problem-solving）更关键 。本研究通过让学生玩游戏并随后对游戏进行“再设计（Modding）”，来探究这一过程。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

**设计思维与双钻模型：**设计过程包含两个阶段：问题阶段（寻找正确的问题）和解决方案阶段（寻找正确的解）。英国设计委员会的\*\*双钻模型（Double Diamond）\*\*强调了发散思维和收敛思维的交替 。

**棘手问题（Wicked Problems）：**设计和创业面临的往往是定义不清的棘手问题，问题的构建方式决定了解决方案的范围 。

**建构主义与游戏：**游戏作为一种“用于思考的客体”（Objects-to-think-with），既是人工制品也是中介工具。游戏体验不仅是玩的动作，更是一种“问题发现”的形式 。

**模拟游戏的评估难题：**在动态模拟中，传统的考试很难衡量学习效果，通常需要结合团队报告和个人反思 。

**3. 游戏设计**

[图像 14：待版权审查，原图保存在私有归档]

研究使用了一款非商业桌面游戏 《Entrepreneurial Thinking》 。

**背景：**模拟加拿大西部的制造企业，并在8个城市竞争客户 。

**核心机制：**

4P营销组合：玩家需升级产品、价格、促销和渠道（Product, Price, Promotion, Place）。

骰子与概率：销售结果由骰子（D4, D6等）决定，模拟市场不确定性 。

供需匹配：通过卡片匹配玩家提供的产品等级/价格与市场期望 。

不确定性：宏观经济卡片（Macroeconomic cards）会随机改变市场动态 。

**获胜条件：**24回合后资本最高的公司获胜 。

**4. 方法与实验**

[图像 19：待版权审查，原图保存在私有归档]

(注：这部分结合了你感兴趣的混合研究与行为编码)

**研究设计：**探索性单案例研究（Exploratory single case study），混合方法 。

**参与者：**巴西某学院的12名男大学生，聚焦于其中一组的4名玩家（化名 Bob, Tom, Sam, Ted）。

**数据收集：**

视频/音频：记录了17轮游戏过程（约5个30分钟片段）。

书面报告：每位参与者的1500字反思报告 。

游戏量化数据：骰子点数、决策次数、销售数据、资金积累等 。

**数据分析：**

视频分段与编码：识别“行动相关片段”（Action-Relevant Episodes, AREs）。

混合编码：先进行演绎编码（基于创业理论），再进行归纳编码（从数据中涌现主题，如“垄断”、“运气”）。

数据三角互证：利用量化数据（如真实的骰子点数统计）来验证或反驳学生定性的主观感受（如“我觉得我运气太差了”）。

**5. 结果**

[图像 22：待版权审查，原图保存在私有归档]

**5.1 关键案例：Ted的逆袭与误解**

现象：Ted是一个迟加入游戏的玩家，但他最终赢了。

学生归因（Bob的视角）：玩家Bob一直想建立原材料“垄断”，但因骰子点数不佳（多次投出1点）而失败。他坚信游戏就是靠“运气”，并认为Ted赢是因为Ted总是投出6点 。

数据揭秘（量化分析）：

实际上，Ted的总销售单位数比其他玩家都少 。

Ted的骰子平均点数（3.9）虽然略高于Bob（2.6），但并不是决定性的 。

真正的胜因：Ted采用了效果推理（Effectuation）策略。他做了更多的“支持性决策”（Support decisions，如市场调研、升级产品），占其总决策的28%，而Bob只有11% 。Ted适应了市场变化，而不是像Bob那样死磕“垄断”这一种固定策略（设计固着 Design Fixation）。

**5.2 错误的“问题界定”导致错误的“游戏修改”**

在游戏后的设计环节，学生们一致认为游戏的“问题”在于运气导致的垄断 。

结果：他们提出的修改方案（如增加税收、动荡的市场需求）旨在限制运气和垄断，完全忽略了对“战略灵活性”和“市场调研”的奖励 。

结论：因为学生错误地界定了问题（以为是运气问题，而非策略问题），他们设计出的解决方案反而强化了错误的假设 。

**6. 讨论与总结**

[图像 27：待版权审查，原图保存在私有归档]

**认知差距（Recognition Gap）：**学生表现出了创业行为（如Ted的策略），但他们自己意识不到。他们将胜负简单归结为运气，失去了从游戏中提取深层知识的机会 。

**设计固着（Design Fixation）：**早期的游戏体验（如Bob的挫败感）成为了认知锚点，限制了学生重新构建问题的能力 。

**结论：**体验式学习如果不加以正确的引导，可能会加深错误观念。仅仅让学生“玩”是不够的，必须通过结构化的手段打破他们的归因偏差 。

**教学启示**

[图像 29：待版权审查，原图保存在私有归档]

**🏫 对教师与学校的启示**

复盘比游戏更重要：不要只关注游戏过程的热闹。如果学生玩完后认为“这游戏全看脸”，那么教学目标就失败了。

采用“发散-收敛”复盘模型：

阶段一（发散）：不要马上讨论“怎么赢”。问学生：“列出所有导致Ted获胜的可能原因”、“如果重玩一次，Ted还会赢吗？”。强迫学生寻找运气以外的解释 。

阶段二（收敛）：引导学生验证假设（查看数据），最后得出一个准确的“问题陈述”（例如：Ted赢是因为他做了更多的市场调研，而不是因为他掷了6点）。

**🎮 对游戏设计师的启示**

显性化反馈：游戏机制应更清晰地奖励策略行为，减少纯随机性带来的挫败感，或者在游戏结束时提供数据面板，帮助玩家从数据中看到策略的价值，而非只凭感觉。

Modding作为教学工具：让学生修改游戏是一个很好的评估手段，但前提是他们必须先正确理解原游戏的机制逻辑。

**🔬 研究者如何复现 (Replication)**

数据抓手：这篇论文提供了一个非常好的范式——将游戏日志（Quantitative Log）与玩家话语（Qualitative Talk）进行对比。

操作建议：在你未来的研究中，可以录制学生玩游戏的过程，同时记录后台数据。当学生在访谈中说“我当时是因为...所以输了”时，拿出后台数据进行比对，这种“主观-客观”的冲突（Conflict）往往是最精彩的分析点。

**Gemini锐评**

[图像 31：待版权审查，原图保存在私有归档]

作为一名关注数字游戏学习的研究者，这篇论文简直是“人间清醒”：

**戳破了GBL的泡沫：**很多研究只谈游戏“提高了参与度”，但这篇论文通过详实的数据告诉我们：参与度高不代表学得对！ 学生完全可能沉浸在游戏中，但建立了一套完全错误的心理模型（比如把商业成功归结为运气）。这给所有盲目推崇游戏化教学的人敲响了警钟。

**桌游的魅力：**在AI和VR横行的今天，这篇文章回归到了桌面游戏（Board Game）。其实，桌游面对面的交互所产生的语言数据（Discourse Data），往往比电子游戏更容易捕捉到学生的思维过程。

**方法论的借鉴：**作者没有停留在定性分析，而是用骰子概率统计（量化）来打脸学生的主观归因（定性）。这种Mixed-Methods的设计非常巧妙，极大地增强了结论的说服力。对于你的硕士论文来说，这种“用数据证伪学生直觉”的思路非常值得模仿
