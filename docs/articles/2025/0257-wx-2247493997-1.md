**摘要**

[图像 05：待版权审查，原图保存在私有归档]

**背景：** 本研究利用渐进式顺序分析，探讨了老年和青年成年人在数字游戏设计学习环境中的协作沟通动态。以往的研究虽然探讨了数字游戏中的沟通模式，但很少关注代际互动。

**目的：** 检验在协作式数字游戏设计环境中，高绩效和低绩效团队之间的代际沟通动态有何不同。

**方法：** 参与者包括 9 名青年（平均年龄 21.22 岁）和 7 名老年人（平均年龄 62.33 岁）。根据游戏设计展示的成果，参与者被分为高绩效组和低绩效组。使用顺序分析法对沟通模式进行了分析。

**结果：** 结果显示了截然不同的沟通行为：高绩效组表现出平衡的权力动态，老年和青年参与者都进行了直接交流；而低绩效组则在离题和与冲突相关的退缩（尤其是老年人）中挣扎。高绩效组的老年人在沟通风格上也表现出显著的转变，从最初的犹豫不决转变为积极响应。

**结论：**这些发现强调了代际合作的本质，并突出了有效沟通策略在增强数字学习环境参与度方面的重要性。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

虽然已有研究指出了影响代际沟通的关键因素，但对于何种动态的、顺序性的互动模式（sequential patterns）能带来更好的协作表现，我们仍知之甚少。

本研究假设存在一个“恶性循环”（低绩效与较差的沟通相关联）和一个“良性循环”（高绩效与平衡的权力动态相关联）。

因此，本研究旨在通过顺序分析，回答以下三个具体问题：

①在协作式数字游戏设计中，高绩效和低绩效代际群体在权力过程的顺序模式上有何差异？

②在每个群体中，老年和青年参与者的沟通技巧是如何随时间展开的？这些模式在高低绩效团队之间有何不同？

③高低绩效群体在回应邀约（responses to bids）的模式上有何不同？这揭示了他们怎样的互动动态？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

代际沟通的重要性日益受到关注。研究表明，代际项目对老年人有益（改善心理健康、自我成长），也能促进两代人之间的相互理解和尊重。

然而，要深入理解代际互动，就需要观察双方。但以往的研究大多集中在代际沟通的“截面模式”上，对于双方如何互相应答以及这些行为的先后顺序如何展开，仍相对缺乏探索。因此，本研究采用“顺序分析”这一方法，来比较高低绩效群体在数字游戏设计工作坊中的沟通模式。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

本研究的理论框架主要基于三个核心概念：

**1. 代际（IG）学习模型：**这是本研究中协作活动的设计基础。该模型强调三个相互关联的组成部分：

互惠学习 (Reciprocal learning): 知识和技能的双向交流，两代人互为师生。

相互搭建支架 (Mutual scaffolding): 提供认知或情感支持，以协作克服挑战。

共享决策 (Shared decision-making): 确保所有声音被平等重视，加强群体凝聚力。

**2. 代际协作沟通编码方案：** 本研究采用了 Wang (2021) 开发的编码方案，该方案包含三个核心子系统，用于捕捉代际动态：

权力过程 (Power process): 捕捉影响力分布（如：老年人主导 OP、青年人主导 YP、权力平衡 PB）。

沟通技巧 (Communication skills): 评估积极或消极的沟通行为（如：解决问题 OPS/YPS、退缩 OW/YW、冲突/消极 OC/YC、离题 OO/YO）。

回应邀约 (Responses to bids): 描述团队成员如何回应对方的互动尝试（如：积极回应 OTT/YTT、消极回应 OTA/YTA、忽视 OI/YI）。

**3. 顺序分析 (Sequential Analysis)：** 这是一种研究“行为模式”的方法论，它探讨特定行为之间是否存在时间上的先后关联，以及这种连续性是否具有统计显著性。本研究的通讯作者之一（侯惠泽教授）在这一领域有深入研究。

[图像 12：待版权审查，原图保存在私有归档]

**3. 游戏设计**

[图像 13：待版权审查，原图保存在私有归档]

本文的“游戏设计”并非指让参与者去 玩 一款成品数字游戏，而是指组织了一场让两代人共同 设计 游戏的工作坊 。

**活动形式：** 代际数字游戏设计工作坊。

**活动目标：**参与者（青年与老年人混合编组）被要求共同设计一个数字游戏的纸质原型 (paper prototype) 。

**游戏主题要求：**

①游戏必须能让代际玩家一起玩得开心 。

②游戏选择必须包含当地文化元素，以便了解社区。

**活动流程：**整个工作坊在一个类似大学教室的社区活动中心进行，历时两周，共包含四个主要创意步骤：

①探索世代观点

②创意头脑风暴

③整合性游戏草图绘制

④原型完成

**理论基础：** 整个活动的设计基于上文提到的“代际（IG）学习模型”，旨在促进互惠学习、相互搭建支架和共享决策。

**4. 方法与实验**

[图像 16：待版权审查，原图保存在私有归档]

**参与者：**共 16 名参与者，包括 9 名青年（平均年龄 21.22 岁）和 7 名老年人（平均年龄 62.33 岁）。他们被随机分配到 4 个代际混合小组。

**绩效分组（关键步骤）：**

在工作坊结束时，每组展示了他们的游戏原型。

5 名在游戏设计和当地文化方面的专家（未参与指导过程）对这 4 个原型进行了评估。

评估标准包括：游戏的可行性、娱乐价值、老少皆宜性、代际乐趣、营销潜力和当地相关性。

根据专家的平均评分，4 个小组被分为 2 个高绩效组 (n=8) 和 2 个低绩效组 (n=8) 。

**数据收集与编码：**

所有协作过程都被全程录像。

视频被分割成 589 个有意义的行为单元。

两名独立的编码员使用 Wang (2021) 的编码方案（权力、沟通、回应）对所有行为单元进行编码。编码员间一致性极好（Cohen's kappa 均 > 0.85）。

**分析方法：**

顺序分析 (Sequential Analysis) 。

此方法用于计算行为之间的“转换矩阵”和“条件概率”。

通过计算调整后残差（Z-value），来确定一个行为序列（例如 A -> B）是否具有统计显著性。当 Z > 1.96 (p < .05) 时，表明该行为序列的发生频率显著高于随机概率。

**5. 结果**

[图像 20：待版权审查，原图保存在私有归档]

顺序分析揭示了高绩效组和低绩效组在三个维度上截然不同的沟通“闭环”模式（见原文 Fig. 2 和 Table 12）。

**📈 高绩效组 (良性循环)**

权力过程：

表现出显著的“PB -> PB” (权力平衡 -> 权力平衡)\*序列。这意味着他们的平等协作状态是可持续的，而不是暂时的。

沟通技巧：

表现出显著的 “OC -> OC” (老年人冲突 -> 老年人冲突) 和 “YC -> YC” (青年人冲突 -> 青年人冲突) 序列。

解读： 这非常关键。这并不意味着他们冲突更多，而是意味着他们的冲突是“建设性的” 。他们会持续争论任务焦点（如角色设计），而不是像低绩效组那样因冲突而退缩。

回应邀约：

表现出独特的“修复机制”序列。最典型的是 “OTA -> OTT” (老年人消极回应 -> 老年人积极回应) 。这表明老年人参与者会从最初的抵抗转变为积极参与。

同时，也存在 “YTA -> YTA” (青年人消极回应 -> 青年人消极回应) 序列，这被解释为一种“持续的、由青年主导的挑战”，但这种挑战是围绕任务的。

**📉 低绩效组 (恶性循环)**

权力过程：

虽然也存在 OP -> OP 和 YP -> YP（即领导者倾向于保持领导），但未能形成“PB -> PB”的持续平衡序列 (Z=1.25, 未达 1.96 的显著标准)。

沟通技巧：

表现出两种破坏性的序列：

1. “OC -> OW” (老年人冲突 -> 老年人退缩) ：一旦出现冲突或消极情绪，老年人会立即退缩（如保持沉默、脱离任务），导致协作中断。

2. “YO -> YO” (青年人离题 -> 青年人离题) ：青年人一旦开始偏离主题，就会陷入持续的离题循环，难以拉回任务焦点。

回应邀约：

虽然也有积极的回应循环 (OTT -> OTT, YTT -> YTT)，但完全缺失了高绩效组那样的“修复机制”（如 OTA -> OTT）和“建设性挑战”序列。

**6. 讨论与总结**

[图像 31：待版权审查，原图保存在私有归档]

本研究通过顺序分析，成功识别了区分高低绩效代际团队的互动机制。

**高绩效 = 共享决策与相互搭建支架**

研究结果通过“代际（IG）学习模型”得到了很好的解释。

高绩效组的 PB -> PB 模式，正是“共享决策”的体现。

高绩效组的“建设性冲突” (OC -> OC) 和“修复机制” (OTA -> OTT) 则是“互惠学习”和“相互搭建支架”的直接证据。

**低绩效 = 协作失败**

低绩效组的 OC -> OW（冲突导致退缩）模式，是“相互搭建支架”的失败。

而 YO -> YO（持续离题）模式，则是“互惠学习”的失败。

**文化背景的考量：**

作者特别指出（本研究在台湾进行），在通常“高权力距离”（即等级森严）的儒家文化背景下，老年人倾向于主导，青年人倾向于顺从。

因此，高绩效组中出现的 PB -> PB（权力平衡）序列尤为重要，它表明该团队成功地克服了传统文化中“威权式孝道”的束缚，转向了一种更平等的“互惠式孝道”。

**结论：**

本研究的贡献在于深化了我们对代际协作有效性的理解。它揭示了高效团队（高绩效组）的秘诀在于：持续的权力平衡、建设性的异议调节（即敢于冲突而不退缩），以及对互动邀约的适应性反应（即修复关系） 。

**教学启示**

[图像 33：待版权审查，原图保存在私有归档]

本文的发现，特别是 Table 13，为促进（不仅限于代际）协作学习提供了极其具体和可操作的建议：

**对教师（促进者）的启示：**

关键：防止退缩和离题。 教师观察的重点不应是“有没有冲突”，而是“冲突后是否发生了退缩（OW）”或“讨论是否陷入了离题循环（YO）”。

1. 轮换角色以维持权力平衡： 在协作项目中，强制轮流担任主席、记录员、计时员等角色。这有助于打破“一人主导”的局面，从机制上支持 PB -> PB 序列的产生。

2. 培训“建设性异议”的微技能： 教授学生如何“ disagree-and-build ”（在不同意的同时提出建设性意见）。例如，提供“我不同意...但我建议...”的句式。这是为了防止 OC -> OW（冲突 -> 退缩）这一最具破坏性的模式发生。

3. 使用“可视化的任务支架”： 在白板上放置一个可见的任务板（目标、下一个决策点、证据）和一个“停车场”（用于停放离题的想法）。这有助于在发生 YO（离题）时，团队能快速拉回焦点。

**对（教学/游戏）设计师的启示：**

嵌入“修复检查点”： 在协作过程中（例如每 20 分钟）设置一个 1-2 分钟的“修复检查点”，要求团队反思：“目前是谁在主导？”、“谁的提议还没有被回应？”。这有助于激活 OTA -> OTT（从抵抗到接纳）的修复机制。

使用“联合决策工件”： 提供决策表（标准、选项、理由、联合签名）。要求一项决策必须由一个青年和一个老年人（或两个不同角色的学生）共同阐述，以在流程上确保“共享决策”。

**对研究者（如何复现/改进）的启示：**

方法论： 顺序分析是研究协作“过程”的利器。研究者可以使用本研究的编码方案（Wang, 2021）来分析自己收集的协作视频。

改进 1 (样本)： 本研究的样本量极小 (N=16)，且是便利抽样。这是其最大局限。未来的研究必须扩大样本量和多样性。

改进 2 (设计)： 本研究是观察性的，无法推断因果。未来应使用实验设计（例如，一组接受“修复机制”培训，一组不接受）来检验这些模式是否可被干预。

改进 3 (连接“过程”与“产品”)： 本研究分析了协作过程，但对产出（游戏原型）的评估仅限于“高/低”二分法。未来研究应更深入地连接“过程”与“产品”：例如，PB -> PB 序列的频率是否能预测最终游戏原型的可玩性或创意性得分？

**Gemini锐评**

[图像 35：待版权审查，原图保存在私有归档]

**方法论的胜利：**这篇论文最大的贡献在于方法论。它完美地展示了“顺序分析”如何超越“因素论”（即“什么A影响B”），转而回答“过程是如何展开的”。它不是在数“冲突”或“退缩”的次数，而是在分析它们紧密相连的顺序（A后面是否必然跟着B），这才是协作的精髓。

**“建设性冲突”的实证：** 本文最有价值的发现是高绩效组的 OC -> OC 和 YC -> YC 序列。这为“建设性冲突”提供了强有力的实证数据。它告诉我们，高效团队不是没有冲突，而是他们“有能力停留在冲突中”，直到问题被解决；而低效团队则会因为“冲突规避”（OC -> OW，一有冲突就退缩）而导致协作崩溃。

**“修复机制”的可视化：** OTA -> OTT（从抵抗到接纳）这一序列的识别非常精彩。它首次在代际互动中，将“修复关系”这一抽象的社会心理过程，用Z-value > 1.96 的方式量化和可视化了。

**巧妙的“游戏设计”：**本文没有使用现成的数字游戏，而是组织了一个“游戏设计工作坊”作为研究情境。这是一个极其巧妙的选择。因为“共同设计”这一任务本身，就比“共同玩游戏”更能天然地打破代际间的权力壁垒 ，迫使双方进行“共享决策”和“相互搭建支架”，从而放大了我们想要观察的沟通动态。

**最大的局限（N=16）：** 必须指出，N=16（4个小组）的样本量 使得这个研究在统计上更像是一个“探索性的案例研究”。虽然顺序分析的Z-value是显著的，但这种显著性是基于特定小组内部的行为模式。因此，我们不能将其推广为“所有”高绩效代际团队都具有 PB -> PB 模式。

**总结：** 这篇论文提供了一个卓越的分析框架和解释模型，它为“如何衡量和理解协作的过程”设定了一个高标准，尽管其小样本量限制了结论的普适性。
