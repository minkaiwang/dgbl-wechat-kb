**摘要**

[图像 05：待版权审查，原图保存在私有归档]

游戏化学习（GBL）作为一种体验式学习方法，在项目管理（PM）培训领域广受认可。然而，尽管GBL在研究界声誉卓著，其在高等教育中的实际应用率却长期停滞不前。为了推动其广泛应用，本系统综述旨在揭示项目管理游戏化学习（PM-GBL）研究的关键发现、趋势和空白。研究采用PRISMA框架，筛选了50篇关于项目管理严肃游戏（PM-SGs）的案例研究。内容分析确定了五大主题：

试点研究、案例研究、比较研究、学生自制游戏和游戏设计趋势 。此外，文献计量分析揭示了该领域研究在时间和地域上的分布特征。最终，本文为严肃游戏的设计、开发、实施和评估提出了关键的未来研究方向。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

作为一篇系统综述，本文没有设立传统的实证研究问题。其核心目标是：

系统性地梳理和展示项目管理游戏化学习（PM-GBL）的研究现状。

整合过去十年的关键发现，为GBL的开发者和采纳者提供实践指南。

识别出现有研究中的空白，并为严肃游戏在设计、开发、实施和评估方面指明未来的研究方向。

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

随着各行业项目日益复杂，项目管理（PM）能力变得至关重要。为了培养学生的实践能力，高等教育急需有效的体验式学习方法。基于建构主义学习理论的游戏化学习（GBL），尤其是严肃游戏（SGs），通过模拟简化版的真实世界系统或流程，让学习者在无风险的环境中进行实践和实验，与PM教育的需求完美契合。

尽管研究反复证明GBL能提升学生的社会技术技能、批判性思维，并增强学习投入度和反思能力，但它在高校PM课程中的应用率却出奇地低 。本研究正是为了解决这一“叫好不叫座”的困境，通过全面梳理现有实证研究，试图为PM-GBL的普及铺平道路。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

严肃游戏（SG）的分类： 本文将PM领域的严肃游戏（PM-SGs）从两个维度进行分类：

**界面 (Interface):**

数字游戏 (Digital games): 通过电脑、手机或VR头显进行。

桌面游戏 (Tabletop games): 使用棋盘、卡牌、纸笔等实体道具。

混合游戏 (Hybrid games): 结合了数字和桌面游戏的元素。

**互动 (Interaction):**

单人游戏 (Single-player) 。

合作多人游戏 (Cooperative multiplayer) 。

竞争多人游戏 (Competitive multiplayer) 。

研究现状： 尽管之前已有多篇综述，但它们要么年代较早，要么仅关注PMBOK知识领域的覆盖度，或局限于特定子领域（如软件项目管理）。目前，

缺乏一篇能全面反映近十年来PM-GBL实证研究全貌的综述，特别是关于研究方法、游戏设计趋势和学习效果的综合分析。

[图像 12：待版权审查，原图保存在私有归档]

**3. 游戏设计**

[图像 13：待版权审查，原图保存在私有归档]

本综述分析了37款不同的严肃游戏，揭示了当前PM教育领域游戏设计的核心趋势和特点：

**主流设计范式：**

数字单人游戏 和 桌面合作游戏 是最常见的两种设计。数字游戏占比最高（62%），其中又以单人模式为主（41%）。桌面游戏位居第二（33%），且绝大多数是合作模式（46%）。

混合游戏 (Hybrid) 和 竞争性游戏 (Competitive) 则非常罕见，是未被充分探索的“蓝海”。

**学科领域分布：**

施工管理 (Construction Management, CM) 是PM游戏化学习的“主战场”，拥有最长的研究历史和最多的游戏数量（17款）。

软件项目管理 (Software Project Management, SPM) 是最新趋势，75%的研究发表于2023年之后。

商业项目管理 (Business Project Management, BPM) 的游戏则更多面向研究生。

**创新的游戏化教学模式：**

学生自制游戏 (Student-Made Games): 这是一个非常有趣且未被充分探索的领域。在这种模式下，学习活动本身就是“做一款游戏”。学生通过亲身经历游戏开发的全过程，来实践和应用PM技能，如团队合作、沟通和组织能力。例如，有研究让土木工程学生设计关于施工管理的桌游，或让PM专业的学生带领CS专业大一新生进行游戏开发项目。

**4. 方法与实验**

[图像 18：待版权审查，原图保存在私有归档]

本研究采用系统性文献综述方法，其“实验”过程是严谨的文献筛选、分类与分析。

**研究框架:**严格遵循 PRISMA 框架进行文献的识别、筛选和纳入。

**检索策略:**

数据库: 使用 Scopus 数据库进行文献检索。

关键词: 采用了“game-based learning”, “serious game”, “project management”, “construction management”等多组关键词进行组合检索。

筛选流程 (见原文图1):

初步检索到203 篇文献。

经过筛选（时间范围2014-2024年、仅限期刊文章、英语），剩余76篇。

再根据内容相关性（必须是高等教育、GBL、PM、案例研究）进行精筛，最终纳入50 篇文献进行分析。

**分析方法：**

主题分析 (Content Analysis): 对50篇文献的内容进行深入阅读和归纳，总结出五大核心研究主题。

文献计量分析 (Bibliometric Analysis): 使用 VOSviewer 软件，对文献的发表年份、国家分布、关键词共现等进行可视化分析，以揭示宏观趋势。

**5. 结果**

[图像 23：待版权审查，原图保存在私有归档]

**主题分析的五大发现：**

试点研究 (Pilot Studies): 是游戏开发的关键环节，主要用于收集用户反馈，确保游戏玩法与学习目标一致。

案例研究 (Case Studies): 是最主要的研究形式（48%），重点关注三个方面：游戏反馈 (43%)、知识增益 (40%) 和学习行为 (17%) 。大多数研究都报告了积极的学生反馈和显著的知识获取。

比较研究 (Comparative Studies): 数量较少，主要比较不同界面（如桌面 vs VR）的效果，或GBL与传统教学的差异。目前的研究认为GBL应作为传统教学的补充，而非替代品。

学生自制游戏 (Student-Made Games): 一种创新的建构主义学习方式，能有效培养团队合作和学科兴趣。

游戏设计趋势 (Game Design Trends): 数字单人和桌面合作是主流，混合式和竞争式游戏有待开发。

**文献计量分析的发现：**

发表趋势： PM-GBL是一个小众研究领域（年均4篇），但在2021年后呈急剧上升趋势，可能与远程学习的需求有关。

地理分布： 研究主要集中在“全球北方”，其中美国（14篇）、英国（8篇）和西班牙（8篇）的贡献最大。

关键词趋势： “serious games”是比“educational games”更新、更常用的术语。对“批判性思维”、“决策制定”等软技能的关注日益增加。

**6. 讨论与总结**

[图像 33：待版权审查，原图保存在私有归档]

本综述系统地描绘了过去十年PM-GBL的研究版图。尽管GBL在提升学生参与度、自信心和积极性方面表现出色，但其在高等教育中的普及之路依然漫长。

**核心结论：**

研究主题集中： 当前研究主要集中在评估游戏的反馈、知识增益和学习行为上，且多采用主观的自我报告数据，缺乏客观、长期的效果评估。

设计范式固化： 游戏设计多为数字单人或桌面合作模式，竞争和混合模式等创新形式潜力巨大但未被充分挖掘。

教师角色转变： 在GBL中，教师的角色从知识传授者转变为学习的引导者和教练 。游戏后的复盘(debriefing)是连接游戏体验与现实应用的关键，其重要性被反复强调。

研究存在空白： 针对研究生的软件项目管理游戏和针对本科生的商业项目管理游戏数量稀少，是未来的研究蓝海。

**教学启示**

[图像 35：待版权审查，原图保存在私有归档]

**对教师的启示：**

拥抱教练角色： 在GBL课堂中，不要干预学生的游戏过程，而应在游戏结束后引导他们进行深入的讨论和反思，帮助他们建立游戏与现实的联系。

循序渐进： 如果对GBL不熟悉，可以先从一个独立的、小型的游戏练习开始，根据学生反馈再逐步整合到整个课程中。

改变评估方式： GBL更适合与过程性评估相结合，如反思性论文、项目报告等，而不是传统的选择题考试。

管理大班课堂： 对于大班教学，可以将学生分组，并培训助教担任游戏引导员。

**对学校的启示：**

支持教学创新： 教师对变革的抵触是GBL普及的一大障碍。学校应提供制度和资源上的支持，鼓励教师尝试新的教学方法。

促进跨学科合作： “学生自制游戏”模式需要多学科（如PM与CS）的合作，学校应为此搭建平台。

**对游戏设计师的启示：**

让多方参与设计： 在开发早期（试点阶段）就应邀请学生、教师和行业专家等多方利益相关者参与测试，以确保游戏的用户体验、教育价值和行业需求三者对齐。

为教师“减负”： 开发更多“无代码”的、可定制的、模块化的游戏模板或平台，降低教师使用的门槛，是加速GBL普及的关键。

分享成果： 鼓励通过开源、商业授权或共享文档等方式，让更多人能接触和使用到开发出的严肃游戏。

**对研究者的启示 (如何复现与推进):**

开展纵向研究： 当前研究多为短期评估，亟需开展学期甚至学年级别的纵向研究，以评估GBL对知识和技能保留的长期影响。

采用更客观的评估： 摆脱对自我报告数据的依赖，开发更多过程导向的、客观的评估方法。

关注“被忽视的变量”： 系统地研究性别、文化背景、过往游戏经验等因素对GBL效果的影响。

填补研究空白： 积极探索竞争性游戏、混合游戏，以及在SPM研究生和BPM本科生群体中的应用。

**Gemini锐评**

[图像 37：待版权审查，原图保存在私有归档]

**只靠Scopus“单腿走路”？****这综述的视野可能有点窄。**这篇系统综述最大的方法论短板是——它只检索了Scopus这一个数据库！对于一个旨在描绘领域全景的研究来说，这是个硬伤。像Web of Science、IEEE Xplore、ACM Digital Library这些数据库，尤其是在软件工程和计算机领域，同样藏龙卧虎。单库检索很可能遗漏了不少重要文献，让这份“全景图”出现盲区。

**精准定位了“病症”，但“病因”分析浅尝辄止。**文章开篇就点出了核心矛盾：GBL在PM教育中“叫好不叫座”。这是一个极有价值的洞察。然而，文章对于为什么“叫座难”的分析却不够深入。除了简单归因于教师的“变革阻力”和“额外工作量”，背后更深层次的制度障碍、评估体系错位、以及教育文化的惯性等问题，都没有被系统性地挖掘。

**一片“我觉得”的汪洋大海。综述承认，其分析的大多数研究都严重依赖自我报告数据（比如“我觉得我学到了”、“我觉得这个游戏很有趣”）。**这意味着我们目前对PM-GBL有效性的认知，很大程度上是建立在学生的“感觉良好”之上。到底学生的PM能力有没有实质性、可衡量的提升？能否迁移到真实工作中？这个领域迫切需要更多客观、基于表现的硬核证据。

**描述性分类很清晰，但理论性洞察不够深刻。**文章对文献进行了非常清晰的主题分类，告诉我们研究者们都做了什么。但在解释为什么会出现这些现象时，理论深度稍显不足。例如，为什么桌面合作游戏在PM领域如此流行？这背后可能与PM工作本身的社会性、协作性和沟通密集型特征有关。如果能结合组织行为学、学习科学等相关理论进行更深入的阐释，文章的洞察力会更上一层楼。
