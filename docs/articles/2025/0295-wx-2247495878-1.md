# 怎样的教育游戏才“耐玩”？基于模糊逻辑与决策树的数字公民游戏纵向研究

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

随着数字公民身份成为教育重点，如何设计既能持续吸引学生又能培养其道德责任感的游戏成为难题。本研究通过偏最小二乘结构方程模型（PLS-SEM），对372名泰国初中生进行了纵向重复测量设计（Longitudinal repeated-measures design）。研究利用模糊逻辑（Fuzzy Logic）和决策树（Decision Tree）算法个性化定制数字道德场景。结果发现，后期的持续动机（Sustained Motivation）是感知可持续性的最强预测因子，而教学设计和体验因素则通过动机产生显著的间接影响。研究证实了早期动机体验对后期参与度的纵向影响，强调了自适应反馈在长期行为改变中的重要性 。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

**RQ1:** 教学设计、内容质量、可用性和动机在多大程度上影响数字公民教育个性化游戏的可持续性？

**RQ2:** 这些设计和体验因素如何促进学生长期的动机和继续使用游戏的意愿？

**RQ3:**在这些因素中，哪一个不仅是可持续性的预测因子，而且是最显著的？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

数字公民教育旨在培养学生在网络环境中的道德、安全和负责任的行为 。虽然数字游戏学习（DGBL）被证明有效，但现有研究多关注短期效果，缺乏对AI增强的个性化如何维持长期学习行为的探讨 。本研究认为，“可持续性”不仅指技术的可用性，更指学习者持久的参与度、知识迁移以及负责任的数字行为的坚持 。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

**个性化学习设计：** 结合模糊逻辑和决策树的AI游戏已被证明能有效提升数字素养，利用学习者的行为决策生成形成性反馈 。

**可持续性定义：** 在本研究中，可持续性通过学生的\*\*持续使用意愿（Continuance Intention）和感知有用性（Perceived Usefulness）\*\*来衡量，这反映了学生对长期参与的动机承诺 。

**理论基础：**基于自我决定理论（SDT），模型假设教学设计、内容质量和可用性通过满足心理需求来驱动动机，进而预测可持续性 。

[图像 12：待版权审查，原图保存在私有归档]

**3. 游戏设计**

[图像 13：待版权审查，原图保存在私有归档]

本研究开发了一款2D角色扮演游戏（RPG），核心在于其“专家系统模块”，利用AI算法实现实时自适应反馈。

**游戏主题：**涵盖网络欺凌、数字冲突（Digital Drama）、网络安全等真实场景（改编自Common Sense Media课程） 。

**AI 核心引擎：**模糊逻辑 + 决策树 (Fuzzy Logic & Decision Trees)这套机制让游戏不是简单的“对/错”判断，而是具备了诊断能力：

数据收集： 系统记录学生在游戏中的决策（例如：是否报告网络欺凌） 。

模糊推理（Fuzzy Logic）： 将具体的行为转化为模糊概念。例如，系统会将学生的决策质量分类为“表现良好”、“部分表现”或“表现不佳” 。

决策树分析（Decision Tree）： 算法分析这些模糊输出，决定游戏下一步的路径 。

个性化反馈： 根据分析结果，系统提供针对性的反馈（如Emoji表情反应、叙事提示），并可能要求学生重玩（Replay）特定场景以强化道德推理 。

**💡 设计亮点：** 这种“决策-反馈-重玩”的循环，将隐性的行为数据转化为了显性的教学干预，不仅维持了参与度，还促进了学生的元认知反思 。

[图像 14：待版权审查，原图保存在私有归档]

**4. 方法与实验**

[图像 15：待版权审查，原图保存在私有归档]

这是一个典型的纵向研究，含金量极高，因为它跨越了两个学年。

**被试：** 372名泰国初中生（涵盖7-9年级） 。

**实验流程：**

Phase 1 (Time 1, 2023年): 学生玩7天游戏 -> 完成问卷（T1） 。

间隔期 (12个月): 无额外干预，进行常规数字素养教学 。

Phase 2 (Time 2, 2024年): 同一批学生再玩7天游戏（系统有升级） -> 完成问卷（T2） 。

**数据收集：**

问卷： 测量教学设计(PD)、内容质量(CQ)、可用性(US)、动机(MO)、可持续性(SUS) 。

系统日志： 记录游戏中的“好行为”和“坏行为”频率 。

**数据分析：** 使用 SmartPLS 进行偏最小二乘结构方程模型（PLS-SEM）分析 。

**5. 结果**

[图像 20：待版权审查，原图保存在私有归档]

**Time 1 的意外发现：** 在第一阶段，教学设计、内容和行为数据并没有显著预测动机（MO\_T1）。甚至，“好行为”与动机呈负相关（虽然不显著），这可能意味着初次接触时，表现好的学生觉得游戏挑战性不足。

**Time 2 的全面爆发：** 在第二阶段，所有的设计因素（教学、内容、可用性）以及游戏内的行为（无论好坏）都显著正向预测了动机（MO\_T2）。

**纵向传递效应：** Time 1 的动机显著正向影响 Time 2 的动机，证明了早期体验对长期参与的重要性。

**可持续性的核心：**Time 2 的动机（MO\_T2） 是可持续性（SUS\_T2）最强、最直接的预测因子（f^2效应量极大）。

**6. 讨论与总结**

[图像 27：待版权审查，原图保存在私有归档]

**动机是“引擎”：** 游戏设计再好，如果不能转化为持续的“动机”，就无法实现“可持续性”。设计因素（如UI、内容）是通过“动机”这个中介变量间接起作用的 。

**AI的作用：** 模糊逻辑和决策树的结合，使得游戏能够根据学生的历史行为调整反馈。T2阶段动机的显著提升，部分归功于系统能提供更复杂的场景和更精准的反馈，满足了学生的胜任感和自主感 。

**“坏行为”也是学习：** T2阶段，“坏行为”也能正向预测动机。这说明游戏中的试错（Error-based learning）在及时反馈的支持下，引发了反思，反而促进了投入 。

**教学启示**

[图像 29：待版权审查，原图保存在私有归档]

**👩‍🏫 对教师的教学启示**

利用后台数据： 教师应将游戏后台的行为日志（好/坏决策）作为形成性评价工具，识别哪些学生需要额外的伦理指导 。

拥抱试错： 不要害怕学生在游戏中做“坏决定”。研究表明，当配有解释性反馈时，错误决策能引发深度反思和更高的参与度 。

**🏫 对学校的启示**

长期主义： 数字公民教育不能是一次性的活动。研究证明，跨越学年的持续接触才能形成稳定的动机和行为规范 。

基础设施： 引入此类AI系统需要确保学校具备稳定的技术设施和教师支持系统 。

**🎨 对游戏设计师的启示**

自适应反馈是关键： 不要只给分数。设计能分析决策质量（而不仅仅是结果）的算法（如模糊逻辑），并提供能引导“重玩”的反馈机制 。

迭代设计： T1到T2的效果差异表明，随着学生能力提升，游戏内容的复杂度和反馈深度也必须动态升级，以维持挑战和兴趣 。

**🔬 研究者如何复现？（Replication Guide）**

算法选择： 复现时可尝试 Fuzzy Logic (分类行为质量) + Decision Tree (决定路径) 的组合，这是一种通过规则可解释的AI（XAI），比黑箱模型更适合教育归因。

实验设计： 尝试纵向设计。本研究的亮点在于 T1 和 T2 之间间隔了12个月，通过对比两个时间点的模型差异，能够更有力地论证“可持续性” 。

工具： 问卷设计参考文中 Table 2 和 Table 3，数据分析使用 SmartPLS 进行 PLS-SEM 建模 。

**Gemini锐评**

[图像 31：待版权审查，原图保存在私有归档]

这篇文章为我们提供了一个非常扎实的“AI+教育游戏”范本，但也并非完美：

**AI 的选择：** 在大模型（LLMs）横行的今天，这篇文章依然使用了模糊逻辑（Fuzzy Logic）这种“老派”AI技术。但这恰恰是它的聪明之处——在教育场景中，我们需要可解释、规则明确的反馈，而不是LLM有时产生的“幻觉”。对于规则明确的道德评价，经典算法可能比生成式AI更稳健。

**“可持续性”的定义局限：**文中将“可持续性”主要定义为“继续使用的意愿（Intention）”，这仍然属于自我报告（Self-report）的范畴。学生说“我想继续用”和“不仅用了而且行为真的改变了”之间还有距离。未来的研究如果能追踪 T2 之后真实的长期行为数据，会更具说服力 。

**T1 的尴尬：**Time 1 的结果几乎全军覆没（不显著），作者解释为“早期体验不足”。这其实给游戏化设计提了个醒：新奇效应（Novelty Effect）并不总是正向的，如果引导不足，学生在初期可能因为迷茫而产生不了动机。如何设计好“新手引导（Onboarding）”，是让游戏活过 T1 的关键。
