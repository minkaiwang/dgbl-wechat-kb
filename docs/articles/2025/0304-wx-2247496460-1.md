**Title**

Modelling the complex dynamic effect of L2 speaking anxiety in metaverse on students' academic enjoyment, pronunciation anxiety, speaking performance, and task load

建模元宇宙中二语口语焦虑对学生学业愉悦感、发音焦虑、口语表现及任务负荷的复杂动态影响

**DOI**

10.1002/berj.70062

**Keywords**

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

本研究深入探讨了在沉浸式技术不断发展的背景下，二语（L2）口语焦虑如何影响发音焦虑、感知任务负荷、口语表现以及学业愉悦感。尽管元宇宙常被认为能通过虚拟化身（Avatar）降低抑制感，但本研究关注虚拟环境是否可能无意中加剧了情感障碍。研究对 117名 高中生（14-17岁，B1-B2水平）进行了为期8周的实验，学生使用VR头显在元宇宙中完成辩论任务。

PLS-SEM（偏最小二乘结构方程模型）分析结果显示：元宇宙中的口语焦虑显著加剧了发音焦虑和感知任务负荷，并抑制了学业愉悦感和口语表现。此外，发音焦虑负向预测口语表现，而任务负荷负向预测学业愉悦感。不过，学业愉悦感被证实能显著提升口语表现。研究揭示了元宇宙语言学习中情感因素的复杂互动机制 。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

本研究构建了一个包含9条假设的结构模型，核心探究以下路径关系：

**焦虑的扩散：** 元宇宙口语焦虑是否会增加发音焦虑 (H1) 和任务负荷 (H2)？

**情感的抑制：** 元宇宙口语焦虑是否会降低学业愉悦感 (H3) 和口语表现 (H4)？

**连锁反应：** 发音焦虑 (H5) 和任务负荷 (H6) 是否会进一步拉低口语表现？

**愉悦感的力量：** 学业愉悦感能否提升口语表现 (H7)？

**负荷的代价：**任务负荷 (H8) 和发音焦虑 (H9) 是否会破坏学业愉悦感？

**1. 介绍**

[图像 10：待版权审查，原图保存在私有归档]

随着元宇宙（Metaverse）在教育领域的兴起，许多人认为其沉浸式、交互式和虚拟化身的特点能为语言学习者提供一个“低焦虑”的环境。然而，现有的研究多关注其积极面，往往忽视了技术本身可能带来的认知负担（如操作VR设备的难度）以及虚拟社交中的新型焦虑。本研究旨在填补这一空白，探究在完全沉浸式的元宇宙辩论任务中，心理与认知因素是如何动态交互并最终影响口语成绩的 。

[图像 11：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 12：待版权审查，原图保存在私有归档]

**元宇宙与语言学习：** 元宇宙被定义为一个通过虚拟化身进行互动的共享虚拟空间。理论上，它能提供情境化学习和具身认知体验 。

**二语口语焦虑（L2 Speaking Anxiety）：**尽管虚拟化身提供了一层保护色，但“被评价”的恐惧在虚拟世界中依然存在，甚至可能因为技术的陌生感而被放大 。

**发音焦虑（Pronunciation Anxiety）：** 这是口语焦虑的一个特定分支，指学生害怕因发音错误而被嘲笑。在沉浸式环境中，高保真的语音互动可能让这一点变得敏感 。

**任务负荷（Task Load）：** NASA-TLX模型定义的任务负荷包括心理、生理和时间需求。在VR中，学生不仅要处理语言信息，还要操控设备、导航环境，这构成了额外的认知负荷 。

[图像 13：待版权审查，原图保存在私有归档]

**3. 游戏/环境设计**

[图像 14：待版权审查，原图保存在私有归档]

本研究并非使用现成的商业游戏，而是基于 Spatial.io 平台构建了一个专门的教育元宇宙环境。

**平台与设备：** 使用 Spatial.io 元宇宙平台，学生佩戴 Oculus Quest 2 VR头显，手持控制器进行交互 。

**场景构建：** 设计了一个虚拟辩论大厅（Virtual Debate Arena），模仿现实世界的会议或辩论赛场，但加入了未来主义的视觉元素，以增强沉浸感。

环境支持空间音频（Spatial Audio），即声音会随着虚拟距离和方向变化，模拟真实听觉体验 。

**虚拟化身（Avatar）：** 学生可以自定义他们的 3D Avatars。研究允许学生自由选择外观，这被视为降低社交抑制的关键设计（虽然结果显示焦虑依然存在） 。

化身支持肢体语言（通过手柄控制手势）和面部表情模拟（Eye/Face tracking if available, or preset animations） 。

**任务设计：** 辩论任务（Argumentative Speaking Tasks）： 学生被分为正反方，就科技、环境等话题进行辩论。

交互机制： 学生需要“走”上讲台发言，听众在台下通过表情符号或动作给予反馈。这种仪式感极强的设计旨在模拟真实压力环境 。

[图像 15：待版权审查，原图保存在私有归档]

**4. 方法与实验**

[图像 16：待版权审查，原图保存在私有归档]

**参与者：** 土耳其某高中的 117名 学生（63女，54男），年龄14-17岁，英语水平为 CEFR B1-B2 。

**实验流程（共8周）：**

第1-2周（适应期）： 介绍元宇宙概念，分发VR设备，进行操作培训，创建虚拟化身，熟悉 Spatial.io 平台 。

第3-8周（实验期）： 每周进行一次 45分钟 的元宇宙辩论课。学生在虚拟教室中完成口语任务 。

**测量工具：**

焦虑量表： 改编自 FLCAS（外语课堂焦虑量表）和 PAS（发音焦虑量表） 。

任务负荷： 使用 NASA-TLX 量表（测量脑力需求、体力需求、时间紧迫感等） 。

愉悦感： 外语愉悦感量表（FLE） 。

口语表现： 两位评分员根据雅思（IELTS）口语评分标准对学生的录音进行打分（流利度、词汇、语法、发音） 。

**数据分析：**使用 SmartPLS 4.0 进行偏最小二乘结构方程模型（PLS-SEM）分析，验证路径假设 。

**5. 结果**

[图像 20：待版权审查，原图保存在私有归档]

模型解释力良好（R^2 values: 口语表现 45.4%, 愉悦感 30.6%, 发音焦虑 57.5%） 。

**焦虑的破坏力：**元宇宙中的口语焦虑对发音焦虑有极强的正向影响（beta=0.758, p<0.001），同时也显著增加了任务负荷（beta=0.596） 。

**焦虑抑制表现：** 口语焦虑直接负向影响学业愉悦感（beta=-0.375）和口语表现（beta=-0.228） 。

**发音焦虑的关键作用：** 发音焦虑显著负向预测口语表现（beta=-0.286），说明学生越担心发音，说得越差。

**任务负荷的副作用：** 高任务负荷显著降低了学业愉悦感（beta=-0.259），但其对口语表现的直接负面影响未达显著水平（H6不成立） 。

**快乐就是生产力：**学业愉悦感是口语表现的最强正向预测因子（beta=0.366） 。

**6. 讨论与总结**

[图像 26：待版权审查，原图保存在私有归档]

**技术不是万能药：** 尽管有虚拟化身，学生在元宇宙中依然感到焦虑。这种焦虑甚至可能因为技术操作的复杂性（高任务负荷）而被放大。例如，担心网络卡顿、操作失误或VR晕动症，都成为了新的焦虑源 。

**发音的执念：** 研究发现焦虑强烈地转化为对发音的担忧。在沉浸式音频环境中，学生对自己的声音更加敏感，这种“完美主义”倾向阻碍了流利表达 。

**愉悦感的中介作用：** 虽然焦虑和负荷有负面影响，但如果设计得当，元宇宙带来的新奇感和沉浸感（Enjoyment）可以显著抵消负面因素，直接提升成绩。这强调了“好玩”在教育中的硬核价值 。

**教学启示**

[图像 28：待版权审查，原图保存在私有归档]

**👩‍🏫 对教师的教学启示**

技术脚手架： 在正式上课前，务必给学生足够的技术适应期。不要让“如何操作手柄”成为学生开口说的障碍。

容错氛围： 在元宇宙中也要强调“内容大于形式”，明确告诉学生发音不完美是可以接受的，以降低发音焦虑。

关注愉悦感： 设计任务时要有趣味性（如角色扮演），最大化“学业愉悦感”这一核心驱动力。

**🏫 对学校的启示**

基础设施是底线： 任务负荷与网络延迟、设备重力密切相关。学校需确保高带宽网络和轻量化VR设备，否则技术本身就是一种负担。

混合模式： 不要为了元宇宙而元宇宙。对于高焦虑学生，可以先从非沉浸式（桌面版）开始，逐步过渡到VR。

**🎨 对游戏/环境设计师的启示**

简化交互（UI/UX）： 元宇宙教育平台的界面应极简设计，降低认知负荷。例如，发言按钮应触手可及，移动方式应符合直觉。

声音美化功能： 既然发音焦虑如此重要，是否可以开发“声音滤镜”或实时发音辅助功能？让学生听起来更自信，可能有助于降低焦虑。

化身保护机制： 设计当学生感到极度紧张时可以开启的“隐身”或“观察者模式”，提供心理安全区。

**🔬 研究者如何复现？（Replication Guide）**

工具复用： 可以直接使用本研究验证过的 SEM 模型框架。

控制变量： 注意控制学生的英语水平（本研究为 B1-B2）和 VR 熟练度，这两个变量极易干扰结果。

扩展方向： 本研究主要针对高中生，未来可以在大学生或成人学习者中复现，或者对比 VR 头显 vs 桌面式元宇宙的效果差异 。

**Gemini锐评**

[图像 30：待版权审查，原图保存在私有归档]

这篇文章非常及时地给“元宇宙教育热”降了温。它用扎实的数据证明了：换个马甲（Avatar）并不等于换了个人，社恐在元宇宙里可能还是很慌。

**模型构建精细：**将“焦虑”细分为一般焦虑和发音焦虑，并将“任务负荷”作为独立变量引入，这非常精准地捕捉到了VR学习的痛点——累（认知负荷高）。

**揭示了负面路径：**很多研究只谈元宇宙的 Engagement（投入度），但这篇指出了 Anxiety -> Task Load 的显著正向影响，说明越焦虑的学生觉得操作越难，这在教学设计中极具警示意义。

**局限性：**样本量（117人）对于复杂的 SEM 模型来说略显单薄；且研究未设置“非元宇宙”对照组，无法断言这种焦虑模式是元宇宙特有的，还是口语任务本身自带的。
