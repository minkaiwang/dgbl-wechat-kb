**Title**

A scoping review on serious games as rehabilitation technologies for ankle rehabilitation: game genres, game accessibility, and game usability

踝关节康复严肃游戏作为康复技术的范围综述：游戏类型、可访问性与可用性

**DOI**

10.1007/s10209-024-01173-4

Serious game (严肃游戏); Ankle rehabilitation (踝关节康复); Game genre (游戏类型); Game accessibility (游戏可访问性); Game usability (游戏可用性)

**摘要**

[图像 05：待版权审查，原图保存在私有归档]

为了应对踝关节损伤后的康复需求，严肃游戏逐渐成为一种激励家庭康复的手段。本研究通过范围综述（Scoping Review）的方法，对2009年至2024年间发表的53篇相关文献（涵盖70款游戏）进行了深度分析。研究发现，“体育类（Sports）”是应用最广泛的游戏类型。然而，现状令人担忧：绝大多数游戏并未考虑视力、听力或认知障碍者的可访问性，且极少有研究全面评估了游戏的可用性（如易学性、效率、满意度等）。未来的研究亟需结合现代AI工具，并从设计之初就融入无障碍理念 。

[图像 06：待版权审查，原图保存在私有归档]

**研究问题**

[图像 07：待版权审查，原图保存在私有归档]

RQ1: 用于踝关节康复的严肃游戏通常采用哪些游戏类型（Game Genres）？

RQ2: 这些游戏通过哪些踝关节动作来进行控制？

RQ3: 采集动作数据使用了哪些传感器？

RQ4: 这些严肃游戏是否提供了游戏可访问性（Accessibility）？

RQ5: 相关研究是否评估了游戏可用性（Usability）？

[图像 08：待版权审查，原图保存在私有归档]

**1. 介绍**

[图像 09：待版权审查，原图保存在私有归档]

踝关节扭伤是最常见的运动损伤之一，传统的物理治疗依赖治疗师的指导，但患者在家进行康复时往往缺乏反馈和动力。严肃游戏（Serious Games）作为一种“药”，旨在通过娱乐化的方式提高患者的依从性。尽管针对上肢康复和机器人辅助康复的综述很多，但专门针对踝关节康复游戏的设计元素（类型、无障碍性、可用性）的系统性分析却非常匮乏 。

[图像 10：待版权审查，原图保存在私有归档]

**2. 文献综述**

[图像 11：待版权审查，原图保存在私有归档]

**游戏类型分类：** 引用 Wolf (2001) 的分类法，如射击、策略、体育、解谜等。

**可访问性定义：** 即使在感官（视/听）、认知或运动受限的情况下，用户仍能进行游戏的能力。

**可用性四个维度：**

易学性 (Learnability): 上手难易度。

效率 (Efficiency): 学会后操作的流畅度。

错误 (Errors): 犯错频率及恢复能力。

满意度 (Satisfaction): 用户的愉快程度 。

[图像 12：待版权审查，原图保存在私有归档]

**3. 游戏设计**

[图像 13：待版权审查，原图保存在私有归档]

本综述分析了70款已开发的康复游戏，发现了以下设计模式：

**主流类型：** 体育类（Sports）占比最高（18.57%），如足球、乒乓球、滑雪等；其次是移动物体类（如控制球移动）和躲避类（如类似Flappy Bird的游戏） 。

**交互方式：** 94%的游戏使用\*\*足背屈（脚尖向上）和跖屈（脚尖向下）\*\*这两个最基础的动作来控制游戏 。

**硬件依赖：** 大多数游戏并非纯视觉识别，而是依赖外骨骼机器人或力/压力传感器（43%）来作为控制器。这意味着这些游戏大多需要昂贵的外部设备，而非仅仅一部手机或摄像头 。

**反馈机制：**绝大多数仅提供视觉反馈，只有7.5%提供了听觉反馈，3.8%提供了触觉反馈 。

**4. 方法与实验**

[图像 16：待版权审查，原图保存在私有归档]

**研究方法：**Scoping Review（范围综述）。

**数据库：** IEEE Xplore, PubMed, ScienceDirect, Scopus。

**筛选过程：** 检索到274篇文章，最终纳入53篇符合标准的英文文章（2009.1-2024.8）。

**分析框架：** 提取了游戏类型、康复动作、传感器类型、无障碍设计指标及可用性测试指标 。

**5. 结果**

[图像 22：待版权审查，原图保存在私有归档]

**缺乏AI介入：**令人惊讶的是，尽管AI发展迅速，但在这些康复游戏中，极少使用现代计算机视觉工具（如Mediapipe, OpenPose）来进行动作捕捉，绝大多数仍依赖笨重的传感器硬件 。

**可访问性危机：**

视觉/听觉： 游戏界面几乎都是固定的，无法调整颜色或声音，对视听障碍者极不友好。

认知/年龄： 虽然很多参与者是老年人，但没有一款游戏根据认知能力调整难度 。

**可用性评估缺失：** 没有任何一项研究完整评估了可用性的四个维度（易学性、效率、错误、满意度）。大多数研究仅停留在“能不能跑通”的技术验证阶段，而忽略了“好不好用”的用户体验 。

**6. 讨论与总结**

[图像 29：待版权审查，原图保存在私有归档]

**硬件的束缚：** 当前踝关节康复游戏对物理传感器（外骨骼、压力板）的依赖过重，限制了家庭普及。

**错失的AI机会：** 智能手机已具备强大的AI算力（如Azure, Mediapipe），完全可以通过摄像头实现低成本的动作捕捉，但这在现有研究中是一片空白。

**呼吁包容性设计：**康复游戏的用户往往伴随其他机能衰退（如老年人的视力下降），未来的设计必须包含多模态反馈（触觉/听觉）和自适应难度 。

[图像 30：待版权审查，原图保存在私有归档]

**教学启示**

[图像 31：待版权审查，原图保存在私有归档]

**👩‍⚕️ 对治疗师/教师的启示**

选择合适的类型： 体育类游戏（如模拟踢球）最容易被患者理解和接受，因为它们直观地映射了康复动作。

关注个体差异： 在推荐游戏时，不仅要看康复部位，还要评估患者的视力和认知能力，目前的很多游戏可能并不适合高龄老人。

**🏫 对学校/机构的启示**

跨学科合作： 康复游戏的设计不能仅由工程师完成，物理治疗师必须参与设计。数据显示，只有不到10%的研究有治疗师全程参与设计，这导致很多游戏机制并不符合康复科学 。

**🎨 对游戏设计师的启示**

拥抱轻量化AI： 放弃昂贵的传感器，尝试使用 Mediapipe 或 OpenPose 开发基于手机摄像头的康复游戏，这是未来的蓝海 。

无障碍设计是刚需： 增加“大字体模式”、“高对比度模式”和“语音指导”，这对于康复游戏的目标用户（通常是老年人或病患）至关重要。

**🔬 研究者如何复现？（Replication Guide）**

研究方向： 既然现有研究缺乏可用性评估，未来的研究可以复现现有的游戏模式，但重点放在SUS（系统可用性量表）测评和用户体验优化上。

技术路线： 尝试开发基于单目摄像头（Monocular Camera）的踝关节动作识别游戏，并对比其与传统传感器游戏的准确度与用户接受度。

**Gemini锐评**

[图像 33：待版权审查，原图保存在私有归档]

这篇综述像是一份“体检报告”，无情地指出了当前康复游戏领域的“虚火”：

**重技术，轻体验：** 大量研究堆砌了复杂的机器人外骨骼和传感器，却连最基本的“字体大小调整”或“音量控制”都没做。

**AI 滞后：**2024年的综述里，看到大家还在用电位器和编码器测角度，而不是计算机视觉，确实让人感到康复游戏领域与前沿科技的脱节。

**价值：** 这篇文章对于想做“医疗+游戏”方向的同学是极佳的选题指南——去做基于手机视觉的、无障碍友好的康复游戏，你就已经赢在了起跑线上。
