**摘要（Chatgpt）**

[图像 05：待版权审查，原图保存在私有归档]

🔹 科学知识往往较为抽象和复杂，学生在理解和应用这些概念时面临挑战。数字游戏化学习（DGBL）作为一种沉浸式学习方式，能够增强学习兴趣，但传统游戏化学习的固定学习路径和静态资源限制了个性化支持的可能性。

🔹 本研究创新性地**引入大语言模型**（LLM）构建**自适应情境游戏**（LLM-ACG），提供个性化反馈，优化学习路径，从而提升学生的学习体验和效果。

🔹 研究采用准实验设计，对比了\*\*LLM-ACG（实验组）与传统情境游戏C-CG（对照组）\*\*在以下四个方面的影响：

1️⃣ 学习成绩（Academic Achievement）

2️⃣ 流畅体验（Flow Experience）

3️⃣ 认知负荷（Cognitive Load）

4️⃣ 行为模式（Behavioral Patterns）

**研究结果表明：**
✅ LLM-ACG 显著提升了学习成绩和心流体验，让学生在游戏化学习中更加沉浸。
✅ LLM-ACG 有效降低认知负荷，学生能够更轻松地处理科学知识。
✅ LLM-ACG 促进了积极学习行为，学生在游戏中更倾向于探索、提问和深入互动。

**研究结论： 大语言模型（LLM）可以作为数字游戏化学习的强大助手，为学生提供更智能、更个性化的学习支持，优化科学教育体验。**

**3. 方法（Chatgpt）**

[图像 13：待版权审查，原图保存在私有归档]

本研究构建了一种**基于大语言模型（LLM）的自适应情境游戏（Adaptive Contextual Game, LLM-ACG）**，用于提升科学学习的效果。该游戏的核心设计理念是结合情境游戏化学习（Contextual Game-Based Learning, CGBL）与大语言模型（LLM）驱动的自适应机制，以动态调整学习任务，提供个性化反馈，优化学习路径，提高学生的学习体验。

**设计目标**

LLM-ACG 旨在解决传统情境游戏（C-CG）中存在的问题，如：

**①固定任务路径，缺乏个性化学习支持**：传统情境游戏的学习路径较为单一，不能根据学生的需求调整难度。

**②缺乏智能反馈机制**：传统情境游戏主要依赖预设提示，无法针对个体提供实时的学习支持。

**③认知负荷较高**：当任务难度不匹配学生的学习水平时，学生容易感到挫败。

LLM-ACG 通过 LLM 技术实现动态调整，提高游戏的适应性，增强个性化支持，优化认知负荷管理。

**LLM-ACG 方法的特点：**

①个性化学习支持：LLM 能够根据学生的提问和学习需求，提供实时反馈和个性化指导，使学习过程更加灵活。

②交互式学习体验：在游戏情境中，学生可以与游戏内的虚拟角色进行自然语言对话，获得即时的学习支持。

③动态适应性：不同于传统游戏中固定的学习路径，LLM-ACG 通过 AI 生成适应性内容，提供因材施教的学习体验。

④学习数据记录与分析：系统能够记录学生的行为模式，分析其学习过程，以优化教学设计。

**LLM-ACG 的实现方式：**

①游戏环境构建：基于情境化学习设计，打造虚拟世界或任务型学习场景（如科学实验模拟、历史探究任务等）。

②LLM 交互集成：在游戏中嵌入 LLM 支持的智能助手，调用Ollama的Qwen模型。学生可以通过对话窗口或任务引导获取帮助。

③实时反馈机制：LLM 根据学生的输入动态调整提示，提供解释、示例或建议，帮助学生深化理解。

④行为数据收集：系统自动记录学生的学习轨迹，包括提问行为、任务完成情况、交互频率等，为学习分析提供数据支撑。

**4. 实验设计（Chatgpt）**

**研究对象**

70 名五年级小学生（35 人实验组，35 人对照组）。

研究在中国浙江某小学进行，所有学生均有 3 年以上的计算机使用经验。

**实验设计**

实验组（LLM-ACG）： 使用 LLM 支持的自适应游戏学习模式。

对照组（C-CG）： 使用传统情境游戏，无 LLM 交互支持。

**6. 讨论与总结（Deepseek）**

[图像 35：待版权审查，原图保存在私有归档]

本文通过实验验证了基于大语言模型（LLM）的自适应情境游戏（LLM-ACG）在科学教育中的有效性。研究结果表明，LLM-ACG在提升学生学习成绩、增强心流体验、降低认知负荷以及促进积极学习行为方面显著优于传统情境游戏（C-CG）。具体发现如下：

①学习成绩提升：LLM-ACG通过实时反馈和个性化指导，帮助学生更好地掌握科学概念，尤其是低先验知识水平的学生进步更为显著。

②心流体验增强：LLM-ACG通过平衡任务挑战与学习者技能，创造了更具沉浸感的学习环境，显著提升了学生的心流体验。

③认知负荷降低：LLM-ACG通过提供精准的反馈和指导，帮助学生更有效地分配认知资源，从而降低了学习过程中的认知负荷。

④学习行为分析：滞后序列分析表明，LLM-ACG组学生表现出更多积极的探索和互动行为，尤其是在与LLM的持续互动中展现了更强的学习动机。

然而，研究也存在一些局限性，如样本规模较小、实验时间较短，且未充分考虑LLM生成内容的准确性问题。未来研究应进一步探索LLM-ACG在不同学科、年级和文化背景下的适用性，并设计更严谨的实验来验证其长期效果。

**教学启示**

①个性化学习支持：教师可以利用LLM的实时反馈和自适应功能，为学生提供个性化的学习支持，尤其是在复杂科学概念的教学中。

②游戏化教学设计：将LLM与游戏化学习结合，能够有效提升学生的学习动机和参与度。教师可以设计更多互动性强、反馈及时的游戏任务，帮助学生沉浸于学习过程。

③认知负荷管理：通过LLM提供的精准指导，教师可以帮助学生更高效地管理认知资源，避免因信息过载而影响学习效果。

④学习行为引导：教师应关注学生在游戏中的行为模式，尤其是与LLM的互动，鼓励学生通过提问和探索深化对知识的理解。

⑤跨学科应用：LLM-ACG不仅适用于科学教育，还可以推广到其他学科领域，如语言学习、数学等，为不同学科的教学提供创新工具。

总之，LLM-ACG为教育科技提供了新的可能性，但其成功应用仍需教师、研究者和技术开发者的共同努力，以确保其在实际教学中的有效性和可持续性。
