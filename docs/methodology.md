# 构建与审计方法

知识库遵循“原始数据—规范化内容—公开材料—检索索引”的分层流程。

1. 公开合集接口的原始响应保存在本地私有档案。
2. 每篇文章使用微信消息 ID 与图文序号构成稳定 ID。
3. 原始 HTML 先保存，再生成 Markdown；原图按版权审计批次保存到私有归档，不进入公开 Git。
4. 自动检查覆盖标题、日期、正文长度、图片数、链接和重复项。
5. 无法核实的内容进入 `uncertain`，第三方素材进入 `pending_review`。
6. 未完成素材审查时，公开 Markdown 只生成图片占位符，不热链、不提交原图。
7. 公开发布前，正文与图片必须分别完成权利确认；代码的 MIT 许可证不覆盖文章内容。
